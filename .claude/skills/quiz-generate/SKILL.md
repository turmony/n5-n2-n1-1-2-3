# JLPT 网上练习题组卷（quiz-generate）

题目必须来自日本日语教学网站已有的练习。AI 只负责检索、筛选、转录、匹配语法卡、组卷、翻译和讲解，不自行出题。不要求历年真题，普通教学练习题即可；未经核实不得冠以“真题”。

## 不可替代的题源规则

- 必须实际打开原题及其对应答案，不能凭搜索摘要、模型记忆、其他 AI 输出或没有出处的题库选题。
- 优先日本日语学校、教育机构、教师运营的日语教学网站；核实网站的运营者或教学背景，不以 `.jp` 域名或日语页面单独判定可靠性。
- 保留原题题干、上下文、空格位置、全部选项和选项顺序。只允许调整本卷题号、Markdown 排版以及无歧义的选项编号映射，并记录映射。
- 禁止自行写题、补写干扰项、替换词语、拼接不同题目、把例句挖空、把二选一或开放填空改成四选一、为锁定唯一解改写原题。用户要求20道四选一时，只选已有完整四选一题。
- 来源缺答案、疑似多解、答案与语法或上下文冲突、OCR 无法确定文字时，排除该题并另找原题。不得以模型答案替代来源答案，也不得自行修题后作为来源原题交付。
- 题量不足、考点覆盖不足、来源不可访问或检索工具不可用时，报告已找到的数量、缺少的卡片和原因。可以换可靠检索渠道；不得转为 AI 编题或擅自减少题数、扩大考点。需要调整范围时由用户决定，不宣称已经完成整卷。

## 第 0 步：读取要求与格式

先读仓库 `START-HERE.md`、`README.md`、`AGENTS.md`、资料库 `jlpt-notes/README.md` 与相应卡片前置元数据。既有试卷、答案、题卡仅作文件格式参考，不作为自编题模板。若旧设计文档与本流程冲突，以本流程的网上选题规则为准。

解析级别、卡片范围、题数与题型。沿用未指定时的默认值：N4、34题（形式选择20＋排序7＋完形7）；用户明确指定“20道选择题”则为20＋0＋0。课程编号只用于读取本地卡片，检索使用实际日语语法名称。

用户指定卡片时直接检索，不再重复请求选卡确认；指定练习不改变七天复习日期。未指定时，参考 attempts.jsonl、最近报告薄弱项、已确认且到期卡片，先给出卡号／考点／题型数量／理由的选卡建议，待用户确认后检索。

## 第 1 步：检索与来源取证

1. 阅读目标卡片的接续、语义边界和易混项，列出检索词，例如「ものだから 文法 練習問題」「をきっかけに 選択問題 解答」。
2. 使用当前环境可用的网页检索工具；有 Firecrawl 时按其搜索技能执行。搜索仅用于发现页面，须继续读取正文、原题和答案；交互题可操作到显示答案的位置，PDF/图片题须核对实际页面。
3. 只选择真正考查目标语法的题，语法仅出现在干扰项中不算覆盖。优先多站点取材，排除同题转载，避免为满足每卡固定配额而选不匹配的题。
4. 为候选题记录网站名、运营者或教学背景、标题、原题网址、原题号或唯一定位说明、答案网址及定位、检索日期。将题目和答案所在页面的相关摘录或截图保存至资料库 `quizzes/sources/<试卷名>/`，便于复核；快照必须来自实际读取的网页，不可由模型重构。
5. 记录每题对应语法卡及匹配理由。排序题必须已有完整题块、星号位置和可核实顺序；完形题须保留理解题目所需的完整篇章，不能只截取空格附近内容。
6. 统计各卡覆盖与题型数量。不足则按题源规则报告缺口，不生成伪完整试卷。普通教学练习无需额外取得“非真题”许可。

## 第 2 步：整理试卷、答案和题卡

- 试卷：`jlpt-notes/quizzes/papers/YYYY-MM-DD-<level>-<主题>-test-N.md`，保留既有标题和四选一格式；不含答案，尾部含空白“答案填写区”。标注“日本教学网站练习题选编”。逐题来源放在答案文件中，避免答题页暴露答案。
- 答案：`answers/<试卷名>-answers.md`，每题含题目、翻译、考点卡号、来源正确项、正确接续、解析和四个选项的逐项解释。追加来源链接、原题定位及本地证据链接；明确区分“来源答案／来源解析”和“AI 补充翻译与解析”。来源未给解析时如实注明，不能把补充讲解冒充网站原文。
- 题卡：`questions/<LEVEL>-Q-XXXX.md`，沿用 JSON frontmatter 字段：id/revision/level/item_type/prompt/translation/tested_cards/conjugation/options/correct_option/correct_explanation/option_explanations；排序另有 recommended_order。新编号接续该级别最大号，不覆盖旧卡；完全相同的既有题可复用，但须如实说明重复练习。
- 每张新选编题卡增加 `source` 对象，至少包含：`kind`（teaching_exercise；只有已核实才用 official_sample 或 past_exam）、`site_name`、`publisher`、`title`、`url`、`locator`、`answer_url`、`answer_locator`、`accessed_at`、`evidence_paths`（相对资料库根目录）、`original_answer`、`option_mapping`（原编号到本卷编号）、`adaptation`（仅排版／编号映射）。同页答案的 answer_url 可与 url 相同，定位须明确。
- 中文翻译与补充解析不能反向改变题目或答案。若讲解时发现来源有问题，排除并换题，不自行裁定一个答案。
- 对正文中的本地图片按所在 Markdown 目录写相对链接，遵守仓库图片校验规则。只写练习资料，不改正式语法卡或复习日期。

## 第 3 步：来源核对与机械校验

先逐题对照保存的原题及答案证据，确认空格、上下文、选项文字与顺序、答案映射一致，每题四项解释齐全。题目去重以来源定位和内容共同判断。

再运行现有校验器，例如20道形式选择题：

```text
uv run python .claude/skills/quiz-generate/scripts/validate_quiz.py --paper <试卷路径> --answers <答案路径> --structure 20,0,0
uv run python -m jlpt_notes validate-links --root jlpt-notes
```

校验器检查结构和文件一致性，**不会自动证明题源真实性或语法正确性**；不得用“机械校验通过”代替来源核对。图片链接校验非零时列出问题，不宣称完成。

发现转录或排版错误可按原文修复并重跑；题目本身有问题只能替换。最多3轮仍有错误则停止报告。查重警告须确认是否为用户已做题或同题转载，不用改写题干来绕过查重。

## 第 4 步：独立审题

派独立子代理盲答，第一阶段只提供试卷全文及目标语法卡目录，禁止读取答案文件、题卡和来源答案，不传含答案的证据。要求逐题输出答案、理由、信心；排序题拼出完整句。

第二阶段提供来源答案及证据定位，复核分歧和机械校验警告。来源答案不是必然正确；存在持续分歧、多个自然答案或不可靠出处的题直接排除，重新检索替换后重跑检查。不得让用户替有缺陷题目决定标准答案，不得通过 AI 改写消除分歧。

## 第 5 步：交付

说明试卷、答案、题卡及来源证据路径；报告题目数量、各卡覆盖、网站来源、来源核对、机械校验和独立审题结果。没有执行的步骤必须如实标注。不得编造“全绿”或网站来源。

仅在请求的数量、题型和范围均满足且检查通过后，按既有习惯提交本地 Git：`feat: 添加 <卷名>（日本网站练习选编，<题数>题，覆盖<卡段>）`。题量不足时只报告候选清单和缺口，等待用户决定后再正式组卷。

## 维护

用户只要求修改 skill 时，不执行检索组卷、不创建试卷或作答记录。今后新增机械校验能力时，要同时修改校验脚本及有意义的回归测试；文档中不得声称尚未实现的自动来源校验已经存在。
