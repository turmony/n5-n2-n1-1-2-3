# JLPT 本地学习系统

这是一个以本地 Markdown 为核心的 N5–N2 日语学习资料库。系统保存学习输出、校对结果、固定七天复习记录、N2 非听力练习和错题分析。

当前正在搭建基础功能。完成后，使用 `python -m jlpt_notes init --root jlpt-notes` 创建资料库。

详细设计见 `docs/superpowers/specs/`；实施计划见 `docs/superpowers/plans/`。

## iPad 局域网只读阅读器

阅读器将 `jlpt-notes` 下的 Markdown 和 JSONL 临时渲染成适合 iPad Safari 阅读的网页。目录、全文搜索、JLPT 等级与类型筛选、明暗主题和字号均在网页内使用；正式卡标题会保留 JLPT 编号。试卷页面还支持直接在 iPad 上点选作答并提交，答案会写入试卷文件的答案填写区。生成文件存放在系统临时目录，不会写入学习资料目录。

### 日常使用

1. 让 Win11 和 iPad 连接同一个可信任的家庭 Wi-Fi，并确认 Windows 将该网络标记为“专用网络”。
2. 双击桌面的“JLPT iPad 阅读器”。它只能手动启动，不会随电脑启动。
3. 等待窗口显示“运行中”，点击“复制地址”，然后在 iPad Safari 打开该地址。无需设置 Windows 账户密码或阅读器密码。
4. 资料变更后，阅读器会在数秒内重新生成页面。当前页变化时会显示提示；其他页变化时会自动载入新版本并尽量保留阅读位置。若更新构建失败，窗口会说明原因，并继续提供上一次成功版本。
5. 阅读完成后关闭控制窗口。监测、网页服务和本次临时页面会同时停止。
6. 正式语法卡的页尾提供「上一张卡／下一张卡」，仅在同级序列内按编号顺序翻阅；序列首尾自动隐藏对应按钮。

同一局域网内能连接该地址的人可能读取全部学习资料，所以不要在公共 Wi-Fi 使用，也不要把端口暴露到互联网。电脑休眠、关闭阅读器或离开当前局域网后无法访问；没有离线缓存。

### 首次设置

首次设置是一个连续流程，会安装本地阅读器并改变 Windows 状态，因此只在你明确同意后由 Codex 执行：

**安装阅读器（稳定目录）→ 创建桌面快捷方式 → 配置 Private + LocalSubnet 防火墙。**

稳定项目目录固定为 `D:\PersonalProject\n5-n2-n1-1-2-3`。开始前，Codex 会先把已经审核的实现合入这个最终目录，并检查下面四个位置都在该目录或选定的固定运行时中：

- 学习资料：`D:\PersonalProject\n5-n2-n1-1-2-3\jlpt-notes`
- 阅读配置：`D:\PersonalProject\n5-n2-n1-1-2-3\reader\mkdocs.yml`
- 阅读器模块：`D:\PersonalProject\n5-n2-n1-1-2-3\src\jlpt_notes`
- 启动程序：一套固定运行时中互为同目录兄弟的 `python.exe` 和 `pythonw.exe`

Codex 会使用这套 `python.exe` 从稳定项目目录安装阅读器，再确认实际导入的 `jlpt_notes` 仍指向上面的稳定目录。随后才会用同目录的 `pythonw.exe` 创建桌面快捷方式，并为这个完全相同的 `pythonw.exe` 创建仅限 TCP 8765、Private + LocalSubnet 的防火墙规则。快捷方式的工作目录、资料目录和配置文件也必须全部指向稳定项目目录。此流程不会创建任何开机启动项，公共网络不会开放。

`.worktrees` 下的目录是开发期间的临时工作树，可能被删除，永远不能作为安装、快捷方式或防火墙配置目标。即使临时工作树中的测试全部通过，也必须先把实现合入稳定项目目录，再执行首次设置。

设置完成后，平时只需双击快捷方式。若控制窗口显示“当前只允许本机访问”，可点击“配置专用网络访问”并确认 Windows 的管理员提示。取消提示不会影响资料，也只会保持本机预览。

如果项目曾被移动、快捷方式含有 `.worktrees`、导入位置不是稳定目录，或更换了 Python 运行时，应关闭阅读器并让 Codex 重新安装：先在稳定目录重新安装并验证导入位置，再重建桌面快捷方式；如果 `pythonw.exe` 路径改变，还要用新的精确路径替换防火墙规则。不要只修改快捷方式后继续使用旧规则。

### 严格只读边界

- 网页服务只接受 `GET` 和 `HEAD` 阅读请求；唯一例外是作答提交端点 `POST /reader/submit-answers`。
- 提交端点只能改写 `quizzes/papers/` 下既有试卷的「答案填写区」代码块内部；不能创建、删除或修改其他文件，文件其余部分逐字节不变；答案区已有内容时拒绝提交。
- 阅读器将 `.md` 和 `.jsonl` 渲染为页面，不会修改其他源文件的内容、大小或修改时间。
- 本地 PNG、JPEG、GIF、WebP 图片也会只读复制到临时站点，保留卡片相对链接并在正文显示；图片变更会触发重建。隐藏文件和链接到资料库外部的文件不发布。
- 损坏的 Markdown 元数据和 JSONL 记录会显示只读警告，不会回写修复。
- 临时网页不会放入 `jlpt-notes`；停止阅读器后会清理本次临时页面。

### 故障排查

图片链接可单独只读检查：`uv run python -m jlpt_notes validate-links --root jlpt-notes`（`validate` 也执行此检查）。命令检查正文中的本地图片、引用式图片和指向 PNG/JPEG/GIF/WebP 的超链接；不联网检查外部图片，不验证图片画面内容。退出码 0 表示通过，1 表示发现问题或资料库不存在，不会创建或修改目录。

图片必须位于资料库内，且符合阅读器的可发布规则。缺图、隐藏文件、符号链接／目录联接和不支持的图片格式均会报告原文档、原链接及解析目标。阅读器仍提供文字阅读，页面显示缺图提示；控制窗口显示问题数量、首条详情与完整临时日志位置。补回图片后会自动重建并清除提示。

入库自动调用 `rebase_assets` 按草稿和正式卡的真实目录换算图片链接，保留正文、代码示例及链接标题。校验失败或无法无损换算时，在写正式卡、草稿确认状态和确认事件前停止。批量／手动整理必须遵守 `AGENTS.md` 中相同的前置校验；完整 pytest 测试包含实际资料库图片链接检查。图片技术修复不改变既有七天复习日期。

| 现象 | 处理方法 |
|---|---|
| 窗口显示网络不是“专用网络” | 在 Windows“设置 → 网络和 Internet → 当前连接”中将网络配置文件改为“专用网络”，然后重新打开阅读器。只对可信任的家庭网络这样做。 |
| iPad 打不开，窗口提示防火墙规则缺失 | 点击“配置专用网络访问”，确认 Windows 管理员提示；取消后仍只允许本机访问。 |
| 两台设备看似连接 Wi-Fi，仍无法打开 | 确认两台设备连接同一个普通 Wi-Fi，而不是访客网络；路由器的“访客隔离/AP 隔离”会阻止设备互访。 |
| 窗口提示端口 8765 被占用 | 关闭可能占用该端口的旧阅读器或其他程序，再重新启动。不要同时打开两个阅读器窗口。 |
| 刚才可读，锁屏或一段时间后失联 | 唤醒 Win11 并保持网络连接；电脑睡眠时网页服务暂停。 |
| 首次构建失败 | 按窗口给出的错误和日志位置检查损坏或非 UTF-8 文件；修正源文件后关闭并重新启动。阅读器不会替你修改文件。 |
| 更新后提示“已继续提供上一个版本” | 当前旧页面仍可安全阅读。按窗口给出的临时日志检查最近修改的文件；修正后等待下一次自动更新。 |
| 本机能打开，iPad 不能打开 | 依次检查专用网络、防火墙提示、同一 Wi-Fi、访客隔离和电脑是否休眠；不要通过路由器做端口转发。 |
