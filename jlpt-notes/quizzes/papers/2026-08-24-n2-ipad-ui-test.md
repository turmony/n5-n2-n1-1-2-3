# N2 iPad 作答页面测试卷

- 日期：2026-08-24
- 用途：仅测试 iPad 阅读器的点选、题号进度、不确定标记与提交页面；不是正式练习卷，不纳入复习或判分。
- 题源：复制自既有 iPad 提交链路测试卷；不做语法、答案或题目质量检查。
- 题数：6 题（形式选择 4 ＋ 句子排序 2）
- 听力：无；读解：无

## 作答说明

- 每题只有一个最佳答案；排序题提交完整语序（如 `5：1234`）。
- 在 iPad 上直接点选作答，全部作答后点击「提交答案」。
- 在题号前加 `*` 表示不确定（点每题下方的「标记不确定」开关）。

## 第一部分：文の文法１（形式选择）（1–4）

### 1. 「お荷物は、私が明日お宅まで（　）。」

1. お届けします
2. お届けになります
3. 届けていらっしゃいます
4. 届けております

### 2. 今日は忙し（　）から、昼ご飯を食べる時間もありませんでした。

1. すぎて
2. すぎって
3. すきて
4. すぎと

### 3. 学生のころ、京都に（　）ことがあります。

1. 住む
2. 住んで
3. 住んだ
4. 住んでいる

### 4. 今日のミーティングは３時からです（　）。みんな知っていますか。

1. かな
2. よね
3. かしら
4. っけ

## 第二部分：文の組み換え（句子排序）（5–6）

将四个语块排列成自然的句子，提交完整语序（如 `5：1234`）。每题仅有一种自然语序。

1. 撮った
2. 先週
3. 旅行の
4. 家族で

4. 一度も
