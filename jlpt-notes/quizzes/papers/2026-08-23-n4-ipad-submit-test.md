## 作答说明

- 在 iPad 上直接点选作答，全部作答后点击「提交答案」。
- 在题号前加 `*` 表示不确定（点每题下方的「标记不确定」开关）。

## 第一部分：文の文法１（形式选择）（1–4）

### 1. 「お荷物は、私が明日お宅まで（　）。」

1. お届けします
2. お届けになります
3. 届けていらっしゃいます
4. 届けております

### 2. 今日は忙し（　）から、昼ご飯を食べる時間もありませんでした。

1. すぎて
2. すぎって
3. すきて
4. すぎと

### 3. 学生のころ、京都に（　）ことがあります。

1. 住む
2. 住んで
3. 住んだ
4. 住んでいる

### 4. 今日のミーティングは３時からです（　）。みんな知っていますか。

1. かな
2. よね
3. かしら
4. っけ
