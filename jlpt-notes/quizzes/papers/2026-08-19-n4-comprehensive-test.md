2. 電子辞書より値段が安いから
3. 目的のことばを一番早く調べられるから
4. 電子辞書より長く使えるから

### 37.

最近、うちの町の図書館で、大きな声で話す人が増えたように思う。静かな場所で勉強したいと考えて来ている人は多いはずだ。図書館の一部には「話してもいい席」があるが、利用者はそれを守っていないように見える。私は、新しいルールを増やすより、利用者一人一人が「図書館はみんなの勉強の場だ」ということを、もう一度考え直す必要があると思う。そうすれば、特別なルールがなくても、自然に静かになるはずだ。

### 朝の散歩

私は半年前から、毎朝六時に起きて、近所の公園を三十分歩くことにしている。きっかけは、健康診断の結果が悪かったことと、医者に「もっと運動するように」と言われたことだ。最初の一週間はとてもつらくて、やめようと思ったこともあった。しかし、二週間目から、体がだんだん軽くなってきたのが分かった。今ではすっかり習慣になり、雨の日は休むが、それ以外はほとんど毎日歩いている。

散歩のいい点は、体の調子だけではない。公園で会う年配の人たちと、朝のあいさつを交わすようになったし、季節の花の変化を感じるようにもなった。先月の健康診断では、数字が全部よくなっていて、医者にもほめられた。早く起きるという小さな習慣が、思ったより大きな変化を私に運んできてくれたと思う。

3. 年配の人たちと話す機会がほしかったから
4. 朝早く起きるのが昔から好きだったから

#### 39. 散歩を始めてから変わったことはどれか。

3. 健康診断の数字は、まだほとんど変わっていない

#### 40. 筆者の今の気持ちはどれか。

1. 続けるのがつらくなってきた

## 第六部分：主張・意見（長文）（41–43）

次の評論を読んで、後の三つの質問に答えてください。

### 考える力

「できません」と言う子どもに、大人はすぐ答えを教えてしまうことが多い。時間がないとき、それが一番早い方法に見えるからだろう。しかし、答えを教えられた子どもは、そのときは分かったような顔をするが、次に似た問題に出会うと、また「できません」と言うことになる。

考えるというのは、自分の中で、問いと答えの間を何度も行ったり来たりする作業である。その時間を大人がなくしてしまうと、子どもは考える練習をする機会を失ってしまう。もちろん、何も教えないほうがいい、という意味ではない。大人の役目は、答えを渡すことではなく、子どもが自分の力で答えの近くまで行けるように、小さなヒントを与えることだ。道を尋ねる人に、目的地まで車で送るのではなく、地図の一部を見せる、と言えばいいだろう。

考える力は、教わって手に入れるものではなく、自分で使って育てるものなのである。

#### 41. 筆者が最も言いたいことはどれか。

1. 困っている子どもには、すぐ答えを教えてあげたほうがいい
2. 大人の役目は、答えを渡すのではなく、考える手伝いをすることだ
3. 効率よく学ぶには、答えを早く教えるのが一番いい
4. 子どもが自分で解決するまで、何も言わないで待ったほうがいい

#### 42. 文中の「地図の一部を見せる」は、何に例えたものか。

1. 目的地まで車で送ること
2. 答えを全部教えること
3. 道を尋ねること
4. 小さなヒントを与えること

#### 43. この文章の内容と合っているのはどれか。

1. 答えを教えられた子どもは、似た問題ができるようになる
2. 時間がないときは、答えを教えるしかない
3. 考える力は、自分で使ってこそ育つものだ
4. 答えの近くまで行けるかどうかは、子どもの才能で決まる
