## 对学习者理解的判断

本节重点正确：这些形式是日常会话中常见的缩约，JLPT 题目常要求识别其完整形式和语气。

- 缩约主要用于随意会话、影视对白、聊天等，不宜直接用于正式书面语或郑重场合。
- 缩约改变的是发音和写法，不改变原语法的基本意义；还原后再判断原句语法最稳妥。

## 待确认卡

# 核心

日语口语会把常见语法形式缩短，使表达更自然、更轻快。学习时应同时掌握“缩约形式 → 完整形式”的还原。

# 常见缩约

## 1. 「～てしまう／～でしまう」→「～ちゃう／～じゃう」

| 完整形式 | 口语缩约 |
| --- | --- |
| `～てしまう` | `～ちゃう` |
| `～でしまう` | `～じゃう` |
| `～てしまいました` | `～ちゃいました` |
| `～でしまいました` | `～じゃいました` |

- 今朝買ったパンは、全部食べちゃいました。  
  今早买的面包全吃完了。
- 飼っていた金魚が死んじゃいました。  
  养的金鱼死了。

## 2. 「～ては／～では」→「～ちゃ／～じゃ」

常见于禁止或条件表达。

- ここでタバコを吸ってはいけません。  
  → ここでタバコを吸っちゃいけません。  
  这里不可以抽烟。
- お酒を飲んではだめですよ。  
  → お酒を飲んじゃだめですよ。  
  不可以喝酒哦。

## 3. 「～なければ」→「～なきゃ」

常用于义务、必要等表达。

- 英語でレポートを書かなければなりません。  
  → 英語でレポートを書かなきゃなりません。  
  必须用英语写报告。

## 4. 「～ておく／～でおく」→「～とく／～どく」

| 完整形式 | 口语缩约 |
| --- | --- |
| `～ておく` | `～とく` |
| `～でおく` | `～どく` |
| `～ておいて` | `～といて` |
| `～でおいて` | `～どいて` |

- 食事が終わったら、お皿を洗っておいてください。  
  → 食事が終わったら、お皿を洗っといてください。  
  吃完饭后，请把盘子洗好。
- バスに乗る前に、酔い止めの薬を飲んでおきます。  
  → バスに乗る前に、酔い止めの薬を飲んどきます。  
  坐公交车前，先吃好晕车药。

## 5. 「～ています／～でいます」→「～てます／～でます」

口语中常省略「い」。

- 運転免許を持っていますか。  
  → 運転免許を持ってますか。  
  有驾照吗？
- 今、本を読んでいます。  
  → 今、本を読んでます。  
  现在正在看书。

## 6. 五段动词ら行「～らない」→「～んない」

这是部分五段动词否定形的口语缩约。

- 英語が分からない。  
  → 英語が分かんない。  
  不懂英语。
- その車は止まらない。  
  → その車は止まんない。  
  那辆车停不下来。

注意：此规律针对动词的「～らない」，不是把所有「ない」都改成「んない」。

# JLPT N4 提示

- 先把`ちゃ／じゃ`还原成`ては／では`或`てしまう／でしまう`，再由上下文判断具体意思。
- `なきゃ`常接`ならない／いけない`，表示“必须”。
- 口语缩约在听力、会话和阅读的对白中常见；选择正式表达时优先使用完整形式。
