## 学习者原始输出

这节语法讲的是助词も的全部否定的用法,它的句型规则是疑问词加も加否定,表示全部否定,结合图片中的例句进行分析。

## 待确认卡

# 核心

「疑问词＋（助词）＋も＋否定」表示全面否定，即“没有任何……／谁也不……／哪里也不……”。句末必须是否定形式。

**基本形式**：

- 何も＋否定：什么也不……
- 誰も＋否定：谁也不……
- どこも／どこにも＋否定：哪里也不……
- 「誰か／何か」等疑问词后也可保留原来需要的助词，再加「も」。

# 图片例句

1. 今朝は何も食べませんでした。  
   ——今天早上什么也没吃。

2. 明日はどこも行きません。うちにいます。  
   ——明天哪里也不去，待在家里。  
   *「どこにも行きません」也很常用；「に」强调目的地。*

3. 今日は誰とも話したくないです。  
   ——今天不想和任何人说话。

4. 妖怪はどこにもいません。人間の想像です。  
   ——妖怪哪里也不存在，是人类的想象。

# 助词与「も」的位置

| 要表达的关系 | 形式 | 例句 |
| --- | --- | --- |
| 做某事的对象 | 何も | 何も食べません。——什么也不吃。 |
| 存在／去往的地点 | どこにも | どこにも行きません。——哪里也不去。 |
| 一起做事的人 | 誰とも | 誰とも話しません。——不和任何人说话。 |
| 接受动作的对象 | 誰にも | 誰にも会いません。——谁也不见。 |

「を」「が」「は」等助词常被「も」取代，如「何も食べません」；「に」「と」「から」等表示具体关系的助词通常保留，形成「にも」「とも」「からも」。

# 易混项与JLPT N5考点

- 必须与否定搭配：  
  × 何も食べます。　○ 何も食べません。  
  *注意「何でも食べます」是“什么都吃”，属于全面肯定，不能混淆。*
- 「誰も」是“谁也不”；要表达“和谁也不说话”用「誰とも」。
- 「どこにもいません」用于“任何地方都没有（人／动物等）”；「どこにもありません」用于“任何地方都没有（物品等）”。
- 句末的否定可以是「～ません」「～ない」「～ませんでした」「～たくない」等。

# 自然例句

- 今日は誰も来ません。——今天谁也不来。
- 冷蔵庫に何もありません。——冰箱里什么也没有。
- 休みの日はどこにも行きたくないです。——休息日哪里也不想去。
