# 丁宁体与普通体：礼貌体和简体

日语句子常根据对象、场合和说话人的立场，选择丁宁体（です・ます体）或普通体（简体）。

## 1. 丁宁体（です・ます体）

丁宁体以「です／ます」结尾，用于初次见面、对老师或上级、服务场合、正式谈话等。它表达礼貌和郑重，通常会让交谈保持较正式的距离感。

- 毎日、日本語を勉強します。  
  我每天学习日语。
- 田中さんは学生です。  
  田中是学生。

## 2. 普通体（简体）

普通体常用于朋友、家人和亲近的人之间的自然交谈，也用于日记、文章、独白，以及许多语法句型的句中接续。它更直接、随意，常会带来较亲近的感觉。

- 毎日、日本語を勉強する。  
  每天学习日语。
- 田中さんは学生だ。  
  田中是学生。

## 基本对应

| 类别 | 丁宁体 | 普通体 |
| --- | --- | --- |
| 动词现在肯定 | 行きます | 行く |
| 动词现在否定 | 行きません | 行かない |
| 动词过去肯定 | 行きました | 行った |
| 动词过去否定 | 行きませんでした | 行かなかった |
| 名词／な形容词肯定 | 学生です／静かです | 学生だ／静かだ |
| い形容词肯定 | 高いです | 高い |

## 语义边界与易混项

- “心里距离”是理解二者差异的一个好方法，但不是绝对规则。丁宁体首先表示礼貌、正式和对对方的尊重，不一定代表关系真的疏远；熟人之间在正式场合也会使用丁宁体。
- 普通体并不总等于“不礼貌”。它适合平辈、家人、亲近朋友，以及写作、内心独白和句中接续；对老师、上级或初次见面的人直接使用，可能显得过于随意。
- 普通体的名词和な形容词在肯定句末可用「だ」，但い形容词不能加「だ」：高い（不能说「高いだ」）。
- 同一段对话中要尽量保持体裁一致；随意切换可能造成语气变化，或听起来不自然。

## JLPT N5 考点

- 判断句子是です・ます体还是普通体。
- 能把动词、名词、形容词的基本肯定／否定／过去形式互相转换。
- 理解普通体会出现在「～と思う」「～から」等后续语法的接续位置，不能一概把它理解为只用于随便说话。

## 自然例句

- 先生：明日、テストがあります。  
  老师：明天有考试。
- 友だち：明日、テストがある。  
  朋友：明天有考试。
- 私はこの映画はおもしろいと思います。  
  我觉得这部电影很有意思。
