# 接续词：连接句子与逻辑关系

接续词用于连接前后两个独立的句子，并说明它们之间的逻辑关系。基本位置是**后一句的句首**：

**A。接续词、B。**

它在整段话中位于 A 和 B 之间，但不是放在一个句子的中间；书写时通常先结束 A，再用接续词开始 B。

## 图片中的五种用法

| 关系 | 常见接续词 | 图片例句与作用 |
| --- | --- | --- |
| 顺接 | ですから／だから | 仕事でよく日本へ行きます。ですから、日本語を勉強しています。——前句是理由，后句是结果。 |
| 逆接 | しかし／でも | タクシーで行きました。しかし、間に合いませんでした。——有利条件存在，结果却与预期相反。 |
| 对比 | しかし | 原子力発電は二酸化炭素を出さない。しかし、事故が起きた時は大変だ。——并列呈现相反方向的评价。 |
| 添加／递进 | それに／そして | 果物はおいしいです。それに、体にいいです。——在前一项优点上补充另一项。 |
| 顺序 | それから／そして | 今晩、友達と食事します。それから、映画を見ます。——按时间先后叙述动作。 |

“逆接”和“对比”在实际用法中常有重叠：两者都可出现「しかし」。初学时可这样区分：后句若明显违背前句带来的预期，叫逆接；若主要并列两个相反方向的事实或评价，叫对比。

## 图片例句分析

### 顺接：ですから

**仕事でよく日本へ行きます。ですから、日本語を勉強しています。**  
我因工作经常去日本。因此正在学习日语。

「ですから」把前一句作为理由，推出后一句的结果。普通体中常用「だから」。

### 逆接：しかし／でも

**タクシーで行きました。しかし、間に合いませんでした。**  
坐出租车去了。但是，还是没赶上。

坐出租车本来让人期待能赶上，后句却是否定结果，所以是逆接。「でも」也可用，且更常见于会话：タクシーで行きました。でも、間に合いませんでした。

### 对比：しかし

**原子力発電は二酸化炭素を出さない。しかし、事故が起きた時は大変だ。**  
核能发电不排放二氧化碳。但是，发生事故时会很严重。

前句说明优点，后句说明风险；重点是把两个不同方向的评价放在一起比较。

### 添加：それに／そして

**果物はおいしいです。それに、体にいいです。**  
水果很好吃。而且对身体好。

「それに」表示“而且、再者”，在已有内容上继续添加。这里的「そして」也可表示“并且”，但「それに」更突出“再补充一个理由／优点”。

### 顺序：それから／そして

**昨日、寿司屋へ行きました。そして、大トロを食べました。**  
昨天去了寿司店。然后吃了金枪鱼大腹。

「それから」和「そして」都可按顺序连接动作；「それから」更明确表示“在那之后”。

## 接续词与接续助词的区别

| | 接续词 | 接续助词 |
| --- | --- | --- |
| 连接单位 | 两个独立句子／话语 | 一个句子里的两个分句 |
| 位置 | 后一句的开头 | 前一分句的句尾，接在词的活用形式后 |
| 图片例子 | 日本語は難しいです。**でも**、おもしろいです。 | 日本語は難しいです**が**、おもしろいです。 |

同样是“但是”，两句的结构不同：

- **日本語は難しいです。でも、おもしろいです。**  
  「でも」是接续词，前后各自可以独立成句。
- **日本語は難しいですが、おもしろいです。**  
  「が」是接续助词，附在前一分句「難しいです」后，把两个分句连成一个句子。

## 语义边界与易混项

- 接续词并非一律只能写成两个完整句号；在口语中停顿可能较短，但它在语法上仍从后一句开始。
- 「しかし」较书面、正式；「でも」较口语、自然。两者都可表示逆接。
- 「そして」既可表示添加，也可表示动作顺序，需根据前后关系判断。
- 「ですから」是接续词；「～から」附在前一分句后表示原因时，属于接续助词，二者位置不同。

- 根据上下文选择ですから、しかし／でも、それに、そして、それから等接续词。
- 区分表示理由、逆接、添加和顺序的逻辑关系。
- 区分「でも」和「が」、「ですから」和「～から」的结构位置。

## 自然例句

- 明日は休みです。ですから、遅くまで寝ます。  
  明天休息。因此我会睡到很晚。
- この店は小さいです。でも、人気があります。  
  这家店很小。不过很受欢迎。
- まず宿題をします。それから、テレビを見ます。  
  先做作业，然后看电视。
