## 学习者原始输出

继续。动词て形+しまいます。有三种用法。1，表示遗憾。2，表示动作快速完成，迅速进行。3，表示无法抵抗！无法控制。注意图中的口语缩约现象

## 对学习者理解的判断

理解基本正确，需补充两点。

- 「～てしまいます」可表示说话人认为遗憾、可惜或非本意的结果；也可只陈述意外的负面结果，是否带强烈遗憾需看语境。
- 第二种用法的核心是“完全做完／彻底完成”，并非一定“快速”。若语境有「今日中に」「全部」等，常会带尽快做完的语感。
- 第三种用法表示动作或变化不由自主地发生，常含“结果竟然如此”的意味；它与遗憾用法可以重叠。
- 口语中「～てしまう」常缩约为「～ちゃう」，「～でしまう」常缩约为「～じゃう」。

## 待确认卡

# 核心

`动词て形＋しまいます`有两个主要核心：动作全部完成，以及动作或结果非本意地发生。后者可进一步表现为遗憾、意外或不由自主。

# 接续

动词て形＋しまう／しまいます

- 食べる → 食べてしまいます
- 飲む → 飲んでしまいます
- 忘れる → 忘れてしまいます

后项「しまう」按句子需要活用：

- 書いてしまいました：已经写完了／不小心写了。
- 食べてしまいましょう：把它吃完吧。
- 忘れてしまった：竟然忘了。

# 三种常见语境

## 1. 非本意的结果、遗憾

多用于发生了不希望发生的事情，常译为“不小心……了”“竟然……了”。

- 服が汚れてしまいました。  
  衣服弄脏了。（可惜／麻烦了）
- 切符をなくしてしまいました。  
  不小心把票弄丢了。

## 2. 完全做完

表示前项动作做到结束、没有剩余；在赶时间的语境中可含“尽快完成”。

- 今日中にレポートを書いてしまいます。  
  今天之内把报告写完。
- 残りはあと少しですから、全部飲んでしまいましょう。  
  剩下的不多了，把它全喝完吧。

## 3. 不由自主地发生

用于情感、身体反应或结果难以控制的情形。此用法可同时含意外或遗憾的感受。

- お酒を飲むと、顔が赤くなってしまいます。  
  一喝酒脸就会变红。
- この小説を読んで、泣いてしまいました。  
  读了这本小说，不由得哭了出来。

# 口语缩约

| 原形 | 口语形式 | 例句 |
| --- | --- | --- |
| `～てしまう` | `～ちゃう` | 食べてしまう → 食べちゃう |
| `～でしまう` | `～じゃう` | 飲んでしまう → 飲んじゃう |
| `～てしまいました` | `～ちゃいました` | 食べてしまいました → 食べちゃいました |
| `～でしまいました` | `～じゃいました` | 飲んでしまいました → 飲んじゃいました |

缩约多用于日常会话，正式书面语及需要郑重表达时通常避免使用。

# 易混项

## 与单纯过去式

- レポートを書きました。  
  写了报告。→ 只说明完成这一事实。
- レポートを書いてしまいました。  
  把报告写完了。→ 强调彻底完成；也可能依语境带“竟然写完了”的情感。

## 不是每次都表示遗憾

「全部食べてしまいました」通常只是“全吃完了”。是否有遗憾，取决于上下文和语气。

# JLPT N4 提示

- 先判断上下文是“做完”，还是“发生了非本意的结果”。
- `～ちゃう／～じゃう`是「～てしまう／～でしまう」的口语缩约，常考识别和还原。
- 情感或身体反应与「～てしまう」搭配时，常表示“不由得……”。
