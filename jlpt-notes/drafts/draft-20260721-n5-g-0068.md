# 核心：ます形的用途

动词的「ます形」用于礼貌地陈述、提问或回答，常见于对不熟悉的人、老师、顾客或正式场合。

- 毎日、日本語を勉強します。——每天学习日语。（现在的习惯）
- 明日、友達に会います。——明天见朋友。（将来的安排）

「～ます」本身表示**非过去**，可表示现在的习惯或将来。相关礼貌形式：

| 形式 | 含义 | 例句 |
| --- | --- | --- |
| ～ます | 现在／将来肯定 | 行きます。——去。／会去。 |
| ～ません | 现在／将来否定 | 行きません。——不去。／不会去。 |
| ～ました | 过去肯定 | 行きました。——去了。 |
| ～ませんでした | 过去否定 | 行きませんでした。——没去。 |

说明：教材常把「読みます」整体称为“ます形”；严格说，前面的「読み」是**ます词干（连用形）**，可继续接「たい」「に行く」等表达，如「読みたい」「読みに行きます」。

# 三类动词：从辞书形变为ます形

| 类别 | 变换规则 | 例子 |
| --- | --- | --- |
| 第一类动词（五段） | 词尾的う段假名变为同行い段＋ます | 書く→書きます；話す→話します；読む→読みます；待つ→待ちます；買う→買います |
| 第二类动词（一段） | 去掉词尾「る」＋ます | 食べる→食べます；見る→見ます；起きる→起きます |
| 第三类动词（不规则） | 单独记忆 | する→します；来る（くる）→来ます（きます） |

## 第一类动词词尾变化表

| 辞书形词尾 | ます形词尾 | 例子 |
| --- | --- | --- |
| う | い＋ます | 買う→買います |
| つ | ち＋ます | 待つ→待ちます |
| る | り＋ます | 帰る→帰ります |
| く | き＋ます | 書く→書きます |
| ぐ | ぎ＋ます | 泳ぐ→泳ぎます |
| す | し＋ます | 話す→話します |
| ぬ | に＋ます | 死ぬ→死にます |
| ぶ | び＋ます | 遊ぶ→遊びます |
| む | み＋ます | 読む→読みます |

# 判断类别的要点

- 不是以「る」结尾的动词，基本都是第一类：書く、話す、読む等。
- 以「～る」结尾、且「る」前多为い段或え段的动词，很多是第二类：食べる、見る、起きる、教える。
- 但**不能只看「る」判断**。以下是常见的第一类「る」动词，必须记忆：  
  帰る、入る、走る、切る、知る、要る。
- 第三类只有「する」及其复合词（勉強する、運動する等），以及「来る」。

# 易错点与N5考点

- × 食べります　○ 食べます（第二类去「る」，不变「り」）
- × 読むます　○ 読みます（第一类把「む」变为「み」）
- × 来るます　○ 来ます（きます）
- 「行く」是第一类：行く→行きます。

# 自然例句

- 毎朝、コーヒーを飲みます。——每天早上喝咖啡。
- 週末は映画を見ません。——周末不看电影。
- 昨日、図書館へ行きました。——昨天去了图书馆。
