## 学习者原始输出

继续，て形+います有三种用法。1，表示动作正在进行。2，表示状态。3，表示习惯

## 对学习者理解的判断

理解正确。

- 「～ています」的三种基本用法是：动作进行中、某个动作后持续的结果状态，以及反复进行的习惯／职业。
- 对于「座る、住む、知る、結婚する」等动词，「～ています」多表示状态，而不是正在发生该动作。
- 「日系企業で中国語を教えています」可依语境表示“此刻正在教”，也可表示职业或日常工作；没有时间限定时，后者更常见。

## 待确认卡

# 核心

`动词て形＋います`可表示动作正在进行、当前持续的结果状态，以及反复进行的习惯或职业。

# 接续

动词て形＋いる／います

- 食べる → 食べています
- 座る → 座っています
- 住む → 住んでいます

# 三种基本用法

## 1. 动作正在进行

用于有持续过程的动作，表示说话时或某一基准时正在做。

- ご飯を食べています。  
  正在吃饭。
- 今、電話で話しています。  
  现在正在打电话。

## 2. 结果状态

表示某个动作已经发生，其结果状态持续到现在。瞬间动词用「～ています」时，常是此义。

- 椅子に座っています。  
  坐在椅子上。→ 已经坐下，现在处于坐着的状态。
- 大阪に住んでいます。  
  住在大阪。→ 现在持续居住的状态。
- 彼の名前を知っています。  
  知道他的名字。→ 获知后的状态。

## 3. 习惯、反复动作与职业

表示日常反复进行的事，也可说明长期从事的工作。

- 毎日日記を書いています。  
  每天写日记。
- 日系企業で中国語を教えています。  
  在日企教中文。→ 通常表示职业／经常做的工作。

# 易混项

## 进行与状态：看动词性质

| 形式 | 常见含义 |
| --- | --- |
| 食べています | 正在吃。→ 有过程的动作进行中。 |
| 座っています | 坐着。→ 坐下后的状态。 |
| 結婚しています | 已婚。→ 结婚后的状态。 |
| 死んでいます | 死了。→ 死亡后的状态，不是“正在死”。 |

## 与「～ます」

`～ます`可表示一般事实、习惯或将来；`～ています`则强调进行、持续状态或反复性。

- 毎日日記を書きます。  
  每天写日记。→ 说明习惯这一事实。
- 毎日日記を書いています。  
  每天都在写日记。→ 强调持续保持的习惯。

# JLPT N4 提示

- 先判断动词是有过程的动作，还是瞬间完成的动作；后者的「～ています」常表示结果状态。
- 有「毎日、いつも、週に～回」等频率词时，多表示习惯。
- 职业或长期活动常用「～ています」，例如「銀行で働いています」。
