## 待确认卡

# 核心

`动词て形＋おきます`表示为了之后的需要而有意识地预先处理某事，或使处理后的状态维持下去。

# 接续

动词て形＋おく／おきます

- 買う → 買っておきます
- 読む → 読んでおきます
- する → しておきます

# 三种常见用法

## 1. 事前措置：预先做好

在某个将来的活动、情况发生前，先做好准备。

- 旅行のまえに、お金を換えておきます。  
  旅行前先把钱换好。
- 会議の前に、資料をコピーしておきます。  
  开会前先把资料复印好。

## 2. 善后措置：事后作必要处理

某项活动结束后，主动完成应该做的收拾、归还或整理。

- 読み終わった本は、本棚に戻しておいてください。  
  看完的书请放回书架。
- 使ったコップは洗っておきます。  
  用过的杯子我会洗好收拾起来。

## 3. 善后放置：保持原状

为了之后还要使用等理由，主动不改变当前状态。常与「そのまま」搭配。

- あとで使いますから、机と椅子はそのままにしておいてください。  
  因为之后还要用，请把桌子和椅子保持原样。
- 窓は開けておいてください。  
  请让窗户开着。（维持打开的状态）

# 口语缩约

| 原形 | 口语形式 | 例句 |
| --- | --- | --- |
| `～ておく` | `～とく` | 買っておく → 買っとく |
| `～でおく` | `～どく` | 飲んでおく → 飲んどく |
| `～ておきます` | `～ときます` | 置いておきます → 置いときます |
| `～でおきます` | `～どきます` | 飲んでおきます → 飲んどきます |

缩约主要用于日常会话；正式场合或书面语通常使用完整形式。

# 易混项

## 与「～てある」

| 形式 | 重点 |
| --- | --- |
| `～ておく` | 有人有意地做出准备或保持某状态。 |
| `～てある` | 某个有意行为留下的结果状态。 |

- 会議の前に、資料を机の上に置いておきます。  
  开会前，我先把资料放在桌上。→ 强调准备动作。
- 資料が机の上に置いてあります。  
  资料放在桌上。→ 强调资料现在处于被放好的状态。

# JLPT N4 提示

- 有“为了之后”“预先准备”“保持原样”的语境时，考虑「～ておく」。
- 「そのままにしておく」表示有意地维持现状。
- 能辨认并还原`～とく／～どく`，例如「書いとく」＝「書いておく」。
