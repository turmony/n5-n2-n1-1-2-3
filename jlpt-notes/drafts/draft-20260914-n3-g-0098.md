# 核心与接续

## **A【动词条件形】＋よかった**

## **A【动词ない形去い】＋ければ＋よかった**

总接续聚焦原视频本课教授的两种后悔表达。肯定形式表示实际没有做A，事后认为当时应该做A；否定形式表示实际做了A，事后认为当时不该做A。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 肯定条件 | 动词条件形＋よかった | もっと早く予約すればよかった。 |
| 否定条件 | 动词ない形去「い」＋ければ＋よかった | あんなことを言わなければよかった。 |
| 口语缩约 | 动词ない形去「い」＋きゃ＋よかった | 買わなきゃよかった。 |

# 语义边界与适用条件

1. **以已经确定的事实为前提表达后悔。** 「～ばよかった」回头评价没有做的事，“当时要是做了就好了”；「～なければよかった」回头评价已经做的事，“当时要是没做就好了”。前项与事实相反。
2. **重点是事后的负面评价。** 句末虽有「よかった」，整句不是庆幸，而是认为实际选择不好。可伴随懊恼、遗憾、自责或抱怨。
3. **也可能指责他人。** 主语是对方时，「早く言えばよかった」等说法可能表示“你早说就好了”，带埋怨或非难；需结合语境判断，不一定只是说话人自责。
4. **否定形常缩约为「～なきゃよかった」。** 如课程例句「付き合わなきゃよかった」。这是「～なければよかった」的口语形式，语气直接，正式场合宜用完整形式。
5. **「～たらよかった／～なかったらよかった」近义。** 两组都能表达对过去的反事实后悔；考试重点是能从肯定／否定条件识别现实恰好相反。
6. **与「～てよかった／～なくてよかった」的事实方向相反。** 「勉強してよかった」表示实际学习了，并庆幸这么做；「勉強すればよかった」表示实际没有学习，并为此后悔。课程把前者作为“纳得”对照，不属于本课大号总接续。

# 例句

## 原视频例句

1. 若いうちにもっと勉強すればよかった。<br>
   年轻时要是更用功学习就好了。
2. 薬でこんなにすぐ良くなるなら、もっと早く病院へ行けばよかった。<br>
   早知道吃药这么快就会好，当时早点去医院就好了。
3. つまらない講演会だなあ…。来なければよかった。<br>
   真是无聊的演讲会啊……早知道就不来了。
4. はあ、あなたとなんか付き合わなきゃよかった。<br>
   唉，早知道就不该和你这种人交往。

# 易混项与 JLPT 考点

- **～てよかった**：实际做了A，并认为做得对或感到庆幸；「～ばよかった」则是实际没做A，因此后悔。
- **～なくてよかった**：实际没做A，并对此庆幸；「～なければよかった」则是实际做了A，因此后悔。否定形式相似，事实预设却相反。
- **～たらよかった／～なかったらよかった**：与本课两种形式近义，分别表达“当时做了就好／当时没做就好”。
- **～ばいいのに**：多表达当前未实现的愿望、带不满的建议；「～ばよかった」明确回顾已经过去的选择。
- **口语缩约**：「来なきゃよかった」＝「来なければよかった」。不要误解为“没来真好”；后者应是「来なくてよかった」。
