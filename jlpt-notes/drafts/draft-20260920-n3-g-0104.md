# 核心与接续

## **A【动词て形＋いる】＋つもり**
## **A【动词た形】＋つもり**
## **A【动词以外：普通形（な・の）】＋つもり**

按板书顺序逐行展开：上栏「動詞 て形 いる／た形」，下栏「動詞以外［普通形（な・の）］」，共同接「つもり」。A表示本人认定或假定的内容。「な・の」分别是な形容词和名词现在肯定形的特殊接续；不把动词辞书形混入本课总接续。

**核心：** 一是本人认为A成立，而实际情况或他人的看法不一定相同；二是明知并非A，仍把它当作A来行动。板书分别写「本人はAだと思っている（思っていた）が実際はAではない」「AではないがAだと思って」。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 动词 | 动词て形＋いる＋つもり | 頑張っているつもり；読んでいるつもり |
| 动词 | 动词た形＋つもり | 確認したつもり；生まれ変わったつもり |
| い形容词 | い形容词普通形＋つもり | 若いつもり；若くないつもり |
| な形容词 | な形容词词干＋な＋つもり | 得意なつもり |
| 名词 | 名词＋の＋つもり | 冗談のつもり |

「て形」已包含て／で，不再重复添加。「普通形」不是礼貌体：不用「確認しましたつもり」。な形容词和名词的「な・の」只替换现在肯定形的だ；否定和过去按普通形接，如「得意ではないつもり」「友達だったつもり」（外部接续展开，具体使用需有合理的主观认定语境）。い形容词本来不带だ。

句末可用「つもりだ／です／だった」，连接后项可用「つもりで／つもりでも／つもりだったが」。前项「確認した」表示认为已经完成确认，后项「つもりだった」表示过去曾有这种认定，两处时态不能混为一谈。

### 场景一：自己以为已经做到，实际结果却与认知有差距

**场景演示（自拟场景）：**
同事佐藤没有收到田中发来的资料，向田中确认邮件是否已经发送。

佐藤：昨日の資料、まだ届いていないんだけど。<br>
（昨天的资料还没收到呢。）

田中：送ったつもりだったけど、今見たら下書きに残っていた。すぐ送るね。<br>
（我以为已经发了，但刚一看，还留在草稿里。我马上发。）

### 场景二：明知事情并未发生，仍把它当作事实来行动

**场景演示（自拟场景）：**
两位朋友原本准备周末外出吃饭，后来决定省钱旅行，商量这笔餐费怎么办。

美咲：今週も外食をやめたら、その分のお金はどうする？<br>
（这周也不出去吃的话，省下的钱怎么办？）

健：外食したつもりで、旅行のために貯金しよう。<br>
（就当已经出去吃过了，把钱存下来旅行吧。）

# 语义边界与适用条件

1. **认知与事实／他人评价的差距。** 「確認したつもり」不保证已确认，也不保证确认得足够仔细。课程「気をつけているつもりでも」更不是说完全没有小心，而是自认足够小心仍可能发生事故。
2. **自我认定未必已被证伪。** 外部资料还讨论表达自己的认识，不强制后面出现反证。本课重点是差距，但不能将所有「つもり」理解成客观上必然相反。人称不是机械限制：既能说「私は…つもりだった」，也能评价或询问他人。
3. **假定用法并非记错。** 「生まれ変わったつもりで」明知没有真的重生，仍抱着重新开始的态度行动。「つもりで」也可以表示原本的认识或用意，如课程「冗談のつもりで言った」；不能见到で就一律判作假设。
4. **语气与人物关系。** 「あなたはいったい何様のつもりですか」是在责问“你以为自己是谁”，即使ですか也不属于礼貌询问。「何のつもりだ」责问用意，课程将其作为搭配补充，不另立释义场景。
5. **范围区别。** 动词辞书形＋つもりだ常表示未来打算，课程回顾了这一N4用法，但不属于本课主表。「死んだつもりで」可表达强烈决心（外部补充），属于假定用法的惯用表达，不表示真的死去。

# 例句与中文译文

以下照录04:00原视频例句页，中文为校对译文。

1. 気をつけているつもりでも、ちょっとした気の緩みで事故は起きるものです。<br>
（即使自认为已经很小心，稍一松懈也可能发生事故。）
2. 冗談のつもりで言った一言が相手を傷つけてしまった。<br>
（自认为是玩笑而说的一句话，却伤害了对方。）
3. 生まれ変わったつもりで一からやり直すと彼は誓った。<br>
（他发誓要当作重新获得生命一样，从头再来。）
4. あなたはいったい何様のつもりですか。<br>
（你到底以为自己是谁？）

板书补充例句（02:00）：英語は得意なつもりだったが、はじめてアメリカへ行ったとき、全然通じなかった。<br>
（原以为自己很擅长英语，第一次去美国时却完全无法让人听懂。）

# 易混项及 JLPT 考点

| 表达 | 区别与考点 |
|---|---|
| 送るつもりだ | 打算发送，着眼未来意志 |
| 送ったつもりだ | 自认为已经发出，不保证实际发出 |
| 外食したつもりで貯金する | 当作已花了餐费，实际上把钱存下 |
| ～ふりをする | 装出样子给别人看；つもり侧重本人认定或假定，不要求表演给别人看 |
| ～と思う | 广泛表达想法；つもり在本课突出认定与事实／评价之间的距离，或当作如此的态度 |

接续选择注意「得意なつもり」「冗談のつもり」，不能用「得意だつもり」「冗談だつもり」。阅读时结合后项反差辨别“打算”和“自认为”；「～つもりでも」本身不等于“没有做”。课程列N3，外部网站对自我认定用法有N2／N3两种教学分级，本卡依课程编号，不据此宣称统一官方分级。
