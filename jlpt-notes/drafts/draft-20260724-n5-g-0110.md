## 术语说明

图片中的词严格说不是“量词”（如「一冊」「三人」），而是表示**频度、程度和数量**的副词表达。它们放在动词、形容词或「あります」等谓语前，补充“多常、多少、多么”的信息。

## 待确认卡

# 频度・程度・量の表現

## ① 频度：做某事有多常

以「私はあのスーパーへ……行きます」为例：

| 表达 | 意思 | 例句 |
| --- | --- | --- |
| いつも | 总是、一直 | いつも行きます。 |
| よく | 经常 | よく行きます。 |
| ときどき | 有时、时常 | ときどき行きます。 |
| たまに | 偶尔 | たまに行きます。 |
| あまり～ない | 不太、很少 | あまり行きません。 |
| 全然～ない | 完全不、根本不 | 全然行きません。 |

大致频率：`いつも → よく → ときどき → たまに → あまり～ない → 全然～ない`。

## ② 程度：能力／理解程度

以「日本語が……わかります」为例：

| 表达 | 意思 | 例句 |
| --- | --- | --- |
| よく | 很好地、相当 | よくわかります。 |
| だいたい | 大致、基本上 | だいたいわかります。 |
| 少し | 一点、稍微 | 少しわかります。 |
| あまり～ない | 不太 | あまりわかりません。 |
| ほとんど～ない | 几乎不 | ほとんどわかりません。 |
| 全然～ない | 完全不 | 全然わかりません。 |

注意：「よく」在频度中是“经常”，在「よくわかります」中是“理解得很好”。

## ③ 数量：有多少

以「貯金が……あります」为例：

| 表达 | 意思 | 例句 |
| --- | --- | --- |
| たくさん | 很多 | たくさんあります。 |
| けっこう | 相当多、颇多 | けっこうあります。 |
| 少し | 一点、少量 | 少しあります。 |
| あまり～ない | 不太多 | あまりありません。 |
| ほとんど～ない | 几乎没有 | ほとんどありません。 |
| 全然～ない | 完全没有 | 全然ありません。 |

## ④ 程度：形容词的程度

以「この料理は……辛いです」为例：

| 表达 | 意思 | 例句 |
| --- | --- | --- |
| とても | 非常 | とても辛いです。 |
| けっこう | 相当、颇 | けっこう辛いです。 |
| 少し | 有一点 | 少し辛いです。 |
| あまり～ない | 不太 | あまり辛くないです。 |
| 全然～ない | 一点也不 | 全然辛くないです。 |

## 最重要的接续

`あまり／ほとんど／全然`在N5的标准用法中，通常与否定搭配：

- ○ あまり行きません。／あまり辛くないです。
- ○ ほとんどありません。／全然わかりません。
- × あまり行きます。／全然辛いです。  
  N5阶段不要这样使用。

相反，`いつも、よく、ときどき、たまに、だいたい、たくさん、けっこう、少し、とても`通常可接肯定句。

## 易混项

- **ときどき**比**たまに**更常发生；`たまに`频率更低。
- **だいたい**是“大体上、基本上”，不是“非常”。
- **けっこう**可表示“相当、颇”，也可能在别的语境中表示“够了／不用了”；本图中取“相当”。
- **少し**既能表示数量少，也能表示程度轻微。

## JLPT N5 要点

- 先记住否定组合：`あまり～ない／ほとんど～ない／全然～ない`。
- 根据语境判断副词功能：频度、程度或数量。
- 副词一般放在它所修饰的动词、形容词或谓语前。
