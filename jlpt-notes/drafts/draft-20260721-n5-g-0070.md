# 核心：什么是辞书形

辞书形是词典中查找动词时使用的基本形式。动词的辞书形也是**简体非过去肯定形**，可表示习惯、事实或将来：

- 毎日、日本語を勉強する。——每天学习日语。
- 明日、友達に会う。——明天见朋友。

辞书形常用于普通体会话，也会接在许多语法表达前。

# 三类动词的辞书形

| 类别 | 辞书形的特征 | 例子 |
| --- | --- | --- |
| 第一类动词（五段） | 以う段假名结尾；词尾可为「う・つ・る・く・ぐ・す・ぬ・ぶ・む」 | 書く、読む、話す、買う、待つ、帰る |
| 第二类动词（一段） | 辞书形通常以「る」结尾，前面多为い段或え段 | 食べる、見る、起きる、教える |
| 第三类动词（不规则） | 单独记忆 | する、来る（くる）；勉強する、運動する等复合词 |

## 第一类动词：直接认识辞书形词尾

| 辞书形词尾 | 例子 | 含义 |
| --- | --- | --- |
| う | 買う | 买 |
| つ | 待つ | 等待 |
| る | 帰る | 回去 |
| く | 書く | 写 |
| ぐ | 泳ぐ | 游泳 |
| す | 話す | 说 |
| ぬ | 死ぬ | 死亡 |
| ぶ | 遊ぶ | 玩 |
| む | 読む | 读 |

# 形容词和名词的辞书形（句末普通体）

| 类别 | 辞书形／句末简体 | 例子 |
| --- | --- | --- |
| 一类形容词（い形容词） | 高い | このかばんは高い。——这个包贵。 |
| な形容词 | 静かだ | この町は静かだ。——这个城市安静。 |
| 名词 | 学生だ | 私は学生だ。——我是学生。 |

一类形容词的辞书形本身以「い」结束；な形容词和名词在**句末普通体**中加「だ」。

# 易错点与N5考点

- 第一类动词的辞书形一定以う段假名结尾：  
  ○ 書く、読む、話す；× 書きる、読みる。
- 第二类动词的辞书形多以「る」结尾：  
  ○ 食べる、見る。
- 「来る」读作「くる」。
- 「きれい」是な形容词，句末普通体是「きれいだ」，不是「きれいい」。
- 名词和な形容词的「だ」不能直接放在名词前：  
  × 静かだ町　○ 静かな町；× 学生だ友達　○ 学生の友達。

# 自然例句

- 私は毎朝、新聞を読む。——我每天早上读报纸。
- この店の料理はおいしい。——这家店的菜好吃。
- 田中さんは親切だ。——田中很亲切。
