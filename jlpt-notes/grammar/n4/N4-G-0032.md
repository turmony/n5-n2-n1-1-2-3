# 核心

`动词ます形去ます＋おわります(終わります)`表示前项动作完成，即“做完……”。

前项通常是人能够有意识地进行、可以持续一段时间，并且有明确完成点的动作。

# 接续

动词ます形去ます＋おわります(終わります)

- 食べます → 食べおわります(食べ終わります)
- 読みます → 読みおわります(読み終わります)
- 書きます → 書きおわります(書き終わります)

`动词ます形去ます＋おえます(終えます)`也可以表示“做完……”。但相较于`～おわります(終わります)`，它相对不常用，略偏书面或正式表达；本课重点掌握`～おわります(終わります)`即可。

- ついに長編小説を書きおえました(書き終えました)。  
  终于写完了长篇小说。

# 自然例句

- ご飯を食べおわりました(食べ終わりました)。  
  吃完饭了。
- 宿題をやりおわりました(やり終わりました)。  
  做完作业了。
- この本を読みおわったら(読み終わったら)、貸します。  
  读完这本书后借给你。

# 不适合搭配的动作

## 瞬间完成的动作

- × 椅子に座りおわりました(座り終わりました)。

`座ります(座ります)`是瞬间完成的动作，一般不能理解为“坐完”。

## 非意志性的自然现象

- × 雨が降りおわりました(降り終わりました)。

下雨不是人有意识完成的动作。表示雨停止时，通常说：

- 雨が降りやみました(降りやみました)。  
  雨停了。

# 易混项

| 形式 | 含义重点 |
| --- | --- |
| `～はじめます(始めます)` | 开始做……，关注动作的起点。 |
| `～つづけます(続けます)` | 持续做……，关注动作延续。 |
| `～おわります(終わります)` | 做完……，关注动作完成。 |

- 本を読みはじめました(読み始めました)。  
  开始读书。
- 本を読みつづけています(読み続けています)。  
  一直在读书。
- 本を読みおわりました(読み終わりました)。  
  读完书了。

# JLPT N4 提示

- `～おわります(終わります)`接动词ます形去ます，不能直接接辞书形或て形。
- 前项多为阅读、书写、吃、做作业等可持续且有完成点的动作。
- 瞬间动作或自然现象一般不能机械地接`～おわります(終わります)`。
- `～おえます(終えます)`也表示完成，但相对不常用；考试和日常表达中优先掌握`～おわります(終わります)`。
