# 学习者原始输出

N4第99个语法：【普通形（な，）】+の+助词。表示の的形式名词的用法

# 核心

**`～の`是形式名词，可把前面的句子或动作变成一个“事情／行为”，再接助词或后续表达。**

`普通形（な，）＋の＋助词`

不能直接把动词句接在某些谓语前，需先用 `の` 名词化。

- × ケーキを作るが好きです。
- ○ ケーキを作るのが好きです。  
  喜欢做蛋糕。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + （の + 助词） | 読むのが |
| い形容词 | 普通形 + （の + 助词） | 難しいのは |
| な形容词 | 词干 + な（の + 助词） | 静かなのは |
| 名词 | 名词 + 助词 | 学生が |

名词本身可以直接接助词，不需要经过形式名词 `の`。

# 常见用法

| 形式 | 含义 | 例句 |
| --- | --- | --- |
| `～のが好きです` | 喜欢做…… | ケーキを作るのが好きです。 |
| `～のは～です` | 做……是…… | 日本語の新聞を読むのは難しいです。 |
| `～のを忘れます` | 忘记做…… | エアコンを消すのを忘れました。 |
| `～のに便利です` | 对做……很方便 | この辞書は、漢字の意味を調べるのに便利です。 |

# 语义边界

- `～の`：把具体动作、经历或事情当作一个名词来谈。
- `～のに便利です`中的 `に` 表示用途：“对做……很方便”。
- 不要和表示转折的 `～のに`（明明……却……）混淆。

# 与「こと」的区别

两者都能把动作名词化，但有固定搭配限制。

- `～のが好きです`：常用，强调具体动作。
- `～ことができます`：必须用 `こと`，不能换成 `の`。
- `～ことにします`：必须用 `こと`，不能换成 `の`。

# JLPT N4 提示

看到“动词句后要接 `が／は／を／に`”时，先判断是否要用形式名词 `の`：

- 読む**のが**好きです。
- 行く**のは**難しいです。
- 宿題をする**のを**忘れました。
- 日本語を勉強する**のに**便利です。
