# 学习者原始输出

N4第110个语法：【て形】/【ない形去い+くて】+も。表示逆接。

# 核心

**`A ても B`：即使 A，也 B／就算 A，也 B。**

前项 A 按常理本来可能影响后项 B，但实际上 B 仍然成立；表示让步、逆接关系。

# 接续

| 词类 | 肯定 | 否定 |
| --- | --- | --- |
| 动词 | て形 + も | ない形去 `い` + くて + も |
| い形容词 | て形 + も | ない形去 `い` + くて + も |
| な形容词 | 词干 + でも | 词干 + じゃなくても |
| 名词 | 名词 + でも | 名词 + じゃなくても |

- たべる(食べる) → たべても(食べても)／たべなくても(食べなくても)
- たかい(高い) → たかくても(高くても)／たかくなくても(高くなくても)
- べんり(便利) → べんりでも(便利でも)／べんりじゃなくても(便利じゃなくても)
- あめ(雨) → あめでも(雨でも)／あめじゃなくても(雨じゃなくても)

`じゃなくても`的较正式形式是 `ではなくても`。

# 基本用法

- たくさん食べても、太りません。  
  即使吃很多，也不会胖。
- 値段が高くても、買いたいです。  
  即使价格高，也想买。
- スマホは便利でも、使いません。  
  即使智能手机很方便，我也不用。
- 雨でも、試合をします。  
  即使下雨，也要比赛。
- 勉強しなくても、合格できます。  
  即使不学习，也能合格。
- この大学は、頭が良くなくても入れます。  
  即使不聪明，也能进这所大学。
- 交通が便利じゃなくても、ここに住みたいです。  
  即使交通不方便，我也想住在这里。
- この授業は、学生じゃなくても参加できます。  
  即使不是学生，也可以参加这门课。

# 语义边界

`～ても`的重点是：**A 成立也不会改变 B。**

- 雨が降ったら、試合をやめます。  
  如果下雨，就取消比赛。（普通条件：下雨会影响结果。）
- 雨でも、試合をします。  
  即使下雨，也要比赛。（让步：下雨不改变结果。）

# 易混项

| 形式 | 区别 |
| --- | --- |
| `～ても` | 即使 A，也 B；A 不改变 B。 |
| `～たら` | 如果 A，就 B；A 是 B 发生的条件。 |
| `～けど／～が` | 但是／虽然，单纯连接或对比前后句。 |
| `～のに` | 明明……却……，常带遗憾、不满或意外感。 |

# JLPT N4 提示

- `～ても`的后项可以接意志、愿望、请求、建议等表达：高くても買いたいです。
- 名词和な形容词现在肯定用 `でも`，不是 `～ても`。  
  ○ 雨でも  
  × 雨ても
- 不要把动词否定形写成 `～ないても`。  
  × 食べないても  
  ○ 食べなくても
