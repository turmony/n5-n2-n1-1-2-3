# 核心

- `～てもいいです`：可以……／即使……也没关系。
- `～てもかまいません`：含义相同，更正式、更客气，表示“……也无妨”。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | て形 + もいいです | 借りてもいいです |
| い形容词 | 去「い」+ くて + もいいです | 高くてもいいです |
| な形容词 | で + もいいです | 不便でもいいです |
| 名词 | で + もいいです | 明日でもいいです |

# 动词：许可

- その傘を借りてもいいですか。  
  我可以借那把伞吗？
- ここに座ってもかまいません。  
  坐在这里也没关系。

# 形容词、名词：接受条件

- 値段が高くてもいいです。  
  即使价格高也没关系。
- 交通が不便でもいいです。  
  即使交通不便也没关系。
- レポートは明日でもいいです。  
  报告明天交也可以。

# 易混项

- `借りてもいいですか`：我可以借吗？
- `貸してもいいですか`：我可以借给别人吗？  
  两者动作主体不同，不能混用。

- `田中さんに聞いてもいいですか`：我可以问田中先生吗？
- `田中さんに聞いたらどうですか`：问问田中先生怎么样？
- `田中さんに聞いたほうがいいです`：最好问田中先生。  
  前一句是询问许可；后两句是提出建议。

# JLPT N4 提示

- 动词接续时多表示许可。
- 非动词接续时多表示“即使处于该条件，也没关系”。
- `～てもかまいません`比`～てもいいです`更正式；日常会话中`～てもいいです`更常用。
