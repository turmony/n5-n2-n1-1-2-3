# 学习者原始输出

N4第104个语法：【普通形（な，名词词干）】+だけ。【动词辞书形/名词】+ばかり。表示只，仅仅。

# 核心

**`～だけ／～ばかり`表示限定，意为“只／仅仅”。**

- `だけ`：单纯、客观地限定范围。
- `ばかり`：除限定外，还常带“偏重、过多”或“只剩下……”等语感。

# 接续

| 形式 | 接续 |
| --- | --- |
| `～だけ` | 动词、い形容词普通形 + だけ；な形容词词干 + な + だけ；名词 + だけ |
| `～ばかり` | 名词 + ばかり；动词辞书形 + ばかり（常接 `だ`） |

# 基本用法

## 1. `～だけ`：单纯限定

- 十分だけ休みましょう。  
  只休息十分钟吧。
- お酒の中で、私はビールだけ飲みます。  
  酒当中，我只喝啤酒。
- この店の物は、安いだけで品質はよくない。  
  这家店的东西只是便宜，质量并不好。
- 店員：何かお探しですか。  
  客：いいえ、見ているだけです。  
  店员：您在找什么吗？  
  顾客：不，只是看看。

## 2. 名词 + `ばかり`：只限于某项

- 今回ばかりは、私も腹が立った。  
  唯独这一次，我也生气了。

## 3. 动词辞书形 + `ばかりだ`：只剩下……

表示该做的准备都已完成，之后只剩某件事。

- やることは全部やった。あとは結果を待つばかりだ。  
  该做的都做了，接下来只剩等结果。

# 「ばかり」的其他常见用法

| 用法 | 形式 | 含义与例句 |
| --- | --- | --- |
| 大概数量 | 数量 + ばかり | 相当于 `ぐらい`。<br>この道を百メートルばかり行くと、右に公園がある。<br>沿这条路走大约一百米，右边有公园。 |
| 偏重、偏向 | 名词 + ばかり／动词て形 + ばかりいる | 净是……；总是……，常带负面评价。<br>息子がゲームばかりして、困っています。<br>儿子净玩游戏，让我很烦恼。 |
| 刚完成 | 动词た形 + ばかりです | 刚刚……。<br>彼は先月うちの会社に入ったばかりです。<br>他上个月刚进我们公司。 |

# 与「しか～ない」的区别

| 形式 | 语气 |
| --- | --- |
| `だけ` | 只……，单纯限定；后项可肯定，也可否定。 |
| `しか～ない` | 除此以外没有……；必须接否定，常强调数量少或不足。 |

- 千円だけあります。  
  有一千日元。
- 千円しかありません。  
  只有一千日元。

# JLPT N4 提示

- `～だけ`可接多种词类；名词直接接 `だけ`。
- `动词辞书形 + ばかりだ`是“只剩下……”，不是“总是做……”。
- “总是／净是做……”用 `动词て形 + ばかりいる`。
- “刚刚做完……”用 `动词た形 + ばかりです`。
