# 核心

`名词Aより＋Bほうが＋C`表示比较：“比起 A，B 更 C”。

这里不固定给 B 添加`の`，因为 B 不一定是名词：

- `より`：表示比较的基准，“比起……”
- `ほう`：表示两者中的一方，“……这一边”
- `も`：可加在`より`后，加强“比起 A”的语气

基本形式：

- `AよりBほうがCです`
- `AよりもBほうがCです`

# 接续

B可以是名词、动词或形容词等普通形：

- 名词＋のほうが  
  米国**のほうが**大きいです。
- 动词普通形＋ほうが  
  電車で行く**ほうが**便利です。
- い形容词普通形＋ほうが  
  大きい**ほうが**いいです。
- な形容词＋なほうが  
  静か**なほうが**いいです。

这里的`【普通形（な，の）】`表示：

- **な形容词现在肯定形去`だ`加`な`**：静かだ → 静かなほう
- **名词现在肯定形去`だ`加`の`**：学生だ → 学生のほう

# 例句

- 英国よりも米国のほうが大きいです。  
  比起英国，美国更大。
- 電車よりバスのほうが安いです。  
  比起电车，公交车更便宜。
- 車で行くより、電車で行くほうが便利です。  
  比起开车去，坐电车去更方便。
- 静かなほうがいいです。  
  安静一点比较好。

# 其他表达方式

同样的比较也可以说：

- 米国は英国より大きいです。  
  美国比英国大。→ 以 B 为主题。
- 英国より米国のほうが大きいです。  
  比起英国，美国更大。→ 直接突出 B 这一方。

# 语义边界

`ほう`通常用于明确比较两个选项。只有一个对象、没有比较对象时，一般不使用`～より～ほうが`。

- この店は駅より近いです。  
  这家店离车站更近。
- 駅よりこの店のほうが近いです。  
  比起车站，这家店更近。→ 根据语境明确比较两方。

# 易混项

- `より`：比较基准
- `ほう`：被选中的一方
- `に比べて`：与……相比，语气更偏说明、书面

例如：

- 英国より米国のほうが大きいです。
- 英国に比べて、米国のほうが大きいです。

两句意思接近。

# JLPT N4 提示

- 看到`AよりBほうがC`，译为“比起 A，B 更 C”。
- 只有 B 是名词时使用`名词＋のほうが`。
- な形容词接`ほう`时使用`な形容词＋なほうが`。
- `よりも`中的`も`可以省略，不影响基本意思。
