# 学习者原始输出

N4第111个语法：【によると/によれば/の話しでは】+【普通形】+そうです。表示据说... 要注意其推测的用法：【动词ます形去ます/い形容词去い/な形容词】+そうです表示推测，名词+のようです表示推测

# 核心：传闻的「～そうです」

**`普通形 + そうです`：据说……／听说……。**

表示说话人从新闻、他人、资料等处获得的信息；不是自己亲眼观察后的判断。

信息来源常用：

`～によると／～によれば／～の話では、普通形 + そうです`

# 接续：传闻

| 词类 | 接续 |
| --- | --- |
| 动词 | 普通形 + そうです |
| い形容词 | 普通形 + そうです |
| な形容词 | 词干 + だそうです |
| 名词 | 名词 + だそうです |

- ニュースによると、犯人が逮捕されたそうです。  
  据新闻报道，犯人被逮捕了。
- 気象庁によれば、今年の夏は平年より涼しいそうです。  
  据气象厅说，今年夏天比往年凉爽。
- 友達の話では、中村先生は今でも元気だそうです。  
  据朋友说，中村老师现在也很健康。

# 重点区别：传闻与推测

`～そうです`有两种不同语法，接续和意思都不同。

| 类别 | 含义 | 接续 | 例句 |
| --- | --- | --- |
| 传闻 `～そうです` | 据说……／听说…… | 普通形 + そうです | 雨が降るそうです。<br>听说明天会下雨。 |
| 推测 `～そうです` | 看起来要……／看起来很…… | 动词ます形去 `ます`、い形容词去 `い`、な形容词词干 + そうです | 雨が降りそうです。<br>看起来要下雨了。 |

# 推测的表达

表示根据眼前的样子作出的判断：“看起来……／好像要……”。

| 词类 | 推测接续 | 例句 |
| --- | --- | --- |
| 动词 | ます形去 `ます` + そうです | 雨が降りそうです。<br>看起来要下雨了。 |
| い形容词 | 去 `い` + そうです | このケーキはおいしそうです。<br>这个蛋糕看起来很好吃。 |
| な形容词 | 词干 + そうです | 中村先生は元気そうです。<br>中村老师看起来很有精神。 |
| 名词 | 名词 + のようです | 独身のようです。<br>看起来好像单身。 |

名词不能直接接推测的 `そうです`，因此用 `名词 + のようです`。

- × 独身そうです。
- ○ 独身のようです。

# 易混对照

- 雨が降るそうです。  
  听说要下雨。（传闻：信息来自别人。）
- 雨が降りそうです。  
  看起来要下雨了。（推测：根据眼前情况判断。）
- この店の料理はおいしいそうです。  
  听说这家店的菜很好吃。
- この店の料理はおいしそうです。  
  这家店的菜看起来很好吃。
- 中村先生は元気だそうです。  
  听说中村老师身体很好。
- 中村先生は元気そうです。  
  中村老师看起来很有精神。

# JLPT N4 提示

- 传闻 `そうです`前用普通形；名词、な形容词要保留 `だ`：学生だそうです／便利だそうです。
- 推测 `そうです`前不能用普通形。  
  × 降るそうです（想表达“看起来要下雨”时）  
  ○ 降りそうです
- 传闻可有信息来源，也可省略来源；推测通常根据眼前观察作判断。
