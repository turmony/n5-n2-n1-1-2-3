# 核心

`くださいます`是`くれます`的尊敬表达，表示地位较高或需要尊敬的A给我／我方物品，或为我／我方做事。

`Aは Bに 名词＋を くださいます`  
`Aは Bに 动词て形＋くださいます`

A是施惠者，B是受惠者；B通常是说话者自己或说话者的我方成员。`くださいます`通过抬高A的行为来表达敬意。

# 接续

- 名词＋を くださいます
- 动词て形＋くださいます

# 例句

- 部長は私に英語を教えてくださいました。  
  部长教了我英语。
- 先生は私に本をくださいました。  
  老师给了我一本书。
- 先生がこの本をくださいました。  
  老师给了我这本书。

受惠者是说话者自己时，`私に`常可省略。

# 与「～てくれます」的区别

| 形式 | 施惠者A |
| --- | --- |
| `～てくれます` | 一般人或关系平等的人。 |
| `～てくださいます` | 老师、上司、长辈、客户等需要尊敬的人。 |

- 友達が日本語を教えてくれました。  
  朋友教了我日语。
- 先生が日本語を教えてくださいました。  
  老师教了我日语。

# 与「～ていただきます」的区别

两者都可描述“别人为我做事”，但视角不同。

| 形式 | 主语与敬意 |
| --- | --- |
| `先生が教えてくださいます` | 施惠者是主语；抬高老师。 |
| `私は先生に教えていただきます` | 受惠者是主语；谦逊地说自己得到帮助。 |

# 与「～てください」的区别

`～てください`是请求对方做事的固定表达；`～てくださいます`则是叙述对方为我／我方做事的尊敬表达。

- 教えてください。  
  请教我。

# 使用注意

- `くださいます`的受惠者通常是说话者自己、家人或说话者视为我方的人。
- 不用于“别人为第三方外人做事”的场合。
- 看到老师、上司等为我／我方做事时，优先考虑`～てくださいます`。
