# 核心

`动词辞书形 + つもりです`表示已有的打算或意图；`动词ない形 + つもりです`表示打算不做某事。

# 接续

- 动词辞书形 + つもりです
- 动词ない形 + つもりです
- 动词辞书形 + つもりはありません

# 基本用法

- 来年、日本へ留学するつもりです。  
  我打算明年去日本留学。
- 今日はどこへも行かないつもりです。  
  我打算今天哪儿也不去。
- 日本へ帰るつもりはありません。  
  我没有回日本的打算。

`～ないつもりです`是在做与不做之间，表达自己选择不做；`～つもりはありません`则直接否定“有做某事的打算”，通常语气更明确、坚决。常用形式为`つもりはありません`。

# 与「意向形＋と思う」的比较

| 形式 | 语感 | 例句 |
| --- | --- | --- |
| `动词辞书形＋つもりです` | 已形成、较明确的意图或计划 | 来年、日本へ留学するつもりです。 |
| `意向形＋と思っています` | 之前形成并持续到现在的想法／打算 | 来年、日本へ留学しようと思っています。 |
| `意向形＋と思います` | 此刻的想法或刚作出的决定 | 来年、日本へ留学しようと思います。 |

三者通常可理解为意图的明确度由高到低，但实际能否实现仍由条件和语境决定。

# 语境限制

在当场宣布现在开始做某事时，用`意向形＋と思います`最自然：

- ○ では、会議を始めようと思います。  
  那么，我想现在开始开会。
- △ 会議を始めるつもりです。  
  可用于说明事先的安排，但不适合此处当场宣布开始。
- △ 会議を始めようと思っています。  
  表示此前一直有此打算，不适合此处立刻开始的语境。

# 易混项

- `～たいです`强调愿望：“想做”；`～つもりです`强调已有意图或计划：“打算做”。
- `～つもりはありません`中的「は」用来突出否定；省略后虽可理解，但不如该形式自然、明确。
- `～ようと思っています`不只是“正在想”，而是此前的意向持续到现在。

# JLPT N4 提示

- 看到`つもりです`，优先判断为“打算／意图”。
- 看到`つもりはありません`，判断为“没有……的打算”，并注意其较强的否定语气。
- 需依据语境区分：早已形成的想法用`～ようと思っています`；当场决定用`～ようと思います`。
