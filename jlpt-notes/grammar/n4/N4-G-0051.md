# 核心

`Aは Bほど C（否定形）`表示比较：“A 没有 B 那么 C”。

`ほど`表示比较的程度，C 必须使用否定形式。

# 接续

- 名词 A は＋名词 B＋ほど＋C 的否定形式  
  今年のテストは去年ほど難しくないです。
- 名词 A は＋动词辞书形／た形构成的从句＋ほど＋C 的否定形式  
  この料理は期待したほどおいしくないです。

B 可以是名词，也可以是普通形动词构成的从句；不需要固定添加`の`。

# 例句

- 今年のテストは去年ほど難しくないです。  
  今年的考试没有去年那么难。
- 私は兄ほど上手に泳げません。  
  我没有哥哥那么擅长游泳。
- この店の料理は期待したほどおいしくなかったです。  
  这家店的菜没有期待中那么好吃。
- 彼はみんなが思うほど悪くないです。  
  他没有大家想象的那么坏。

# C 的否定形式

- い形容词：`難しい` → `難しくない`
- な形容词：`上手だ` → `上手ではない／上手じゃない`
- 名词判断：`学生だ` → `学生ではない／学生じゃない`
- 动词：`食べる` → `食べない`

例如：

- 私は兄ほど背が高くないです。  
  我没有哥哥那么高。
- この町は東京ほど便利ではありません。  
  这个城市没有东京那么方便。

# 与「～より～ほうが」的区别

- 東京は大阪より大きいです。  
  东京比大阪大。
- 大阪は東京ほど大きくないです。  
  大阪没有东京那么大。

两句表达的比较关系相近，但：

- `AよりBほうがC`：强调 B 更 C。
- `AはBほどCない`：强调 A 没有 B 那么 C。

# 语义边界

`ほど`后面的 C 必须是否定形式。这个句型表示 A 的程度低于 B，并不是说 B 也不具备 C 的性质。

# JLPT N4 提示

- 常见结构是`AはBほど～ない`。
- B 为名词时直接接`ほど`；B 为动词时，动词普通形构成从句后接`ほど`。
- C 必须使用相应的否定形式。
- 不要把本句型误解为“B 也不 C”；它表示 A 的程度没有达到 B 的程度。
