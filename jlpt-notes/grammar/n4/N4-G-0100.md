# 学习者原始输出

N4第100个语法：名词/动词辞书形+とか，名词/动词辞书形+とか表示举例。其中第二个とか可以省略。还扩展了其他的用法【普通形（だ，だ）】+とか可以表示不明确，不确定的信息和不相信，轻蔑

# 核心

**`～とか`主要表示随意举例：“……之类的／比如……”。**

此外，`普通形（だ・だ）＋とか`还可表示信息不明确、不确定的传闻，或带惊讶、不相信、轻蔑等情绪地提起某事。

# 接续

## 举例

`名词／动词辞书形 + とか、名词／动词辞书形 + とか`

第二个 `とか` 可以省略。

## 其他用法

`普通形（だ・だ）＋とか`

| 词类 | 接续 |
| --- | --- |
| 动词、い形容词 | 普通形 + とか |
| な形容词、名词 | だ + とか |

# 基本用法

## 1. 举例

随意列举多个事物或动作，暗示“还有别的”；语气比 `～や～など` 更口语化。

- スーパーで野菜とか牛乳とかを買いました。  
  我在超市买了蔬菜、牛奶之类的东西。
- スーパーで野菜とか牛乳を買いました。  
  我在超市买了蔬菜、牛奶之类的东西。  
  （第二个 `とか` 已省略。）
- 休みの日は、小説を読むとか、子供と遊ぶとかして過ごしています。  
  休息日会读小说、陪孩子玩之类地度过。

## 2. 不明确、犹豫

列出互相矛盾或不确定的内容，表示“说是……又说是……”，含有说法不清楚的语气。

- 彼を旅行に誘うと、行きたいとか、やっぱり行きたくないとか、いつもはっきりしない。  
  邀他去旅行时，他一会儿说想去，一会儿又说果然不想去，总是不说清楚。

## 3. 不确定的传闻

表示听来的、来源不明确的信息，相当于“听说……／据说……”。

- 朝、散歩するのは精神の健康にとてもいいとか。  
  听说早晨散步对心理健康很好。

## 4. 惊讶、不相信、轻蔑

将难以置信、不愿接受或轻视的内容作为话题提出；常和 `信じられない`、`嫌だ` 等表达一起使用。

- 全く運動しないで痩せられるとか、信じられない。  
  说什么完全不运动也能瘦下来，真让人难以相信。
- あんな人と一緒に仕事するとか、絶対に嫌です。  
  要和那种人一起工作什么的，我绝对不要。

# 易混项

| 形式 | 区别 |
| --- | --- |
| `～とか～とか` | 口语化、随意举例，可接名词或动词。 |
| `～や～など` | 列举同类事物，较客观、较正式。 |
| `～たり～たりする` | 列举反复或代表性的动作；动词要用 `た形`。 |
| `～とか`（句末） | 传闻来源不明，或带不相信、轻蔑等语气。 |

# JLPT N4 提示

- 名词举例：`野菜とか牛乳（とか）`。
- 动作举例：`読むとか遊ぶとかする`，使用辞书形，不要写成 `読んだとか`。
- な形容词、名词接“传闻／评价”等用法时保留 `だ`：便利だとか／医者だとか。
