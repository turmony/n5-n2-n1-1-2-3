## 三、出题规范

### 1. 排序题：唯一自然语序标准

- **JLPT 真题标准**：官方並べ替え每题只有一个语序答案；出现多个自然语序被视为出题缺陷。
- **本体系执行**：每道排序题出题后自检——四个语块的全部 24 种排列中，**仅一种**能构成自然句子；若存在第二种自然排列，必须更换语块或句式后才能定稿。
- 判卷仍沿用"完整句自然即判对"的学习者标准：如排出题库未预设的自然语序，判对并在报告中注明该题存在多解（此类题将修订）。

### 2. 状语排序规则（每套卷第二部分开头附"排序规则速览"）

1. **骨架语序**：主语は → 时间 → 场所 → 方式／对象等 → 宾语 → 动词（谓语永远句尾）。
   例：私は／明日／駅で／友達に／本を／返します。
2. **时间先于地点**：时间词（昨日・来週・午後の…）一般放句首侧；大时间在前，小时间在后。
3. **场所词组紧贴其动词**：「〜で／〜に／〜へ」不能离所属动词太远，更不能被别的动词"抢走"（如"容器に入れて、冷蔵庫にしまって"是两组"场所＋动词"小单位串联）。
4. **连体修饰必须前置**：修饰名词的句子（如「なくした財布」「母が編んだセーター」）整体放在名词前面、紧贴名词。
5. **目的紧贴行く／来る**：「手伝いに行く」「買い物に来る」中的「〜に」紧贴移动动词，不拆开。
6. **副词紧贴被修饰成分**：とても／だんだん／いつも 等放在它修饰的词前，位置相对灵活但不可隔断被修饰的动词或形容词。
7. **前提在前、细节在后**：话题、既知信息放前，新信息、具体补充放后。

### 3. 答案解析格式（每题）

- 正确项 ＋ 题目中文翻译 ＋ 考点（N4-G-XXXX 卡号与名称）＋ 正确接续（公式与本题具体变形，空格成分加粗）＋ 四个选项逐一解析；排序题另附推荐语序与逐块理由。

### 4. 判卷流程

- 回显映射表 → 学习者确认 → 计分 → 写入 `attempts.jsonl`（错题标签）→ 生成报告（**逐题全解析，七字段格式（题目／翻译／考点卡／答案／接续规则／意思／解析）见上文「判卷报告」节；正确信息引用正式卡片原文**）→ 提交 Git。

### 5. 题目查重（禁止重复出题）

- **同一考点允许再考**（覆盖卷与专项卷的既定机制），但**题干句子与语境不得与题库中已有题目相同或类似**：
  - 题干句子完全相同＝重复；
  - 仅替换个别名词／动词、句型框架与语境不变（换汤不换药）＝类似，同样禁止；
  - 例：「明日の会議のために、資料をコピーしておいた」与「明日の打ち合わせのために、資料を印刷しておいた」判为类似题。
- **执行方式**：每套卷定稿前运行查重脚本 `uv run python work/quiz_dedup_check.py --new-from <新题起始编号>`——新题题干与 `quizzes/questions/` 全部既有题卡逐一比对（按题型构造比对键：形式选择比整句、排序比框架＋语块集合、完形比整段文章并区分空格号），相似度 ≥0.72 判为「相同或类似」，必须重写语境后再入库。全库自检：`uv run python work/quiz_dedup_check.py`（2026-08-20 基线：全部通过）。
- 查重范围：N4-Q 与 N5-Q 全部题卡（含各卷已考题目）。

### 6. 题干冗余字符检查（空格与选项拼合，2026-08-20 新增）

- **规则**：题干空格与任一选项拼合后，接缝处不得出现重复字符——选项首字与空格前一字相同、或选项末字与空格后一字相同，均判为「多余字符」缺陷。
  - 例：选项为「ている」、题干为「（　）るです」→ 拼合为「ているるです」，「る」重复，判为缺陷；应改题干为「（　）です」或调整选项。
- **四个选项逐一检查**：干扰项同样不得与题干拼出重复字符（JLPT 干扰项均须可无痕代入题干）。
- **合法豁免**：「で＋で」为合法拼合（如「九時から七時（　）です」填「まで」＝までです），脚本自动豁免；其余接缝重复一律判缺陷。新增合法拼合模式须在脚本 `_LEGIT_JUNCTIONS` 表中登记。
- **执行方式**：`uv run python work/quiz_dedup_check.py --new-from <起始编号>` 在查重的同时自动运行接缝检查；`--junction-only` 单独运行接缝检查。发现缺陷必须修订题干或选项后才能入库。
- **2026-08-20 首次全库运行**：修复 6 处历史缺陷（N4-Q-0002/0058/0074/0153/0158/0175，均为选项末字或题干后字重复；修订不改选项号与正确项，既有作答记录不受影响）；N5-Q-0044「まで＋です」判合法。基线：245 张题卡全部通过。
