# 核心

`动词て形 + いきます`表示动作、现象或变化从说话人所在之处、当前时点向外离开或向后发展。

# 接续

动词て形＋いきます

- 寄る → 寄っていきます
- 飲む → 飲んでいきます
- 増える → 増えていきます

# 四种用法

## 1. 动作后再离开

- ちょっとコンビニに寄っていきます。  
  我去便利店顺路停一下再走。
- もう一杯飲んでいってください。  
  请再喝一杯再走。

重点是：在当前地点完成前项动作，然后离开此处。

## 2. 动作、现象向远处离开

- ランタンが空高く飛んでいきました。  
  灯笼朝高空飞走了。
- 先生が教室を出ていきました。  
  老师走出教室离开了。

## 3. 时间上的变化

- これから結婚しない人が増えていくでしょう。  
  从今以后不结婚的人会逐渐增加吧。  
  → 从现在向未来发展。
- 氷河期になって、恐竜の数は減っていった。  
  到了冰河期，恐龙的数量持续减少下去。  
  → 从过去某一时点向其后的时间发展。

## 4. 从现在持续到未来

- 私はこれからも台湾で日本語を教えていきます。  
  今后我也会继续在台湾教日语。

# 与「～てきます」的区别

| 形式 | 基本视角 |
| --- | --- |
| `～てきます` | 朝说话人／现在时点靠近。 |
| `～ていきます` | 从说话人／现在时点离开，向后发展。 |

- 寒くなってきました。  
  渐渐冷起来了。→ 过去至现在。
- これから寒くなっていくでしょう。  
  今后会渐渐变冷吧。→ 现在至未来。

# JLPT N4 提示

- 空间移动时，判断动作后是“返回这里”还是“离开这里”。
- 时间变化时，`ていく`关注变化继续向未来或某个基准点之后延伸。
- `～ていきます`常表达意志：今后会一直做下去。
