# 核心

`动词辞书形／ない形＋ようにします`表示为了达到某种目标而主动努力、注意或决定以后这样做，可译为“尽量做到……／努力使自己……”。

`动词辞书形／ない形＋ようにしています`表示平时持续有意识地坚持某个行为或避免某个行为，常译为“一直注意……／平时尽量……”。

# 接续

- 动词辞书形＋ようにします／ようにしています  
  `するようにします`、`食べるようにしています`
- 动词ない形＋ようにします／ようにしています  
  `飲まないようにします`、`使わないようにしています`

否定形式直接接动词的`ない形`；不是简单删除`ない`：

- `食べない＋ようにします` → 食べないようにします
- `使わない＋ようにしています` → 使わないようにしています

# 例句

- 毎日ジョギングをするようにします。  
  我以后会尽量每天慢跑。
- 野菜をたくさん食べるようにしています。  
  我平时一直注意多吃蔬菜。
- できるだけエレベーターを使わないようにしています。  
  我平时尽量不用电梯。
- 忘れないように、メモします。  
  为了不忘记，我会记笔记。→ 这里的`～ように`表示目的，不是`～ようにします`。

# 「ようにします」与「ようにしています」

| 形式 | 重点 | 例句 |
| --- | --- | --- |
| `～ようにします` | 今后努力做到、主动注意或作出行为调整 | 毎日早く起きるようにします。 |
| `～ようにしています` | 平时持续有意识地坚持，尚含有努力维持的语气 | 毎日早く起きるようにしています。 |

`～ようにしています`不只是客观说明“已经习惯”，而是强调说话人仍在有意识地维持这个习惯或目标。

# 易混项

- `毎日早く起きることにしました。`  
  我决定每天早起。→ 做出决定。
- `毎日早く起きるようにしています。`  
  我平时一直努力每天早起。→ 持续实践、注意维持。
- `毎日早く起きるようになりました。`  
  我已经变得每天早起了。→ 习惯已经发生变化。

# JLPT N4 提示

- `～ようにします`重点是主动努力、注意或今后的行为调整。
- `～ようにしています`重点是持续的有意识实践。
- `～ようになる`表示变化已经发生，不表示“努力去做”。
- `～ことにする`更偏向“作出决定”；`～ようにする`更偏向“努力做到”。
