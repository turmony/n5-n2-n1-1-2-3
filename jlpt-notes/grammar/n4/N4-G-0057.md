# 核心

`意向形＋と思います／と思っています`表示“打算……／想要……”。

- `意向形＋と思います`：现在刚作出的打算、当下的意向。
- `意向形＋と思っています`：之前就有这个打算，并且现在仍保持这个计划。

这里的`と`是引用助词。

# 例句

- 今後はちゃんと運動しようと思います。  
  今后我打算好好运动。→ 现在作出的决定。
- 新しい事業を始めようと思っています。  
  我打算创办新的事业。→ 之前就有这个计划，现在仍然打算实行。
- 来年、日本へ行こうと思っています。  
  我计划明年去日本。

# 意向形变化

- 五段动词：`読む` → `読もう`；`行く` → `行こう`
- 一段动词：`食べる` → `食べよう`
- 不规则动词：`する` → `しよう`；`来る` → `こよう`

# 与相关表达的区别

- `～ようと思います`：现在决定要做。
- `～ようと思っています`：从以前就有这个打算，并持续到现在。
- `～つもりです`：明确的计划或打算。

`～と思っています`强调意向一直存在，但不一定表示一定会执行。

# 与第56个语法的区别

- `普通形＋と思います`：认为、觉得、推测。  
  明日は雨が降ると思います。
- `意向形＋と思います`：打算做某事。  
  明日は早く起きようと思います。
