# 核心

`名词＋が します`表示能感觉到某种声音、气味、味道或主观感觉，即“有……的声音／气味／味道／感觉”。

这里的`します`不表示“做”，而是表示某种感觉或现象出现。

# 接续

名词＋が します

# 常见名词

| 类别 | 常见名词 | 含义 |
| --- | --- | --- |
| 听觉 | 音(おと)、声(こえ) | 有声音／听到声音。 |
| 嗅觉 | におい(匂い)、香り(かおり) | 有气味／香味。 |
| 味觉 | 味(あじ) | 有……味道。 |
| 感觉、印象 | 感じ(かんじ)、気(き) | 有……感觉；觉得……；有某种心情或意愿。 |

# 例句

## 听觉

- 大きな音がしました。  
  有很大的声音。
- 隣の部屋から声がします。  
  从隔壁房间传来声音。

## 嗅觉与味觉

- 焼き肉のにおいがします(匂いがします)。  
  有烤肉的气味。
- 花の香りがします。  
  有花香。
- この牛乳は変な味がします。  
  这牛奶有奇怪的味道。

## 感觉、印象与心情

- 東京タワーを見ると、東京に来たという感じがします。  
  看到东京塔，就有一种“来到东京了”的感觉。
- あなたとはどこかで会ったような気がします。  
  我觉得好像在哪里见过你。
- 今日は出かける気がしません。  
  今天没有想出门的心情／不想出门。

# 易混项

| 形式 | 含义 |
| --- | --- |
| `音がします` | 听得到声音／有声音。 |
| `音を出します(出します)` | 弄出声音、发出声音。 |
| `気がします` | 说话人的直觉、感觉或推测。 |
| `感じがします` | 对事物产生的感觉或印象。 |

`～が します`中的名词通常是感觉的内容或来源，因此使用`が`，不能机械地改为`を`。

# JLPT N4 提示

- `音(おと)・声(こえ)・におい(匂い)・香り(かおり)・味(あじ)`常与`～が します`搭配。
- `気がします`、`感じがします`常表达主观印象，不等于已经确认的客观事实。
- `今日は出かける気がしません`是固定且自然的说法，表示“今天不想出门”。
