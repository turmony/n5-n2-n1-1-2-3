# 核心

`疑问词＋（助词）＋でも＋B`表示全面肯定，即“无论什么、谁、哪里、什么时候都……”。这里的B必须使用肯定形式。

# 接续

- 疑问词＋`でも`＋肯定形式：`何でも`、`誰でも`、`いつでも`、`どこでも`
- 疑问词后的助词有时保留：`どこへでも`、`どこにでも`、`誰とでも`

# 例句

- 私は嫌いな食べ物はありません。何でも食べられます。  
  我没有讨厌的食物，什么都能吃。
- 彼はやさしい性格で、誰とでも仲良くできます。  
  他性格温和，和谁都能相处得很好。
- いつでも電話してください。  
  请随时打电话。
- どこへでも行けます。  
  哪里都能去。

# 与全面否定的区别

- `何でも＋肯定`：什么都……
  - 何でも食べます。——什么都吃。
- `何も＋否定`：什么都不……
  - 何も食べません。——什么都不吃。

`誰でも`表示“谁都……”，而`誰も＋否定`表示“谁也不……”。

# 易错点

- `でも`形式后面的B不能使用否定形式来表达本语法的全面肯定。
- 助词并非一律删除：`どこでも`中常省略助词，但`どこへでも`、`どこにでも`、`誰とでも`可以保留助词。
- `どこへでも行けます`表示“哪里都能去”；地点选择的疑问句不能机械地改成这一形式。

# JLPT N4 提示

- 全面肯定：`疑问词＋（助词）＋でも＋肯定`。
- 全面否定：`疑问词＋（助词）＋も＋否定`。
- 判断关键是`でも`与肯定谓语搭配，还是`も`与否定谓语搭配。
