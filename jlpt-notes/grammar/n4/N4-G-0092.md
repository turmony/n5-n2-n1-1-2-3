# 学习者原始输出

动词た形+ばかりです。表示刚刚做了... 类似的语法还有【动词た形+ところです】，但是只有前者可以用于两三分钟前做过的事情，类似于日语中”直後“的意思

# 核心

`动词た形 + ばかりです` 表示“刚刚做完……／才……不久”。

这里的“刚”不是严格的客观时间，而是说话人主观上觉得“从那件事发生到现在还不久”。因此可以指几分钟前，也可以是几天、几周，甚至数月前的事。

# 接续

- `动词た形 + ばかりです`
- `动词た形 + ばかりの + 名词`

# 基本用法

- さっき、ご飯を食べたばかりです。  
  刚才刚吃完饭。
- この電子辞書は先週買ったばかりなのに、もう壊れてしまいました。  
  这本电子词典上周才买，已经坏了。
- 彼は今年入社したばかりの社員です。  
  他是今年刚入职的员工。

# 与「～たところです」的区别

| 形式 | 时间感觉 | 特点 |
| --- | --- | --- |
| `～たばかりです` | 主观上觉得“不久前” | 时间范围较宽；可表示几分钟前、几周前，甚至更久前的“刚” |
| `～たところです` | 动作刚结束的直后 | 强调客观上“刚刚、正好结束”，通常是说话时的前一刻或极短时间内 |

- バスはたった今、出たところです。  
  公交车刚刚开走。强调刚开走的那一刻。
- バスはたった今、出たばかりです。  
  公交车刚刚开走。也正确，表示开走不久。
- 彼は今年の4月に入社したばかりです。  
  他是今年四月刚入职的。即使距离四月已有一段时间，只要说话人认为还算“不久”，仍可使用。
- × 彼は今年の4月に入社したところです。  
  如果距四月已过了较久，这种说法不自然；`ところ` 不适合表示较长时间前的事情。

# 语义边界

- `～たばかり` 不等于绝对“几分钟前”。`先週買ったばかり`、`今年入社したばかり` 都可以成立。
- `～たところ` 强调动作完成的瞬间或紧接着的状态，接近“直後”。
- `～たばかりの + 名词` 可修饰名词：入社したばかりの社員（刚入职的员工）。

# 易混点

- `食べてばかりいる`：总是在吃，表示偏重、反复做。  
  `食べたばかりです`：刚吃完，表示时间短。

两者的 `ばかり` 用法不同，不能混淆。

# JLPT N4 提示

- 题目出现“刚刚完成，且强调眼前的直后”，优先考虑 `～たところです`。
- 出现“上周、今年、前不久”等时间，但说话人仍认为时间不长，优先考虑 `～たばかりです`。
- `～たばかりの + 名词` 表示“刚……的……”。
