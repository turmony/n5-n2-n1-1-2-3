# 核心

- `～てはいけません`：不可以……／禁止……
- `～てはだめです`：不行……／不可以……；语气较口语、直接。
- `～てはなりません`：不可以……；较书面、正式，使用较少。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | て形 + はいけません／はだめです | 吸ってはいけません |
| い形容词 | 去「い」+ くては… | 悪くてはいけません |
| な形容词 | で + は… | 下手ではだめです |
| 名词 | で + は… | コーヒーではだめです |

# 动词：禁止

- たばこを吸ってはいけません。  
  不可以吸烟。
- お酒を飲んではいけません。  
  不可以喝酒。

# 形容词、名词：不可接受的条件

- 品質が悪くてはいけません。  
  质量不好是不行的。
- 歌が下手ではだめです。  
  唱歌不好是不行的。
- コーヒーではだめです。  
  咖啡不行。  
  → 例如对方需要的是茶，而不是咖啡。

# 口语缩约

| 原形 | 口语缩约 |
| --- | --- |
| 食べてはいけない | 食べちゃいけない |
| 吸ってはいけない | 吸っちゃいけない |
| 飲んではいけない | 飲んじゃいけない |
| 学生ではだめです | 学生じゃだめです |

- ここで写真を撮っちゃだめです。  
  不可以在这里拍照。

# 易混项

- `～てはいけません`：规则、禁令，“不可以做”。
- `～ないでください`：请求对方不要做，“请不要做”。  
  ここで写真を撮らないでください。  
  请不要在这里拍照。

# JLPT N4 提示

- `ては`在口语中常缩约为`ちゃ`，`では`常缩约为`じゃ`。
- `～てはなりません`比`～てはいけません`更正式、书面。
- 遇到形容词、名词时，应理解为“该状态／条件不被接受”，不必强行翻译成动作禁止。
