# 核心

`动词た形 + ことがあります`表示“有过……的经历／曾经做过……”。

# 接续

接续：动词た形＋ことがあります

- 行く → 行ったことがあります
- 食べる → 食べたことがあります
- 見る → 見たことがあります

# 基本例句

- アメリカへ行ったことがあります。  
  我去过美国。
- 日本で納豆を見たことがあります。  
  我在日本见过纳豆。

# 助词替换

| 形式 | 语感 |
| --- | --- |
| `～たことがあります` | 中性地陈述有该经验。 |
| `～たことはあります` | 强调或对比：“……倒是有过”。 |
| `～たこともあります` | 补充：“也有过……”。 |

- 納豆を食べたことはありません。  
  纳豆我没吃过。
- 納豆を食べたこともあります。  
  我也吃过纳豆。

# 否定

- ～たことがありません：没有做过……
- 一度も～たことがありません：一次也没有做过……

# 语义边界

此句型强调“某项值得提出的过去经验”，常用于旅行、尝试、特殊见闻等。

- ○ アメリカへ行ったことがあります。  
  去美国可作为一项经历提出。
- △ デパートへ行ったことがあります。  
  单独说“去过百货商店”通常缺少特别意义；若有特定限定则自然：  
  日本のデパートへ行ったことがあります。  
  我去过日本的百货商店。

# 易混项

- `～たことがあります`：曾经做过一次或多次，重点是“经验”。
- `～ることがあります`：有时会做……，重点是“偶尔发生”。  
  電車が遅れることがあります。  
  电车有时会晚点。

# JLPT N4 提示

- 「こと」前必须接动词た形。
- `が`可替换为`は`或`も`，分别体现强调／对比和“也”的附加意义。
- 注意与`动词辞书形＋ことがあります`的“有时会……”区别。
