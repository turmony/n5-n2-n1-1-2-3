# 核心

`～すぎます`表示“过于……／太……”，说明动作或状态超过正常、合适的程度。标准基本形是`～すぎる`，属于动词。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | ます形去ます + すぎます | 食べすぎます |
| い形容词 | 去「い」+ すぎます | 高すぎます |
| な形容词 | 去「な」+ すぎます | にぎやかすぎます |

- 食べすぎます。  
  吃得太多。
- このホテルは高すぎます。  
  这家酒店太贵。
- この町はにぎやかすぎます。  
  这个城镇太热闹了。

# 「ない」的特殊变化

`ない`接`すぎます`时，变为`なさすぎます`。

## 名词不是直接接续对象

`責任感`是名词，不是な形容词。完整构造如下：

`責任感 が ない` → `責任感 が なさすぎます`

- `責任感`：名词，“责任感”。
- `が`：标记“责任感”这一对象。
- `ない`：い形容词，“没有”。
- `ない → なさすぎます`：太没有……。

因此，`すぎます`并不直接接在名词「責任感」后面；`×責任感すぎます`不成立。它接的是形容词「ない」。

- 責任感がなさすぎます。  
  太没有责任感。

若原本是い形容词的否定形，保留前面的`く`：

- 高くない → 高くなさすぎます。  
  太不贵了／价格低得过头。

# 重要辨析

| 形式 | 含义 |
| --- | --- |
| 食べすぎません | 不吃得过多／并非吃得过多。 |
| 食べなさすぎます | 吃得太少。 |

前者是否定“过度”，后者是“不做得过度”，即数量或程度不足。

# 易混项

- `いい`接续时用`よすぎます`，不是`いすぎます`。  
  この映画はよすぎます。  
  这部电影太好了。
- `～すぎです`可在口语中听到，但考试和规范表达优先使用`～すぎます`。

# JLPT N4 提示

- 动词接ます形去掉「ます」后的词干。
- い形容词去「い」，な形容词去「な」。
- 看到“太少／不够”时，重点辨认`～なさすぎます`，不要误写成`～なすぎます`。
