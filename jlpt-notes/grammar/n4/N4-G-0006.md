# 核心

`动词ます形去ます + にくいです`表示“难于……／不容易……”。`～にくい`整体是一个い形容词。

# 接续

- 書きます → 書きにくいです
- 食べます → 食べにくいです
- 分かります → 分かりにくいです

# 两类常见含义

## 1. 动作难以进行

- このボールペンは書きにくいです。  
  这支圆珠笔不好写。

## 2. 某种情况不容易发生

- このコップは割れにくいです。  
  这个杯子不容易碎。

这不是说杯子绝对不会碎，而是说它有不容易破碎的性质或倾向。

# 活用

`～にくい`按い形容词活用：

| 形式 | 例句 |
| --- | --- |
| 现在肯定 | このペンは書きにくいです。 |
| 现在否定 | このペンは書きにくくないです。 |
| 过去肯定 | このペンは書きにくかったです。 |
| 过去否定 | このペンは書きにくくなかったです。 |

# 与「～やすい」的对比

| 形式 | 含义 | 例句 |
| --- | --- | --- |
| `書きやすい` | 容易写／好写 | このペンは書きやすいです。 |
| `書きにくい` | 难写／不好写 | このペンは書きにくいです。 |
| `割れやすい` | 容易碎 | このコップは割れやすいです。 |
| `割れにくい` | 不容易碎 | このコップは割れにくいです。 |

# JLPT N4 提示

- 接动词ます形去掉「ます」后的词干。
- `にくい`整体按い形容词活用。
- 常可理解为`～するのが難しい`或`なかなか～ない`，但`～にくい`更紧凑自然。
