# 核心

`动词辞书形＋ことが あります`表示“有时会……／偶尔会……”。

`动词ない形＋ことが あります`表示“有时不……／偶尔不……”。

它说明的是一般性的、反复但不经常发生的情况，不是说明某一次具体经历。

# 接续

动词辞书形＋ことが あります  
动词ない形＋ことが あります

- 止まります → 止まることが あります
- 眠れます → 眠れないことが あります
- 食べます → 食べないことが あります

# 例句

- このパソコンは使用中に突然止まることがあります。  
  这台电脑使用时有时会突然停止。
- 最近、夜になっても眠れないことがあります。  
  最近有时到了晚上也睡不着。
- 忙しくて、朝ご飯を食べないことがあります。  
  因为忙，有时不吃早饭。
- 電車が遅れることがあります。  
  电车有时会晚点。

# 与「～たことが あります」的区别

| 形式 | 含义 |
| --- | --- |
| `动词た形＋ことが あります` | 曾经有过……的经历。 |
| `动词辞书形／ない形＋ことが あります` | 有时会……／偶尔不……。 |

- 日本へ行ったことがあります。  
  我曾去过日本。→ 经历
- 日本へ行くことがあります。  
  有时会去日本。→ 偶尔发生的情况

# 易混项

`ときどき`、`たまに`也表示“有时／偶尔”，可以和本句型一起使用。

- たまに、電車が遅れることがあります。  
  电车偶尔会晚点。

`～ことが あります`本身已经包含“偶尔发生”的意思，不必每次都加这些副词。

# JLPT N4 提示

- 本句型使用动词辞书形或ない形；不要与表示经历的`动词た形＋ことが あります`混淆。
- 常用于机器故障、天气、身体状态、日常习惯等偶发或偶尔出现的事情。
- 否定形式是`～ないことが あります`，意思是“有时不……”。
