# 核心

`动词ます形去ます＋つづける(続ける)`表示前项动作、变化或状态在一段时间内不断延续，即“一直……”“持续……”。

它也可表示长期持续进行的行为；在合适语境下，这类行为可以体现为习惯，但重点仍是“持续未中断”。

# 接续

动词ます形去ます＋つづける(続ける)

- 食べます → 食べつづけます(食べ続けます)
- 歩きます → 歩きつづけます(歩き続けます)
- 降ります → 降りつづけます(降り続けます)
- 増えます → 増えつづけます(増え続けます)

# 主要用法

## 1. 动作的持续

表示某个动作不断进行，没有停下来。

- 今日は朝から晩まで歩きつづけて、足が痛いです。  
  今天从早走到晚，所以脚很疼。
- 彼は二時間話しつづけました。  
  他连续说了两个小时。
- 子どもが泣きつづけています。  
  孩子一直在哭。

## 2. 变化的持续

表示某种变化一直朝同一方向继续发展。

- お正月から今まで、ずっと体重が増えつづけています。  
  从新年到现在，体重一直在增加。
- この町の人口は減りつづけています。  
  这个城镇的人口持续减少。

## 3. 长期持续的行为／习惯

表示某人从过去开始一直持续做某事。若该行为反复、长期发生，也可以表现为习惯。

- 私は二十歳から今まで、タバコを吸いつづけています。  
  我从二十岁到现在一直抽烟。
- 毎日、日本語を勉強しつづけています。  
  我每天持续学习日语。

# 与「～ている」的区别

| 形式 | 重点 | 例句 |
| --- | --- | --- |
| `～ています` | 正在进行，或处于某种状态 | 食べています。＝正在吃。 |
| `～つづけています(続けています)` | 从之前开始一直延续，强调不停或持续时间 | 食べつづけています(食べ続けています)。＝一直不停地吃。 |

`～つづける(続ける)`不能只表示某个瞬间的动作；它必须有“延续”的时间感。

# 易混项

| 形式 | 含义重点 |
| --- | --- |
| `～はじめます(始めます)` | 开始做……，关注起点。 |
| `～つづけます(続けます)` | 持续做……，关注过程未停止。 |
| `～おわります(終わります)` | 做完……，关注终点。 |

- 雨が降りはじめました(降り始めました)。  
  开始下雨了。
- 雨が降りつづけています(降り続けています)。  
  雨一直下个不停。
- 雨が降りおわりました(降り終わりました)。  
  雨下完了／雨停了。

# JLPT N4 提示

- `～つづける(続ける)`接动词ます形去ます，不能直接接辞书形或て形。
- 常与`ずっと`、`～から～まで`、`今まで`等表示持续时间的词语搭配。
- `雨が降りつづけています(降り続けています)`、`人口が増えつづけています(増え続けています)`分别体现动作和变化的持续。
- 长期行为的例句中，`～つづける(続ける)`强调“持续”，不要简单等同于“有……习惯”。
