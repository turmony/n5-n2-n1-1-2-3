# 核心

`动词て形 + きます`表示动作、现象或变化朝说话人所在之处、说话时点靠近。

# 接续

动词て形＋きます

- 食べる → 食べてきます
- 飛ぶ → 飛んできます
- 増える → 増えてきます

# 四种用法

## 1. 动作后再返回

- 昼ご飯を食べてきました。  
  我吃完午饭过来了／回来后已经吃过午饭了。
- ちょっと飲み物を買ってきます。  
  我去买点饮料再回来。

重点是：先完成“吃／买”，再朝说话人当前所在处返回。

## 2. 动作、现象向说话人靠近

- ボールがこちらに飛んできました。  
  球朝这边飞来了。
- 電話がかかってきました。  
  电话打过来了／来电话了。

## 3. 时间上的变化

- 最近ずいぶん寒くなってきました。  
  最近渐渐冷起来了。  
  → 从过去变化到现在。
- 売り上げはだんだん増えてくるでしょう。  
  销售额今后会逐渐增加吧。  
  → 从现在或某个未来基准点开始，朝更远的未来发展。

## 4. 从过去持续到现在

- 私は台湾で20年間、日本語を教えてきました。  
  我在台湾教日语已有二十年。  
  → 教日语这一动作从过去持续至今。

# 与「～ていきます」的区别

| 形式 | 基本视角 |
| --- | --- |
| `～てきます` | 朝现在／说话人方向靠近。 |
| `～ていきます` | 从现在／说话人方向离开、向后发展。 |

- これからもっと暑くなっていくでしょう。  
  今后会越来越热吧。  
  → 从现在朝未来发展。

# JLPT N4 提示

- 空间移动时，判断动作完成后是“回来”还是“离开”。
- 时间变化时，重点判断变化是趋向现在，还是从现在向未来延伸。
- `～てきました`常用于概括“从过去一直做到现在”的经历。
