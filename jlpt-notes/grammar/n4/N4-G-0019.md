# 核心

`动词辞书形／ない形 + ことになります`表示“决定要……／决定不……／结果成为……”。

强调决定来自外部、组织安排、双方协商或事情发展的结果，而非说话人单方面作出的选择。

# 接续

- 出場する → 出場することになります
- 吸わない → 吸わないことになります

# 基本例句

- 柔道の代表としてオリンピックに出場することになりました。  
  已决定作为柔道代表参加奥运会。  
  → 代表选拔、组织安排等作出的决定。
- 私たちは6月に結婚することになりました。  
  我们决定在六月结婚。  
  → 经双方或相关安排后，婚事成为既定事项。
- 来月から大阪支社で働くことになりました。  
  已决定我从下个月起在大阪分公司工作。  
  → 常暗示公司或组织作出安排。

# 与「～ことにします」的区别

| 形式 | 决定的来源 |
| --- | --- |
| `～ことにします` | 说话人自己主动决定。 |
| `～ことになります` | 他人、组织、双方协商、客观情况等决定的结果。 |

- 明日からたばこを吸わないことにしました。  
  我决定从明天开始不抽烟。  
  → 自己作出的决定。
- 寮ではたばこを吸わないことになりました。  
  已规定宿舍里不抽烟。  
  → 宿舍规则或管理方作出的决定。

# 语义边界

「明日からたばこを吸わないことになりました」若要表达“我自己决定戒烟”，不自然，应使用`ことにしました`。

但若主语是团体规定、公司规定或宿舍规则，该形式可以成立。

# JLPT N4 提示

- `ことになりました`常表示“已经决定下来”。
- 表示未来安排时，也常用现在式：  
  来月から転勤することになります。  
  将被安排从下个月起调职。
- 判断关键：自己单独决定用`ことにします`；外部或共同安排用`ことになります`。
