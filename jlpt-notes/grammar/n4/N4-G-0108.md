# 学习者原始输出

N4第108个语法：た形+り，た形+り。表示：1，反复动作。2，不一定

# 核心

**`～たり～たり`：有时……有时……／……来……去／做做……之类的。**

常用于：

1. **反复动作**：两个相反、交替或往复的动作反复发生。
2. **不一定、状态不稳定**：有时做 A，有时不做 A；有时是 A，有时不是 A。
3. **动作举例**：列举代表性的动作，表示“做……之类的”。

# 接续

- 动词た形 + り、动词た形 + り
- 动词た形 + り、动词なかった形 + り

后面常接 `する／します`，也可接 `だ／です／している`等。

# 基本用法

## 1. 反复动作

表示两个动作交替、往复或反复发生。

- 今日は一日中、雨が降ったりやんだりしています。  
  今天一整天，雨时下时停。
- 仕事の関係で、最近は東京と大阪を行ったり来たりの日々だ。  
  因为工作关系，最近每天在东京和大阪之间来来往往。
- マラソン終盤は、田中選手と鈴木選手が抜いたり抜かれたりの大接戦を見せた。  
  马拉松后半段，田中选手和铃木选手你超我、我超你，展开了激烈竞争。

## 2. 不一定／不稳定

常用“肯定 + 否定”的形式，表示某事不是固定如此，而是时有时无、忽好忽坏。

- 朝は時間がなくて、朝ご飯は食べたり食べなかったりです。  
  早上没时间，早饭有时吃、有时不吃。
- 私が作る料理は、おいしかったりおいしくなかったりで、味が安定しない。  
  我做的菜有时好吃、有时不好吃，味道不稳定。

## 3. 动作举例

列举几个代表动作，不表示只做这些；常接 `～たりします`。

- 休みの日は、子供と遊んだり、映画を見に行ったりします。  
  休息日会陪孩子玩、去看电影之类的。

# 语义边界

- `た形`中的 `た`只是构成 `たり`的形式，不一定表示过去。  
  雨が降ったりやんだりしています表示现在正在时下时停。
- `～たり～たりする`不强调动作顺序，也不表示列举完整。
- 如果要按实际顺序叙述连续动作，使用 `～て～て`。

  朝起きて、顔を洗って、朝ご飯を食べます。  
  早上起床、洗脸、吃早饭。

# JLPT N4 提示

- “有时做、有时不做”优先使用：动词た形 + り、动词なかった形 + り。
- “来来回回、时下时停”优先使用：动词た形 + り、动词た形 + り。
- “做……之类的”常用：`～たり、～たりします`。
- 不要写成辞书形。  
  × 食べるり、食べないり  
  ○ 食べたり、食べなかったり
