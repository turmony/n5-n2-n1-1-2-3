# 核心

尊敬语用于抬高老师、上司、客人等应受尊敬者的动作。图片总结了四种主要的尊敬表达：尊敬形、`お／ご～になります`、`お／ご～です`以及专用尊敬语。

# 1. 尊敬形

使用与受身形相同的`～れる／～られる`，详细变形见第76张卡。

- 飲みます→飲まれます
- 待ちます→待たれます
- します→されます
- 出席します→出席されます

# 2. お／ご～になります

## 接续

- `お＋动词ます形去ます＋になります`
- `ご＋动作性名词＋になります`

## 例子

- 飲みます→お飲みになります
- 待ちます→お待ちになります
- 出席します→ご出席になります

一般不能把单独的`します`机械地变成`おしになります`。

# 3. お／ご～です

## 接续

- `お＋动词ます形去ます＋です`
- `ご＋动作性名词＋です`

## 例子

- 飲みます→お飲みです
- 待ちます→お待ちです
- 出席します→ご出席です

这种形式较简洁，常用于询问或说明对方的动作、状态：

- 何をお探しですか。  
  您在找什么？
- 先生はもうお帰りです。  
  老师已经回去了。

# 4. 专用尊敬语

部分常用动词有固定的尊敬语，需要单独记忆：

| 普通表达 | 专用尊敬语 | 辞书形 |
|---|---|---|
| います・行きます・来ます | いらっしゃいます | いらっしゃる |
| 言います | おっしゃいます | おっしゃる |
| くれます | くださいます | くださる |
| します | なさいます | なさる |
| 食べます・飲みます | 召し上がります（めしあがります） | 召し上がる（めしあがる） |
| 見ます | ご覧になります（ごらんになります） | ご覧になる（ごらんになる） |
| 知っています | ご存じです（ごぞんじです） | ご存じだ（ごぞんじだ） |

`ご覧になります`主要对应`見ます`；在观看、阅读资料的语境中也可以对应`読みます`。普通的`読みます`还可以说`読まれます／お読みになります／お読みです`。

# 四种形式对照

| 普通表达 | 尊敬形 | お／ご～になります | お／ご～です | 专用尊敬语 |
|---|---|---|---|---|
| 飲みます | 飲まれます | お飲みになります | お飲みです | 召し上がります |
| 待ちます | 待たれます | お待ちになります | お待ちです | — |
| します | されます | — | — | なさいます |
| 出席します | 出席されます | ご出席になります | ご出席です | 出席なさいます |

# 特殊ます形

`いらっしゃる・おっしゃる・くださる・なさる`都是一类动词，但它们的ます形特殊：词尾不是通常的`～ります`，而是`～います`。

- いらっしゃる→いらっしゃいます
- おっしゃる→おっしゃいます
- くださる→くださいます
- なさる→なさいます

# 易混点

- 尊敬语抬高的是句子中的动作主体，不能用来抬高自己的动作。
- 和语动词一般使用`お`，如`お読みになります`；汉语动作性名词一般使用`ご`，如`ご出席になります`。
- 有专用尊敬语时，JLPT常考专用形式，如`食べます→召し上がります`。
- 通常不要把两个尊敬形式机械叠加，以免形成不必要的双重敬语。

# JLPT N4 提示

- 掌握四种尊敬表达的接续及相互转换。
- 重点记忆七组常用专用尊敬语。
- 特别注意`いらっしゃいます・おっしゃいます・くださいます・なさいます`的特殊ます形。
- 根据动作主体判断是否需要使用尊敬语，并与谦让语区分。
