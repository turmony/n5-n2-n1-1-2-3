# 核心

`动词ます形去ます + なさい`表示命令或指示：“做……吧／去做……”。语气比直接命令形稍缓和，但仍主要用于上对下的关系。

# 接续

- 食べます → 食べなさい
- 寝ます → 寝なさい
- します → しなさい
- 来ます → 来なさい（きなさい）

# 基本例句

- 野菜を食べなさい。  
  吃蔬菜。
- 早く寝なさい。  
  快睡觉。

# 使用对象

适用于父母对孩子、老师对学生等情境。

- × 老师对校长：早く読みなさい。  
  不适合。对上级不能这样说。

对需要礼貌请求的对象，使用`～てください`等表达：

- 読んでください。  
  请读。

# 固定寒暄语

下列虽然带有「なさい」，但已固定为打招呼的表达，不按命令理解：

- おやすみなさい。  
  晚安。
- おかえりなさい。  
  你回来了／欢迎回家。

它们的形式含有「なさい」，但在实际会话中没有“命令对方休息／回来”的意思。

# 易混项

- `～なさい`：上对下的指示或命令。
- 动词命令形：如`食べろ`、`寝ろ`，语气更强、更直接。
- `～てください`：礼貌请求。

# JLPT N4 提示

- 接动词ます形去掉「ます」后的词干。
- `しなさい`、`来なさい`是常见的不规则对应形式。
- 遇到「おやすみなさい」「おかえりなさい」时，应判断为固定寒暄语。
