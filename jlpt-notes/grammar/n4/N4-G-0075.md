# 核心

使役受身形表示“被迫做……”“被要求做……”，常带有“不是自己想做，而是受到他人支配”的语气。

# 1. 一类动词（五段动词）

将词尾的`う段`变成`あ段`，再加`せられる`：

- 書く→書かせられる
- 飲む→飲ませられる
- 話す→話させられる
- 待つ→待たせられる
- 帰る→帰らせられる

一类动词口语中常将`～せられる`缩短为`～される`：

- 書かせられる→書かされる
- 飲ませられる→飲まされる
- 待たせられる→待たされる

# 2. 二类动词（一段动词）

去掉`る`，加`させられる`：

- 食べる→食べさせられる
- 見る→見させられる
- 起きる→起きさせられる

# 3. 三类动词（不规则动词）

- する→させられる
- 来る（くる）→来させられる（こさせられる）

# 常用场景

## ① 被迫做某事

- 私は上司に残業させられました。  
  我被上司强迫加班了。
- 母に野菜を食べさせられました。  
  我被妈妈强迫吃蔬菜。

## ② 被要求完成某项任务

- 先生に作文を書かせられました。  
  我被老师要求写作文。
- 子供のころ、毎日ピアノを練習させられました。  
  小时候每天都被要求练钢琴。

## ③ 表达不满或受害感

使用使役受身形，往往强调说话人不情愿、无奈或受到压力。

# 易混点

- 使役形：让别人做……
  - 母は子供に野菜を食べさせます。——妈妈让孩子吃蔬菜。
- 使役受身形：被迫做……
  - 子供は母に野菜を食べさせられます。——孩子被妈妈强迫吃蔬菜。
- 一类动词常见完整形式和口语缩略形式：`読ませられる／読まされる`。
- 二类、三类动词通常保留`させられる`：`食べさせられる`、`させられる`。

# JLPT N4 提示

- 一类：词尾`う段→あ段＋せられる`，口语常缩略为`～される`。
- 二类：去`る＋させられる`。
- 三类：`する→させられる`，`来る→こさせられる`。
- 判断句意时，注意主语是“让别人做的人”，还是“被迫做的人”。
