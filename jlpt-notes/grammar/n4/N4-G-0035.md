# 核心

`Aは Bに 动词て形＋もらいます`表示A得到B所做的好处动作，即“A请B做……／A得到B帮忙做……”。

A是受惠者，B是施惠者／动作执行者。这个句型从受惠者A的视角来表达。

# 接续

动词て形＋もらいます

- 案内します → 案内してもらいます
- 持ちます → 持ってもらいます
- 貸します → 貸してもらいます
- 作ります → 作ってもらいます

# 基本例句

- 私は友達に東京を案内してもらいました。  
  我请朋友带我游览了东京／朋友带我游览了东京。
- 私は母に料理を作ってもらいました。  
  我请妈妈给我做了饭。

# 说话者视角与“我方—外人”

`～てもらいます`通常把说话者放在受惠者A一方，因此使用时要注意说话者的视角。

## A是说话者或说话者的我方成员

B可以是家人或其他人。

- 私は母に料理を作ってもらいました。  
  我请妈妈给我做了饭。
- 妹は母に料理を作ってもらいました。  
  妹妹请妈妈给她做了饭。

## A是外人，B是说话者或说话者的我方成员

初级阶段通常不从外人A的受惠视角使用`～てもらいます`，而从我方施惠者的视角使用`～てあげます`。

- × 友達は私に料理を作ってもらいました。  
  （此处不表达“我为朋友做饭”。）
- ○ 私は友達に料理を作ってあげました。  
  我给朋友做了饭。

因此，不应简单记成“B绝对不能是家人”；应记为：当A是外人、B是说话者或我方时，通常改用`～てあげます`。

# 委婉拜托：～て もらえませんか

`もらえます`是`もらいます`的可能形。`动词て形＋もらえませんか`字面是“不能让我得到你做……吗”，实际用于委婉地拜托对方帮忙。

- 荷物を持ってもらえませんか。  
  能请您帮我拿一下行李吗？
- 傘を貸してもらえませんか。  
  能借我一下伞吗？

`～てください`是直接请求；`～てもらえませんか`更委婉，也更突出“我得到帮助”。

# 易混项

| 形式 | 视角与含义 |
| --- | --- |
| `～てあげます` | 我／我方为别人做事。 |
| `～てもらいます` | 我／我方得到别人的帮助。 |
| `～てくれます` | 别人为我／我方做事。 |

# JLPT N4 提示

- `～てもらいます`接动词て形。
- 判断时先找“谁受益、谁行动”，再选择表达的视角。
- 委婉请求常用`～てもらえませんか`。
- 授受表达与说话者的“我方—外人”关系有关；不要只按A、B的位置机械替换。
