# 学习者原始输出

N4第96个语法：【普通形】+と 表示条件，有图中表示的四种用法，进行精炼

# 核心

**`A と B`：一……就……／如果……就……。**

前项 A 一成立，后项 B 就作为自然、必然的结果出现；也可表示做完 A 后发现 B，或 A 后紧接着发生 B。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + `と` | 春になると／押すと |
| い形容词 | 普通形 + `と` | 高いと／高くないと |
| な形容词 | 词干 + `だと` | 静かだと |
| 名词 | 名词 + `だと` | この予算だと |

# 四种用法

| 用法 | 含义 | 例句 |
| --- | --- | --- |
| 恒常条件 | 反复成立的规律、习惯或操作结果。 | 春になると、桜が咲きます。<br>このつまみを右に回すと、音が大きくなります。 |
| 必然的假定条件 | 在该条件下，会产生客观、合乎逻辑的结果。 | 追加で五千円払うと、特等席で見られます。<br>この予算だと、東京都内の賃貸物件は難しいです。 |
| 发现 | 做了 A 后，发现 B 已发生或出现；B 常带有意外发现感。 | 窓を開けると、暖かい風が入ってきた。 |
| 继起 | A 完成后，B 紧接着发生，叙述既定的事件顺序。 | 先生は教室に入ると、一枚の写真を学生たちに見せた。 |

# 语义边界

`～と`强调 A 和 B 的联系像规律、自然结果或既定展开。因此后项一般不接说话人的意志、希望、命令、请求或劝诱。

- × 雨が降ると、出かけません。
- ○ 雨が降ったら、出かけません。

不过，后项若是客观描述能力、可能性或制度性结果，仍可使用 `～と`：

- このボタンを押すと、ドアが開きます。

# 与「と・ば・たら・なら」的区别

| 形式 | 一句话记忆 | 典型后项 |
| --- | --- | --- |
| `と` | 一发生就自然会…… | 规律、自然结果、发现、既定继起 |
| `ば` | 如果满足这个条件，就…… | 逻辑判断、一般条件 |
| `たら` | ……之后／如果……就…… | 最通用；可接意志、请求、建议 |
| `なら` | 如果是……的话 | 以已知话题为前提的判断、建议 |

# JLPT N4 提示

- 看到后项是 `～たい`、`～つもりだ`、`～てください`、`～ましょう` 或命令形时，通常不选 `～と`。
- 看到“操作后机器自然变化”“季节规律”“做了某动作后意外发现”时，优先考虑 `～と`。
- 名词、な形容词的现在肯定接续要保留 `だ`：学生だと／便利だと。
