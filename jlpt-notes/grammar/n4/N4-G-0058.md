# 核心

`动词意向形＋とします`表示正要做某事、处于动作即将开始的阶段，或试图做某事。

`动词意向形＋としません／としない`，尤其用于第三人称时，表示某人不肯尝试、拒绝做某事。

# 例句

- 立とうとします。  
  正要站起来。
- 切符を買おうとしたとき、財布を忘れたことに気づきました。  
  正要买票时，我发现忘带钱包了。
- 息子は野菜を食べようとしません。  
  儿子不肯尝试吃蔬菜。
- 彼は謝ろうとしません。  
  他不肯道歉。（礼貌体）
- 彼は謝ろうとしない。  
  他不肯道歉。（普通体，同一个句子的简体说法）

# 相关形式

- `意向形＋とします`：正要做／试图做
- `意向形＋としました`：正要做了／试图做了
- `意向形＋としています`：正在准备做／正试图做
- `意向形＋としません`：不肯做／不试着做（礼貌体）
- `意向形＋としない`：不肯做／不试着做（普通体）

# 不能用于表达自己的“不想做”

`意向形＋としません／としない`通常用于第三人称，描述别人不肯尝试或拒绝做某事。一般不用于表达说话人自己的“不想做”。

表达自己的意愿时，使用以下说法更自然：

- 野菜を食べたくないです。  
  我不想吃蔬菜。
- 野菜は食べません。  
  我不吃蔬菜。

对比：

- 息子は野菜を食べようとしません。  
  儿子不肯尝试吃蔬菜。→ 第三人称的行为拒绝。
- 私は野菜を食べたくないです。  
  我不想吃蔬菜。→ 第一人称的意愿。

# 与「意向形＋と思います」的区别

- 明日、病院へ行こうと思います。  
  我打算明天去医院。→ 计划、意向。
- ドアを開けようとしました。  
  我试图打开门。→ 动作尝试或即将发生的阶段。

# 与「动词辞书形＋ところです」的区别

两者都可表示“正要做……”。一句话：`ところです` 只“报时”，`意向形＋とします` 强调“意图／尝试”。

| 形式 | 视角 | 成败暗示 |
| --- | --- | --- |
| `动词意向形＋とします` | 强调主语想发起动作：“想要、试图” | 常暗示受阻、没做成（`としました` 尤其明显） |
| `动词辞书形＋ところです` | 客观陈述动作所处的时间点：“正要、马上就”（还没开始） | 无，中性 |

- これから昼ご飯を食べるところです。  
  马上正要吃饭。→ 只是陈述时间阶段。
- 昼ご飯を食べようとしたが、急に会議が入った。  
  想吃饭来着，结果突然来了会议。→ 意图＋未遂；这里换成 `食べるところ` 不自然。
- ドアを開けようとした瞬間、猫が逃げた。  
  刚要开门的一瞬间，猫跑了。→ 强调动作正要发动的临界点。

补充：`意向形＋としています` 也可用于自然现象，只表示“变化的临界点”，不含意志：雨が降ろうとしている。（眼看要下雨。）

# JLPT N4 提示

- `意向形＋とする`可表示“正要做”或“试图做”。
- `意向形＋としない`常用于第三人称，表示“不肯尝试”。
- 第一人称表达“不想做”时，优先使用`～たくない`或`～ません`。
