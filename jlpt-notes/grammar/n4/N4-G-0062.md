# 核心

`动词ない形＋で`表示“不做 A 而做 B”，主要有两种用法：

1. **附带状况**：在不做 A 的状态下做 B。
2. **代替行为**：不做 A，取而代之做 B。

# 接续

`动词ない形＋で＋B`

- `食べないで`
- `行かないで`
- `勉強しないで`
- `忘れないで`

# 1. 附带状况

表示做 B 时处于“不做 A”的状态：

- 砂糖を入れないでコーヒーを飲みます。  
  不加糖喝咖啡。
- 今朝は傘を持たないで出かけました。  
  今天早上没带伞就出门了。
- 朝ご飯を食べないで学校へ行きました。  
  没吃早饭就去学校了。

# 2. 代替行为

表示不做 A，改做 B：

- 天気が悪いから、今日は出かけないで、家で映画を見ます。  
  因为天气不好，今天不出门，改在家看电影。
- 彼は勉強しないで、毎日遊んでいます。  
  他不学习，每天都在玩。

是否有“取而代之”的意思，要结合 B 和前后语境判断。

# 与「～なくて」的区别

- 朝ご飯を食べないで学校へ行きました。  
  没吃早饭就去学校了。→ 附带状况。
- 朝ご飯を食べなくて、お腹がすきました。  
  因为没吃早饭，所以肚子饿了。→ 原因。

# 相关表达

- `～ないでください`：请不要……  
  ここで写真を撮らないでください。  
  请不要在这里拍照。
- `～ずに`：意思相近，但更正式、书面。  
  朝ご飯を食べずに出かけました。  
  没吃早饭就出门了。

# JLPT N4 提示

- `～ないで`前面接动词的`ない形`。
- 表示“不做 A 的状态下做 B”或“不做 A，改做 B”。
- 判断两种用法时，要结合 B 和上下文。
- 不要把`～ないで`和表示原因的`～なくて`混淆。
