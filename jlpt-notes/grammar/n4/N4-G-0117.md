# 学习者原始输出

N4第117个语法：讲的是意志性动词和非意志性动词。你进行总结并精炼其核心

# 核心

判断重点不是“动作由人还是物发出”，而是：**说话人能否凭自己的意志，主动控制这件事发生。**

| 类别 | 核心 | 例子 |
| --- | --- | --- |
| 意志性动词 | 人可自主决定、实施或控制的行为 | 开门、学习、参加、治疗 |
| 非意志性动词 | 自然发生、偶然发生，或不由主体意志控制的变化、状态 | 下雨、痊愈、忘记、能够、存在 |

# 常见情形

| 意志性 | 非意志性 |
| --- | --- |
| ドアを開けます（主动开门） | ドアが開きます（门开了） |
| 病気を治します（治疗疾病） | 病気が治ります（病好了） |
| 英語を話します（主动说英语） | 英語が話せます（能说英语） |
| 明日、先生に会います（按计划见老师） | 街で偶然、先生に会いました（偶然遇见老师） |
| 嫌なことは早く忘れましょう（有意放下） | お財布を忘れました（无意遗忘） |

同一个动词并非永远只属于一类；要结合**是否有计划、意图或控制性**来判断。

# 与「ために／ように」的关联

| 表达 | 常接内容 | 含义 |
| --- | --- | --- |
| 意志性动词普通形 + ために | 可主动达成的目标 | 为了…… |
| 非意志性动词普通形 + ように | 能力、状态、自然结果 | 为了能……／以便…… |

- 英語を話すために、来春サークルに入ります。  
  为了说英语，明年春天参加社团。
- 英語が話せるように、毎日練習しています。  
  为了能说英语，每天练习。

# 快速判断

能自然接「～つもりだ」「～ようと思う」「～ましょう」「～てください」的，通常是意志性动词；不能自然这样用的，多为非意志性动词。

# JLPT 要点

- 选择「ために／ように」时，先判断前项是主观目标，还是能力、状态或自然结果。
- 自动词不等于非意志性动词：如「寝る」虽是自动词，仍可表示自己决定睡觉。
- 可能形、被动形、自然现象、无意过失、偶然相遇等，常按非意志性理解。
