# 学习者原始输出

N4第105个语法：【普通形（去だ，去だ）】+でしょうか。表示~吗。用来表示带有推测的提问或者正式的有礼貌的提问

# 核心

**`～でしょうか`：……吗／不知道会不会……呢？**

是比 `～ですか／～ますか` 更委婉、正式的提问表达，主要有两种用法：

1. **带推测的提问**：询问不确定的事情，带“我想知道是否会……”的语气。
2. **正式、有礼貌的提问**：较郑重地向对方询问信息或可能性。

# 接续

| 词类 | 接续 |
| --- | --- |
| 动词 | 普通形 + でしょうか |
| い形容词 | 普通形 + でしょうか |
| な形容词 | 词干 + でしょうか |
| 名词 | 名词 + でしょうか |

な形容词、名词现在肯定时要去掉 `だ`：

- 静かでしょうか。
- 学生でしょうか。

# 基本用法

## 1. 带推测的提问

询问未来、未知情况或说话人没有把握的判断。

- 明日は雨が降るでしょうか。  
  明天会下雨吗？
- 来年の景気はどうなるでしょうか。  
  明年的经济形势会怎么样呢？

与普通问句相比：

- 明日は雨が降りますか。  
  明天会下雨吗？（直接询问信息。）
- 明日は雨が降るでしょうか。  
  不知道明天会不会下雨呢？（带有推测、思考的语气。）

## 2. 正式、有礼貌的提问

用于较正式的场合，或向不熟悉的人、客户等郑重提问。

- 明日も来られるでしょうか。  
  您明天也能来吗？
- 電話番号は何番でしょうか。  
  电话号码是多少呢？

# 与「ですか／ますか」的区别

| 形式 | 语气 |
| --- | --- |
| `～ですか／～ますか` | 一般、直接的提问。 |
| `～でしょうか` | 更委婉、郑重；可表示推测，也可用于礼貌询问。 |

# JLPT N4 提示

- `でしょうか`前接普通形，不接 `ます形`。  
  × 降りますでしょうか  
  ○ 降るでしょうか
- な形容词、名词前不加 `だ`。  
  × 便利だでしょうか  
  ○ 便利でしょうか
- `～でしょう`是推测陈述；`～でしょうか`则是带推测或礼貌语气的疑问句。
