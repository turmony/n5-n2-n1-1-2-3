# 核心

`Aは Bに 动词て形＋さしあげます(差し上げます)`表示A谦逊地为B做某事，即“谦逊地为对方做……”。

A是施惠者，B是受惠者；B通常是长辈、上司、客户等需要表示敬意的人，且不能和A是同一个人。

# 接续

动词て形＋さしあげます(差し上げます)

- 教えます → 教えてさしあげます(教えて差し上げます)
- 送ります → 送ってさしあげます(送って差し上げます)
- 貸します → 貸してさしあげます(貸して差し上げます)

# 例句

- 私は部長に英語を教えてさしあげました。  
  我谦逊地为部长教了英语。
- お客様に駅までの道を教えてさしあげました。  
  我为客人指了去车站的路。

# 使用注意：不宜用于直接主动提出帮助

`～てあげます`和`～てさしあげます(差し上げます)`都包含“我为对方做了一件有益的事”的授受语气。直接对对方说时，即使使用了谦逊形式，也可能让人感觉说话者在强调“我施了恩惠”。

因此，主动表示“我帮您拿行李吧”时，通常不说：

- △ 荷物を持ってさしあげます(持って差し上げます)。
- △ 荷物を持ってあげます。

而使用单纯谦逊地描述自己动作的表达更自然：

- 荷物をお持ちします。  
  我来帮您拿行李。
- 荷物をお持ちしましょうか。  
  我帮您拿行李好吗？

# 与「～てあげます」的区别

| 形式 | 语气 |
| --- | --- |
| `～てあげます` | 中性地为别人做事。 |
| `～てさしあげます(差し上げます)` | 谦逊地为长辈、上司、客户等做事。 |

两者都保留“对方得到我的好处”的授受关系；因此在直接对人主动提议服务时，都要谨慎使用。

# JLPT N4 提示

- `～てさしあげます(差し上げます)`接动词て形。
- B通常是需要敬意的受惠者。
- 表示自己主动提供服务时，优先使用`お～します`、`お～しましょうか`等谦逊表达。
- 不要把“谦逊”理解为一定不会显得居高临下；授受关系本身仍可能带有施惠语感。
