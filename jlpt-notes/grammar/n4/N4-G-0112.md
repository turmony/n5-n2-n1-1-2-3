# 学习者原始输出

N4第112个语法：【动词ます形去ます/い形容词去い/な形容词】+そうです表示推测，其中いい的そうです形式是将よい的い去掉，加上さ再加どうです。否定形式有两种。1，动词ます形去ます+そう+（に）+（も）+ありません。2，ない形去い加さ再加そうです

# 核心：推测的「～そうです」

**`～そうです`：看起来……／好像要……。**

表示根据眼前看到的样子、迹象作出的推测，不是从他人处听来的信息。

- このかばんは便利そうです。  
  这个包看起来很方便。
- 雨が降りそうですから、傘を持っていきましょう。  
  看起来要下雨了，所以带伞去吧。
- おいしそうな料理がたくさんあります。  
  有很多看起来很好吃的菜。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | ます形去 `ます` + そうです | 降ります → 降りそうです |
| い形容词 | 去 `い` + そうです | おいしい → おいしそうです |
| な形容词 | 词干 + そうです | 便利 → 便利そうです |
| 名词 | 原则上不直接接；名词 + のようです | 独身のようです |

# 「いい」的特殊形式

`いい`的原形是 `よい`，因此要从 `よい`变化：

- ○ よさそうです
- × いそうです
- × いいそうです

否定时用 `よくなさそうです`。

# 否定形式

## 1. 动词：ます形去ます + そうに（も）ありません

表示“看起来不会……／似乎不可能……”，较正式。

- 雨は降りそうにありません。  
  看起来不会下雨。
- 彼は来そうにもありません。  
  他看起来完全不会来。  
  （`も`加强否定语气。）

## 2. 「ない」形去い + さそうです

表示“看起来不……”，日常会话中很常用。

- 彼は来なさそうです。  
  他看起来不会来。
- この料理はおいしくなさそうです。  
  这道菜看起来不太好吃。
- 中村先生は元気じゃなさそうです。  
  中村老师看起来没什么精神。
- あの人は日本人じゃなさそうです。  
  那个人看起来不像日本人。

# 名词的注意点

名词一般不能直接接推测的 `そうです`，肯定推测通常使用 `～のようです`。

- × 独身そうです。
- ○ 独身のようです。  
  看起来好像单身。
- × 日本人そうです。
- ○ 日本人のようです。  
  看起来像日本人。

但在否定推测中，可以使用 `名词 + じゃなさそうです`。

有些表示人物特征或状态的词在口语中会见到 `お金持ちそうです／いい人そうです`，但不应把它当作名词一律能直接接 `そうです`的规则。

# 与传闻「そうです」的区别

| 形式 | 含义 |
| --- | --- |
| 雨が降るそうです。 | 听说要下雨。 |
| 雨が降りそうです。 | 看起来要下雨了。 |

- 传闻：普通形 + そうです。
- 推测：动词ます形去 `ます` + そうです。

# 补充注意

`かわいそう`通常表示“可怜”，因此不用它表示“看起来可爱”。

- × 可愛そうな赤ちゃん
- ○ 可愛い赤ちゃん  
  可爱的婴儿。

直接能判断出的外貌特征通常直接说：

- あの男性はハンサムです。  
  那位男性很英俊。

# JLPT N4 提示

- 推测 `そうです`前绝不接动词普通形。  
  × 降るそうです（想表达“看起来要下雨”时）  
  ○ 降りそうです
- `いい → よさそうです`是固定考点。
- 动词否定推测可用 `来そうにありません`或`来なさそうです`；后者更常见于会话。
- `～そうな + 名词`表示“看起来……的……”，如 `おいしそうな料理`。
