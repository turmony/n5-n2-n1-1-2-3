# 核心

`A + のに、B`表示“明明A，却B／虽然A，但是B”。A本来应当导向某种预期结果，但实际出现了与预期相反或不相称的B。

# 接续

接续：【普通形（な，な）】＋のに

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + のに | 食べたのに |
| い形容词 | 普通形 + のに | 高いのに |
| な形容词 | 词干 + な + のに | 静かなのに |
| 名词 | 名词 + な + のに | 学生なのに |

# 基本例句

- たくさん食べたのに、太りません。  
  明明吃了很多，却没有长胖。
- この店はおいしくないのに、高いです。  
  这家店明明不好吃，却很贵。
- あまり勉強しなかったのに、合格できました。  
  明明没怎么学习，却通过了。

# 句末用法

`のに`可在句尾出现，省略后面的结果，用来传达遗憾、不满或未尽之意。

- せっかくお弁当を作ったのに……  
  我好不容易做了便当，可是……

后文虽没有说出，但可从语境理解为“却没能吃／却没能带去”等令人遗憾的结果。

# 易混项

| 形式 | 语感 |
| --- | --- |
| `～けど／が` | 普通转折，语气较中性。 |
| `～のに` | 强调结果出乎意料，常带惊讶、遗憾、不满或批评。 |

# JLPT N4 提示

- 优先识别“预期”和“实际结果”的反差。
- な形容词、名词的现在肯定形必须用`な＋のに`。
- `のに`句末时，注意理解其省略的后半句及情绪色彩。
