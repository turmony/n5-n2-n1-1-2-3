# 核心

条件形表示“如果……就……”。本卡整理动词、い形容词、な形容词和名词的条件形式。

# 1. 一类动词（五段动词）

将词尾的`う段`变成`え段`，再加`ば`：

- 書く→書けば
- 飲む→飲めば
- 話す→話せば
- 待つ→待てば
- 帰る→帰れば
- 買う→買えば

# 2. 二类动词（一段动词）

去掉`る`，加`れば`：

- 食べる→食べれば
- 見る→見れば
- 起きる→起きれば
- 寝る→寝れば

# 3. 三类动词（不规则动词）

- する→すれば
- 来る（くる）→来れば（くれば）

# 4. い形容词

去掉`い`，加`ければ`：

- 高い→高ければ
- 安い→安ければ
- 忙しい→忙しければ

特殊变化：

- いい→よければ

# 5. な形容词和名词

使用`なら`，较正式时可说`ならば`：

- 静かだ→静かなら（ば）
- 便利だ→便利なら（ば）
- 学生だ→学生なら（ば）
- 休みだ→休みなら（ば）

# 例句

- 時間があれば、映画を見ます。  
  如果有时间，就看电影。
- 安ければ、買います。  
  如果便宜，就买。
- 静かなら、ここで勉強します。  
  如果安静，就在这里学习。
- 学生なら、無料です。  
  如果是学生，就是免费的。

# 易混点

- 动词、い形容词使用`～ば`：`行けば`、`安ければ`。
- な形容词、名词使用`～なら`：`静かなら`、`学生なら`。
- `ならば`比`なら`更正式，日常会话中常用`なら`。
- 本卡的“条件形”主要指`～ば／～なら`；`～たら`是另一种条件表达，不能混作同一变形规则。

# JLPT N4 提示

- 一类动词：词尾`う段→え段＋ば`。
- 二类动词：去`る＋れば`。
- 三类动词：`する→すれば`，`来る→くれば`。
- い形容词：`い→ければ`；`いい→よければ`。
- な形容词、名词：`なら（ば）`。
