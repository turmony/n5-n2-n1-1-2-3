# 核心

命令形表示强烈命令“做……！”，常见于上级对下级、男性粗略口语、紧急情况、标语或指示牌。

# 1. 一类动词（五段动词）

将词尾的`う段`变成`え段`：

| 辞书形 | 命令形 |
| --- | --- |
| 書く | 書け |
| 読む | 読め |
| 話す | 話せ |
| 待つ | 待て |
| 死ぬ | 死ね |
| 遊ぶ | 遊べ |
| 帰る | 帰れ |
| 買う | 買え |

# 2. 二类动词（一段动词）

去掉`る`，加`ろ`：

- 食べる→食べろ
- 見る→見ろ
- 起きる→起きろ
- 寝る→寝ろ

# 3. 三类动词（不规则动词）

- する→しろ（也可以说`せよ`）
- 来る（くる）→来い（こい）

# 4. い形容词、な形容词和名词的补充形式（很少用）

这些非动词谓语的命令形在现代日语中**很少使用**，主要见于文语、书面语、格言或固定表达。日常会话一般不会这样命令别人。

- い形容词：去`い`＋`くあれ`
  - 強い→強くあれ
  - よい→よくあれ
- な形容词：词干＋`であれ`
  - 静かだ→静かであれ
  - 立派だ→立派であれ
- 名词：名词＋`であれ`
  - 学生だ→学生であれ
  - 正直者だ→正直者であれ

例如：

- どうか、よかれと願います。  
  希望一切都好。（固定表达，`よかれ`不是日常命令。）
- 強くあれ、若者よ。  
  年轻人啊，要坚强。（文学、标语式表达。）

注意：`強かれ`、`よかれ`属于较旧的文语形式；本卡按现代日语优先记录为`強くあれ`、`よくあれ`。

学习和实际交流中，优先掌握动词命令形；表达礼貌要求时使用`～てください`。

# 例句

- 早く起きろ！  
  快起床！
- ここに名前を書け。  
  在这里写名字。
- 静かにしろ！  
  安静！
- こっちへ来い！  
  到这边来！

# 与礼貌请求的区别

- `座れ！`：坐下！（强硬命令）
- `座ってください。`：请坐。（礼貌请求）

命令形语气很强，日常礼貌场合通常使用`～てください`，或使用较柔和的`～なさい`等表达。

# JLPT N4 提示

- 一类：词尾`う段→え段`。
- 二类：去`る＋ろ`。
- 三类：`する→しろ／せよ`，`来る→来い`。
- 不能把命令形和礼貌请求形式混同。
- い形容词的`～くあれ`、な形容词和名词的`～であれ`很少使用，主要是文语或固定表达。
