# 核心

`动词辞书形／ない形 + ことにします`表示“决定做……／决定不做……”，强调说话人主动作出的选择。

# 接续

- 帰る → 帰ることにします
- 帰らない → 帰らないことにします

# 基本例句

- お正月は国へ帰ることにしました。  
  我决定春节回国。
- お正月は国へ帰らないことにしました。  
  我决定春节不回国。
- 今日から毎日、日本語を勉強することにします。  
  我决定从今天开始每天学习日语。

# 时态

- `～ことにします`：现在作出决定／当场选择。  
  コーヒーにする？ ― ううん、お茶にする。  
  要咖啡吗？——不，我决定要茶。
- `～ことにしました`：已经作出决定。  
  来月から運動することにしました。  
  我决定从下个月开始运动。

# 与「～ことになります」的区别

| 形式 | 决定的来源 |
| --- | --- |
| `～ことにします` | 说话人自己主动决定。 |
| `～ことになります` | 组织、他人、双方协商或客观安排导致的既定结果。 |

- 私は来月から大阪で働くことにしました。  
  我决定从下个月开始在大阪工作。
- 私は来月から大阪で働くことになりました。  
  我被安排从下个月开始在大阪工作。

# 图中对比

- 東京で国際会議が開かれることになりました。  
  已决定在东京召开国际会议。  
  → 会议安排通常不是说话人单方面决定，因此使用`ことになります`。

# JLPT N4 提示

- `ことにします`前接动词辞书形或ない形。
- 表示“不做”的决定时用`动词ない形＋ことにします`。
- 判断题先看决定主体：自己选择用`ことにします`；外部安排用`ことになります`。
