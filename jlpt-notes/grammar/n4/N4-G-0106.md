# 学习者原始输出

N4第106个语法：讲述这个现象，还要说明现在经常用的二类动词和三类的动词的可能形的形式

# 核心：ら抜き可能形

标准日语中，二类动词和 `くる(来る)` 的可能形带 `られる`。但现代日常口语里，常把其中的 `ら` 去掉，改说 `れる`，这叫**ら抜き言葉／ら抜き可能形**。

- 标准、JLPT、正式表达：たべられる(食べられる)
- 日常口语常见：たべれる(食べれる)

它在口语中很常见，尤其常见于年轻人和非正式会话；但正式写作、考试、商务及敬语场合仍应使用带 `ら` 的标准形式。

# 标准可能形与口语常用形

| 动词类别 | 原形 | 标准可能形 | 口语常用的ら抜き形 |
| --- | --- | --- | --- |
| 一类动词 | よむ(読む) | よめる(読める) | 无此问题 |
| 二类动词 | たべる(食べる) | たべられる(食べられる) | たべれる(食べれる) |
| 二类动词 | みる(見る) | みられる(見られる) | みれる(見れる) |
| 二类动词 | おきる(起きる) | おきられる(起きられる) | おきれる(起きれる) |
| 三类动词 | くる(来る) | こられる(来られる) | これる(来れる) |
| 三类动词 | する | できる | 无“ら抜き”形式 |

`する`的可能形本来就是 `できる`，不能说 `できれる`。

# 为什么会出现这种形式

二类动词的 `～られる`同时可能表示可能、被动或尊敬。口语中的 `たべれる`只表示“能吃”，形式更短，也能更清楚地区分可能、被动和尊敬的意思；这是它在会话中逐渐普及的原因之一。

# 例句

- 台湾でおいしい果物が食べられる。  
  在台湾能吃到好吃的水果。（标准表达）
- 台湾でおいしい果物が食べれる。  
  在台湾能吃到好吃的水果。（日常口语常见）
- 臭豆腐は臭くて食べられない。  
  臭豆腐太臭，吃不了。
- 来週の水曜日、来れますか。  
  下周三能来吗？（口语中常见）
- 山田さんは急用で来れません。  
  山田先生/女士因有急事来不了。（口语中常见）

# 使用边界

| 场景 | 推荐形式 |
| --- | --- |
| JLPT、作业、正式写作 | たべられる／みられる／こられる |
| 商务、客户、老师等正式对象 | 标准形式；必要时使用敬语 |
| 朋友聊天、影视、社交媒体 | たべれる／みれる／これる很常见，可理解并听懂即可 |

ら抜き形只能表示可能，不能替代被动或尊敬：

- 先生がケーキを食べられる。  
  老师吃蛋糕。（尊敬表达）
- × 先生がケーキを食べれる。  
  不能用来表示尊敬。

# JLPT N4 提示

- 考试中，二类动词可能形写作 `～られる`。
- `食べれる／見れる／来れる`在现实口语中常见，但不作为 JLPT 语法题的标准答案。
- `する → できる`必须单独记忆。
