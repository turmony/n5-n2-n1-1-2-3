# 学习者原始输出

【名词+（助词）】/【动词て形 】+ばかり。表示仅，只的意思。其他的用法包括：1，【数量词+ばかり】表示大概数量，等于ぐらい的意思。2，【名词/动词辞书形】+ばかり 表示只需要... 等于だけ的意思。

# 核心

`～ばかり` 基本表示“净是……／总是……／只……”。它常带有行为或事物偏向某一方面、缺少其他部分的语感，因此比单纯的 `だけ` 更容易含有“不均衡、偏重”的意味。

# 接续

| 形式 | 含义 |
| --- | --- |
| 名词 + `ばかり` | 净是……／只…… |
| 名词 + 助词 + `ばかり` | 只在／只对／只从……等 |
| 动词て形 + `ばかりいる` | 总是反复做……，几乎只做这一件事 |
| 数量词 + `ばかり` | 大约……，约等于 `ぐらい` |
| 动词辞书形 + `ばかりだ` | 前面的准备都完成了，只剩下做…… |

# 用法一：表示偏重、偏向

- 肉ばかり食べるのは体によくない。  
  净吃肉对身体不好。
- 最近の子供は家の中でばかり遊んで、外で遊ばない。  
  最近的孩子总是在家里玩，不在外面玩。
- 彼は何もしないで、他人を批判してばかりいる。  
  他什么也不做，净是在批评别人。

`动词て形 + ばかりいる` 常带批评、不满或担心的语气，但是否负面仍要看上下文。

# 用法二：表示大约数量

`数量词 + ばかり` 表示“大约……”，与 `ぐらい` 意思接近。

- この信号を渡って50メートルばかり行くと、コンビニがあります。  
  过了这个红绿灯，再走大约五十米就有便利店。
- 10人ばかり集まりました。  
  大约来了十个人。

# 用法三：只剩下要做……

`动词辞书形 + ばかりだ` 表示前面的准备、手续等都已完成，只剩最后一个动作。

- 準備はできた。あとはお客さんを待つばかりだ。  
  准备完成了，之后只剩等客人。
- 荷物も送ったし、あとは出発するばかりだ。  
  行李也寄出了，之后只剩出发。

这里不是单纯的 `だけ`，而是带有“其他事情已完成”的前提。

# 易混点

- `肉だけ食べる`：只吃肉。中性地限定范围。  
  `肉ばかり食べる`：净吃肉，暗示饮食不均衡。
- `食べてばかりいる`：总是在吃，强调反复或偏重。  
  `食べたばかりだ`：刚吃完。这里的 `たばかり` 是另一种用法，不能混淆。

# JLPT N4 提示

- `名词 + ばかり` 和 `动词て形 + ばかりいる` 多考查“偏重、净是”的语感。
- `数量词 + ばかり` 选“大约”。
- `动词辞书形 + ばかりだ` 选“只剩下要做……”，通常前文会出现准备完成的语境。
