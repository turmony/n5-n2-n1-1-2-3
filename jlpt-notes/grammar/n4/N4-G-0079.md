# 学习者原始输出

（お+动词ます形去ます）/（ご+动作性名词）+になります。  
（お+动词ます形去ます）/（ご+动作性名词）+です。表示尊敬

# 核心

`お／ご～になります`和`お／ご～です`都是尊敬表达，用来抬高对方、上级或第三者的动作、状态或安排。不能用于自己的动作。

# 接续

- `お＋动词ます形去ます＋になります／です`
- `ご＋动作性名词＋になります／です`

和语动词一般使用`お`，汉语动作性名词一般使用`ご`。

例：

- お帰りになります（おかえりになります）
- お待ちです（おまちです）
- ご出席になります（ごしゅっせきになります）
- ご利用です（ごりようです）

# 用法与例句

## ① お／ご～になります：强调动作或行为

- 先生はもうお帰りになりました。  
  老师已经回去了。
- 部長は次の会議にご出席になります。  
  部长将出席下一个会议。

## ② お／ご～です：多表示状态、情形或已确定的安排

- お客様はロビーでお待ちです。  
  客人正在大厅等候。
- ポイントカードはお持ちですか。  
  您有积分卡吗？
- 部長は来週、本社へお戻りです。  
  部长下周将返回总部。

`お／ご～です`常可对应普通表达中的`～ています`，但也能像最后一句一样表示既定安排，不能一律机械翻成`～ています`。

# 重要限制

这个句型不能机械套用到所有动词。以下常用专用尊敬语：

| 普通表达 | 常用尊敬语 |
|---|---|
| 行きます・来ます・います | いらっしゃいます |
| します | なさいます |
| 見ます | ご覧になります（ごらんになります） |
| 寝ます | お休みになります（おやすみになります） |

- × 部長は11時にお来になります。  
- ○ 部長は11時にいらっしゃいます。

## ① 去掉ます后只有一个拍的动词，不能直接使用此构式

`お＋动词ます形去ます＋になります／です`中，去掉`ます`后仅剩一个拍的动词不能直接套入这个构式。

- 来ます → き：× お来になります
- します → し：× おしになります
- 寝ます → ね：× お寝になります

这类动词应改用对应的专用尊敬语或其他尊敬表达：`来ます`用`いらっしゃいます`，`します`用`なさいます`，`寝ます`用`お休みになります`。

# 易混点

- `お／ご～します`是谦让语，用于自己或自己一方的动作；`お／ご～になります・です`是尊敬语，用于对方一方。
- 要避免重复使用尊敬形式：`ご覧になられます`不规范，使用`ご覧になります`即可。

# JLPT N4 提示

- 先判断动作主体：对方用尊敬语，自己一方用谦让语。
- 区分`お／ご～になります`的动作含义与`お／ご～です`的状态、情形或安排含义。
- 牢记常见专用尊敬语，尤其是`いらっしゃいます／なさいます／ご覧になります／お休みになります`。
