# 学习者原始输出

N4第102个语法：【普通形（な，名词词干）】+（こと+助词）/ことです。表示形式名词。表示好恶，能力，の、こと都可以用，但是の用的多，然后图片还划分了其他使用的场景，例如在句末只能用こと

# 核心

**`こと`是形式名词，可将前面的动作、状态或内容名词化，表示“做……这件事／……这一情况”。**

- 私は絵をかくことが好きです。  
  我喜欢画画。
- 私の夢は、自分の店を開くことです。  
  我的梦想是开一家自己的店。

# 接续

- 动词普通形 + （こと + 助词）／ことです
- い形容词普通形 + （こと + 助词）／ことです
- な形容词词干 + な（こと + 助词）／ことです
- 名词 + 助词／です

名词本身已经具有名词性质，可直接接助词或 `です`，不需要再接形式名词 `こと`。`名词 + のこと`表示“关于……／……的事”，属于另一种表达，不是本课的名词接续规则。

# 与「の」的区别

| 场景 | 形式 | 例句 |
| --- | --- | --- |
| 好恶 | `～の／ことが好きです` | 映画館で映画を見るの／ことが好きです。 |
| 巧拙 | `～の／ことが苦手です` | 人と話すの／ことが苦手です。 |
| 具体动作评价 | `～の／ことは無理です` | 一人でこの荷物を運ぶの／ことは無理です。 |
| 能力 | `～ことができます` | 英語を話すことができます。 |

好恶、巧拙和具体动作的评价中，`の／こと`都可用；`の`更常用于具体、日常的动作。能力表达 `～ことができます`是固定搭配，只能用 `こと`。

# 常用「こと」的场景

| 场景 | 形式 | 例句 |
| --- | --- | --- |
| 句末定义、梦想、兴趣 | `～ことです` | 私の趣味は、動物の写真を撮ることです。 |
| 经验 | `～たことがあります` | 富士山に登ったことがあります。 |
| 决定 | `～ないことにします` | 今日からタバコを吸わないことにします。 |
| 规定 | `～ことになっています` | ここで靴を脱ぐことになっています。 |
| 结果、安排 | `～ことになりました` | 来週アメリカへ出張することになりました。 |
| 不必要 | `～ことはありません` | あなたが心配することはありません。 |
| 思考内容 | `～ことを考えています` | 来月までに引っ越すことを考えています。 |
| 机会 | `～ことがあります` | 仕事が忙しいので、会社に泊まることがある。 |
| 承诺 | `～ことを約束します` | 二度と遅刻しないことを約束します。 |
| 传达信息 | `～ことを伝えます` | 先生に明日休むことを伝えてください。 |

在“我的梦想是……”“我的兴趣是……”等定义性句子中，用 `ことです`，不使用 `のです`；`のです`是另一种表示说明、解释语气的语法。

# 常用「の」的场景

`の`更适合直接看见、听见、感受到的具体动作或状态。

- カラスが鳴いているのが聞こえる。  
  能听见乌鸦在叫。
- 車と車がぶつかるのを見ました。  
  我看见车和车相撞了。
- 日本人は歩くのが速い。  
  日本人走路快。

# JLPT N4 提示

- `～ことができる／～たことがある／～ことにする／～ことになる` 都是高频固定搭配。
- 感官动词 `見える／聞こえる／見る` 前，优先使用 `の`。
- `こと`较适合抽象内容、决定、规则、经验；`の`较适合具体动作、直接感知。
