# 学习者原始输出

ございます是あります的礼貌语　　いらっしゃいます是います的尊敬语。でございます、でいらっしゃいます分别是です的礼貌语和尊敬语

# 核心

| 普通表达 | 更郑重／敬意表达 | 用途 |
| --- | --- | --- |
| `あります` | `ございます` | `あります` 的郑重、礼貌表达；用于物品、场所、事情、安排等。 |
| `います` | `いらっしゃいます` | `います` 的尊敬语；用于对方、上级或应受尊敬者。 |
| `です`／`だ`／`である` | `～でございます` | `です` 的更郑重表达；不抬高主语本身。 |
| `です`／`だ`／`である` | `～でいらっしゃいます` | `です` 的尊敬表达；用于对方、上级或应受尊敬者。 |

补充：`いらっしゃいます` 还可以作为 `行きます`、`来ます` 的尊敬语。

# 接续

- 名词 + に + `ございます`
- 名词 + が + `ございます`
- 名词 + `でございます`
- 人 + `でいらっしゃいます`

# 基本用法

- 調味料はあちらの棚にございます。  
  调味料在那边的架子上。
- 週末は何かご予定がございますか。  
  您周末有什么安排吗？
- 私の出身は埼玉県でございます。  
  我的出身地是埼玉县。
- 3階は紳士服売り場でございます。  
  三楼是男装卖场。
- 高橋部長は会議室にいらっしゃいます。  
  高桥部长在会议室。
- こちらは筑波大学の伊原教授でいらっしゃいます。  
  这位是筑波大学的伊原教授。

# 语义边界

- `ございます` 不能用于人的存在。  
  × 先生がございます。  
  ○ 先生がいらっしゃいます。
- `でございます` 只使表达更郑重，不等于抬高主语，因此可用于自己或事物。  
  例：私の出身は埼玉県でございます。
- `でいらっしゃいます` 会抬高主语，只用于对方、上级或第三者。  
  × 私は田中でいらっしゃいます。  
  ○ 田中先生でいらっしゃいます。

# 易混点

判断关键是主语：

- 人物且需要表示尊敬：`いらっしゃいます`／`でいらっしゃいます`
- 物、场所、事情，或不需抬高主语的正式说明：`ございます`／`でございます`

`いらっしゃいます` 是尊敬语，不能用于自己一方。

# JLPT N4 提示

- 看到表示存在的句子，先区分对象是人还是物、场所、事情：人用 `います`／`いらっしゃいます`，非人用 `あります`／`ございます`。
- 题目若要求“更郑重”，不一定要使用尊敬语；`でございます` 只增加正式、礼貌的语气，而 `でいらっしゃいます` 同时抬高主语。
