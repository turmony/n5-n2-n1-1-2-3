# 核心

`名词A は 名词B より + 谓语`表示“A比B更……”。`より`标记比较的基准，相当于中文的“比……”。

# 基本例句

- 北海道は九州より大きいです。  
  北海道比九州大。
- 九州より北海道は大きいです。  
  与九州相比，北海道更大。

两句的比较对象和结果相同。第二句把比较基准「九州より」放在句首，更突出“以九州为参照”。

# 接续

- `A は B より + い形容词`
- `A は B より + な形容词`
- `A は B より + 表示程度的动词或其他谓语`

- 電車はバスより速いです。  
  电车比公交车快。
- この町はあの町より静かです。  
  这个城镇比那个城镇安静。

# 语序与易混项

- `AはBより～`和`BよりAは～`可以表达相同的比较关系。
- `より`后面跟的是比较基准B；A才是被说明“更……”的一方。
- `BよりAのほうが～`是常见的加强比较形式：  
  九州より北海道のほうが大きいです。  
  与九州相比，北海道更大／北海道更大些。

# JLPT N4 提示

- 看到`より`先找“比较基准”。
- 注意不要把中文“比”后的对象误认为日语句子的主语；`AはBより～`中，A是结论所描述的对象。
- `より`可与`のほうが`搭配，但本句型本身已经能完成比较表达。
