# 学习者原始输出

（お+动词ます形去ます）/（ご+动作性名词）+ください。表示请您做，既有想让对方做某个动作，又给出了尊敬

# 核心

`お／ご～ください（下さい）`用于郑重地请求对方做某事，既表达“请您做……”，也通过尊敬语抬高对方的动作。主语是对方、上级、顾客等应受尊敬的人，不能用于自己的动作。

# 接续

- `お＋动词ます形去ます＋ください（下さい）`
- `ご＋动作性名词＋ください（下さい）`

和语动词一般使用`お`，汉语动作性名词一般使用`ご`。

# 例句

- こちらでお待ちください。  
  请您在这里等候。
- どうぞお入りください。  
  请进。
- 内容をご確認ください。  
  请确认内容。
- 次の会議にご出席ください。  
  请出席下一个会议。

# 易混点

## ① 与～てください的区别

- `～てください`：一般的“请做……”。
- `お／ご～ください（下さい）`：更郑重地请求对方做某事，常用于服务、通知，或向上级说话的场合。

## ② 与お／ご～します的区别

- `お／ご～ください（下さい）`：请对方做，属于尊敬表达。
- `お／ご～します`：自己为对方做，属于谦让表达。

# 重要限制

不能机械套用到所有动词；常用专用尊敬表达如下：

| 普通表达 | 请求时的尊敬表达 |
|---|---|
| 来ます | おいでください |
| します | なさってください |
| 見ます | ご覧ください（ごらんください） |
| 寝ます | お休みください（おやすみください） |

- × お来ください  
- ○ おいでください

# JLPT N4 提示

- 先判断“谁做动作”：请求对方做时可用`お／ご～ください（下さい）`；自己要做时不用此表达。
- 重点掌握常用固定搭配：`お待ちください／お入りください／ご確認ください／ご覧ください`。
- 在正式通知中，经常见到`ご利用ください／ご記入ください／ご注意ください`等表达。
