# 核心

`～ために`表示为了实现前项的目的而进行后项行为，即“为了……”。

前项通常是说话者可以有意识地设定、努力实现的目的。

# 接续

## 后项B是动作／句子时

`（意志动词辞书形／名词＋の）＋ために＋B`

## 后项B是名词时

`（意志动词辞书形／名词＋の）＋ための＋名词`

# 例句

- 他社の製品の価格を調べるために、スーパーへ行きます。  
  为了调查其他公司的产品价格，去超市。
- 将来自分の会社を設立するために、貯金しています。  
  为了将来成立自己的公司，正在存钱。
- 健康のために、毎日運動しています。  
  为了健康，每天运动。
- 日本で働くための日本語を勉強しています。  
  正在学习为了在日本工作所需的日语。
- 旅行のためのかばんを買いました。  
  买了旅行用的包。

# 与「～ように」的区别

`～ために`的前项是可以凭意志直接努力实现的目的。

`～ように`的前项多为能力、自然变化、疾病痊愈等不能靠意志直接控制的结果或状态。

- 将来自分の会社を設立するために、貯金しています。  
  为了将来成立自己的公司，正在存钱。
- 風邪が治るように、薬を飲んでいます。  
  为了让感冒好起来，正在吃药。
- 日本語が話せるように、毎日練習しています。  
  为了能说日语，每天练习。

# 与「～に行きます」的区别

当目的只是“去某地做某个动作”时，常用`动词ます形去ます＋に行きます`，更简洁、自然。

- 晩ご飯の食材を買いに、スーパーへ行きました。  
  去超市买晚饭的食材。

`晩ご飯の食材を買うために、スーパーへ行きました`语法上可以成立；但在“去某地买东西”这种直接目的的场景中，`買いに行きました`更自然。

# JLPT N4 提示

- `～ために`前接意志动词辞书形或`名词＋の`，不能接ます形。
- 后项是句子时使用`～ために＋B`；后项是名词时使用`～ための＋名词`。
- 看到能力、自然变化、疾病痊愈等非意志结果时，优先考虑`～ように`。
