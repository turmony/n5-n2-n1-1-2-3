# 核心

`～と言います`表示“（某人）说……”，`と`是引用助词。可以表示直接引用和间接引用。

# 直接引用

直接引用保留原话的内容和语气，通常使用`「 」`：

- 先生は「明日、テストをします」と言いました。  
  老师说：“明天考试。”
- 先生は「金曜日までにレポートを出してください」と言いました。  
  老师说：“请在星期五之前交报告。”

原话是礼貌体时，直接引用中保留礼貌体；原话是普通体时，也可以保留普通体。

# 间接引用

间接引用通常把内容改为普通形，再接`と言います／と言いました`：

- 先生は明日、テストを**する**と言いました。  
  老师说他明天考试。
- 先生は金曜日までにレポートを**出せ**と言いました。  
  老师说要在星期五之前交报告。

# 接续

- 动词普通形＋と言います  
  `行くと言います`、`行ったと言います`、`行かないと言います`
- い形容词普通形＋と言います  
  `難しいと言います`
- な形容词＋だ＋と言います  
  `静かだと言います`
- 名词＋だ＋と言います  
  `学生だと言います`

这里的`【普通形（だ，だ）】`表示：**な形容词和名词的现在肯定形保留`だ`**。

- `静かだ` → `静かだと言います`
- `学生だ` → `学生だと言います`

在口语或特定表达中，な形容词、名词前的`だ`有时会省略，例如`静かと言いました`、`学生と言いました`；但 JLPT N4 的普通形接续题中，间接引用的现在肯定形式优先记作`だ＋と`。

# 语体与时态

- `と言います`：说、表示说话内容
- `と言いました`：说过、说道
- 礼貌体的直接引用：`「行きます」と言いました`
- 普通体的间接引用：`行くと言いました`

# 易混项

- `と言います`：说……
- `と思います`：认为、觉得……
- `と聞きました`：听说、听到了……

# JLPT N4 提示

- 直接引用通常保留原句形式，并使用`「 」`。
- 间接引用通常使用普通形＋`と`。
- `と`是引用内容的助词，不是并列助词。
- な形容词和名词的现在肯定间接引用，考试中优先使用`だ＋と`。
