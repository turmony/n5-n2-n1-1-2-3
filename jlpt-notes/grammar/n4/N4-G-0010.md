# 核心

- `动词辞书形 + ことができます`：能够做……／可以做……
- `名词 + ができます`：能够……／可以……

名词通常表示语言、运动、服务等可进行的事项。

# 接续

- 書く → 書くことができます
- 話す → 話すことができます
- 英語 → 英語ができます
- コピー → コピーができます

# 三类常见用法

## 1. 个人能力、技能

- 田中さんはきれいな字を書くことができます。  
  田中能写漂亮的字。
- 私は英語ができます。  
  我会英语。

## 2. 设备、场所或环境允许的可能性

- ここでコピーができます。  
  这里可以复印。
- このホテルではインターネットを使うことができます。  
  这家酒店可以使用互联网。

## 3. 规则或许可范围内“可以做”

- この図書館では本を借りることができます。  
  在这家图书馆可以借书。
- この建物に入ることができません。  
  不能进入这栋建筑。

「入ることができません」可能是规定不允许，也可能是其他原因；须结合语境判断。

# 与明确许可／禁止的区别

| 表达 | 含义 |
| --- | --- |
| `～ことができます` | 有能力、有条件或被允许做。 |
| `～ことができません` | 不能做；原因未必是禁止。 |
| `～てもいいです` | 明确许可：“可以做”。 |
| `～てはいけません` | 明确禁止：“不可以做”。 |

- 入ってもいいです。  
  可以进去。
- 入ってはいけません。  
  不可以进去／禁止进入。

# 易混项

- `名词＋ができます`不能随意接任何名词；常用于可进行的语言、技能、服务等，如`英語ができます`、`コピーができます`。
- 表示具体动作时，优先用`动词辞书形＋ことができます`。

# JLPT N4 提示

- `こと`前必须接动词辞书形，不能接ます形。
- 判断`できます／できません`时，要从语境判断是能力、条件，还是规则上的许可与限制。
- 明确问“可不可以”时，常与`～てもいいです／～てはいけません`比较。
