# 学习者原始输出

【た形】+ら。表示条件，但是图中分为了三种情况，个人认为无需划分，只记一个如果...的话即可

# 核心

**先记住：`～たら` = 前项之后，后项发生。**

它可译为“如果……的话／……之后就……”。前项可以是假设的条件，也可以是实际发生的事情；只要理解为“前项成立或完成后，后项发生”即可。

接续上使用：

- 动词、い形容词：`た形／なかった形 + ら`
- な形容词、名词：`だったら／じゃなかったら`

注意：`たら` 虽然含有 `た`，但不一定表示过去，也可以表示未来条件。

- 明日雨が降ったら、出かけません。  
  如果明天下雨，就不出门。

# 接续

| 词类 | 肯定 | 否定 |
| --- | --- | --- |
| 动词 | 飲んだら | 飲まなかったら |
| い形容词 | 暑かったら | 暑くなかったら |
| な形容词 | 便利だったら | 便利じゃなかったら |
| 名词 | 雨だったら | 雨じゃなかったら |

# 基本用法

- 雨が降ったら、出かけません。  
  如果下雨，就不出门。
- 高くなかったら、買います。  
  如果不贵，就买。
- 日曜日だったら、時間があります。  
  如果是星期日，我有时间。
- 駅に着いたら、電話してください。  
  到车站后，请打电话。
- 大学を卒業したら、カナダへ留学したいです。  
  大学毕业后，我想去加拿大留学。

# 表示实际发生的后续结果

`～たら` 也可用于回顾过去，表示“……之后，结果……”。此时不是假设，而是叙述实际发生的事。

- このお酒を飲んだら、頭が痛くなりました。  
  喝了这酒之后，头疼起来了。
- 箱を開けたら、虫が飛び出してきました。  
  打开箱子后，虫子飞了出来。

# 语义边界

- `～たら` 的重点是前项先完成或出现，再发生后项。因此可以自然接请求、命令、愿望等表达。  
  駅に着いたら、電話してください。  
  到车站后，请打电话。
- 不要因看到 `た` 就误以为只能说过去。`明日行ったら` 是“明天去了以后／如果明天去”的意思。
- 与 `～と` 相比，`～たら` 更适合接命令、请求、意志等后项。  
  ○ 駅に着いたら、電話してください。  
  △ 駅に着くと、電話してください。

# JLPT N4 提示

- 看到 `～たら`，先抓住“如果……／……之后”的条件关系即可。
- 重点掌握各词类的 `～たら` 变形，尤其是：静かだったら／学生だったら／高くなかったら。
- 后项出现 `ください`、`たいです`、`ましょう` 时，常可使用 `～たら`。
