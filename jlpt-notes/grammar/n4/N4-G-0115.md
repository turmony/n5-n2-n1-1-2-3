# 学习者原始输出

N4第115个语法：【普通形（な，の）】+ように +句子。【普通形（な，の）】+ような +名词。【普通形（な，の）】+ようです。表示好像... 有三种用法。1，推测。2，举例。3，比喻

# 核心

**`～ようです／～ような／～ように`：好像……／像……一样。**

`よう`是形式名词。根据后面接续的形式，可用于推测、举例和比喻。

# 接续

| 后续形式 | 接续 | 作用 |
| --- | --- | --- |
| `～ようです` | 普通形（な・の）+ ようです | 推测 |
| `～ような + 名词` | 普通形（な・の）+ ような + 名词 | 举例、比喻性修饰名词 |
| `～ように + 句子` | 普通形（な・の）+ ように + 句子 | 比喻性修饰后项 |

- 动词：壊れているようです
- い形容词：高いようです
- な形容词：静かなようです
- 名词：故障のようです

# 基本用法

## 1. 推测：～ようです

根据看到的现象、掌握的线索或逻辑作出较审慎的判断：“好像……／似乎……”。

- このクーラーは故障しているようです。  
  这台空调好像坏了。
- 外がぬれているので、昨日の夜は雨が降ったようです。  
  外面是湿的，昨晚好像下过雨。

## 2. 举例：～ような + 名词

表示“像……那样的……”，以前项为例子说明后项名词的种类、样子或特点。

- 私も田中さんが持っているようなかばんが欲しい。  
  我也想要一个像田中先生/女士拿着的那种包。
- 子供でも読めるような本を探しています。  
  我在找一本连孩子也能读的那种书。

## 3. 比喻：～ように + 句子

将前项当作比喻对象，说明后项的程度、状态或动作方式。

- もう十一月なのに、今日は真夏のように暑い。  
  已经十一月了，今天却像盛夏一样热。
- 彼は鳥のように空を飛びたいと言った。  
  他说想像鸟一样在天空飞翔。

# 推测的「ようです」与「そうです」

| 形式 | 判断依据与特点 |
| --- | --- |
| `～ようです` | 根据迹象、事实或逻辑作出审慎判断；可用于过去已经完成的事情。 |
| `～そうです`（推测） | 根据眼前样子判断“马上要……”；多用于即将发生的变化。 |

- 昨日の夜は雨が降ったようです。  
  昨晚好像下过雨。（根据迹象，推测已发生的事情。）
- 雨が降りそうです。  
  看起来要下雨了。（根据眼前情况，推测即将发生。）

`雨が降ったそうです`是传闻“听说昨晚下雨了”，不是本课的推测 `そうです`。

# 易混项

`～ように`还有“为了能……”的目的用法：

- 忘れないように、メモします。  
  为了不忘记，我记下来。

这与本课“像……一样”的比喻用法不同。

# JLPT N4 提示

- 名词接 `よう`时要用 `の`：故障のようです。
- な形容词接 `よう`时要用 `な`：静かなようです。
- 根据已发生的事实推测时，常用 `～たようです`。
- 描述即将发生的变化时，常用推测的 `～そうです`：降りそうです。
