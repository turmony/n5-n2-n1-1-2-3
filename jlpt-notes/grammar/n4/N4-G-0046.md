# 核心

`动词辞书形＋ようになります`表示习惯、行为或状态发生变化，变得会做／开始做……。

`动词ない形＋なくなります`表示变得不再做……；若前面是可能形的否定，则表示变得不能够……。

这里的`よう`是形式名词，`に`表示变化的结果。

# 接续

- 动词辞书形＋ようになります  
  `おきる(起きる)ようになります`
- 动词ない形的`ない`改为`なく`＋なります  
  `みない(見ない)` → `みなくなります(見なくなります)`
- 动词可能形＋ようになります  
  `よめる(読める)ようになります`
- 动词可能形的ない形的`ない`改为`なく`＋なります  
  `よめない(読めない)` → `よめなくなります(読めなくなります)`

# 例句

- 社会人になってから、朝早く起きるようになりました。  
  成为社会人后，我开始早起了。
- 最近、テレビを見なくなりました。  
  最近变得不看电视了。
- やっと日本語が読めるようになりました。  
  终于变得能够读日语了。
- 年を取って、小さい字が読めなくなりました。  
  上了年纪后，变得看不清小字了。

# 习惯变化与能力变化

## 习惯或行为的变化

- `早く起きるようになりました`：开始早起了。
- `テレビを見なくなりました`：变得不再看电视了。

## 能力的变化

表示“变得能够……”时，要先使用可能形，再接`ようになります`：

- `日本語を読む` → `日本語が読めるようになりました`  
  变得能够读日语了。

表示“变得不能够……”时，使用可能形的否定，再将`ない`改为`なく`：

- `小さい字が読める` → `小さい字が読めなくなりました`  
  变得看不清小字了。

注意：

- `話さなくなりました`：变得不再说了。→ 习惯变化
- `話せなくなりました`：变得不能说／不会说了。→ 能力变化

# 与「～ようにします」的区别

- 毎日早く起きるようにします。  
  我会努力每天早起。→ 主动努力或今后的目标
- 毎日早く起きるようになりました。  
  我已经变得每天早起了。→ 习惯已经发生变化

# JLPT N4 提示

- “开始做某事／变得会做某事”：`辞书形／可能形＋ようになる`。
- “不再做某事”：`ない形＋なくなる`。
- “变得不能做某事”：`可能形的ない形＋なくなる`。
- 重点区分`話さなくなる`（不再说）和`話せなくなる`（不能说）。
