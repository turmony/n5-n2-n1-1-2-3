# 核心

`动词ない形去ない＋ずに／ず`是较正式、书面的否定连接形式：

- `～ずに`≈`～ないで`：表示附带状况或代替行为。
- `～ず`≈`～なくて`：表示原因或否定并列。

这里的`に`就是`～ずに`中的`に`，**可以省略，也可以保留**：

- `行かずに`／`行かず`
- `食べずに`／`食べず`
- `勉強せずに`／`勉強せず`

# 接续

- 五段、一段动词：动词`ない形`去`ない`＋`ず／ずに`
  - `行かない` → `行かず／行かずに`
  - `食べない` → `食べず／食べずに`
- `する`→`せず／せずに`
  - `勉強しない` → `勉強せず／勉強せずに`
- `来る`→`来ず／来ずに`（こず／こずに）

# 1. ～ずに／～ず：附带状况或代替行为

- 砂糖を入れずに、コーヒーを飲みます。  
  不加糖喝咖啡。
- 天気が悪いから、今日は出かけずに、家で映画を見ましょう。  
  因为天气不好，今天不出门，改在家看电影吧。
- 勉強せずに、遊んでいます。  
  不学习，一直在玩。

这些句子分别相当于`～ないで`：

- 砂糖を入れないで、コーヒーを飲みます。
- 出かけないで、家で映画を見ましょう。

# 2. ～ず：原因或否定并列

- 旅行に行けず、残念です。  
  因为没能去旅行，所以很遗憾。
- この部屋は水も出ず、電気も使えません。  
  这个房间既没有水，也不能用电。

这些句子分别相当于`～なくて`：

- 旅行に行けなくて、残念です。
- 水も出なくて、電気も使えません。

# 特别变化：する→せず

`する`的否定不是`しず`，而是：

- `勉強する` → `勉強せず／勉強せずに`
- `運動する` → `運動せず／運動せずに`

例如：

- 彼は何も言わずに帰りました。  
  他什么也没说就回去了。

# 与相关形式的区别

- `～ないで`：较口语，表示不做……而……。
- `～ずに`：意思相近，但较正式、书面。
- `～なくて`：表示原因或否定并列。
- `～ず`：相当于较正式的`～なくて`。

# JLPT N4 提示

- `ない形去ない＋ず／ずに`。
- `ずに`中的`に`可以省略，也可以保留，形成`ず`与`ずに`两种形式。
- `する`要变成`せず／せずに`。
- `～ずに`主要对应`～ないで`；`～ず`主要对应`～なくて`。
