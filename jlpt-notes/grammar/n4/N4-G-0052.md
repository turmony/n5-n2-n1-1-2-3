# 核心

`名词Aと名词B（と）どちらが～ですか`表示“两者中哪一个……？”`どちら`是“哪一方／哪一个”，用于两个对象之间的比较、喜好、判断或选择。

# 接续

- 标准形式：`名词Aと名词Bとどちらが＋谓语ですか`
- 口语省略：`名词Aと名词B、どちらが＋谓语ですか`

第二个`と`在口语中有时省略，但正式、完整的形式常保留。

# 例句

- 犬と猫とどちらが好きですか。  
  狗和猫，你喜欢哪一个？
- 犬のほうが好きです。  
  我更喜欢狗。
- 明日のサッカーの試合、日本とブラジルとどちらが勝つと思いますか。  
  你觉得明天的足球比赛，日本和巴西哪一方会赢？
- もちろん、ブラジルが勝つでしょう。  
  当然是巴西会赢吧。
- お父さんとお母さん、どちらが優しいですか。  
  爸爸和妈妈，哪一位更温柔？

# 回答方式

- 选择 A：`Aのほうが～です`
- 选择 B：`Bのほうが～です`
- 两者都：`どちらも～です`
- 两者都不：`どちらも～ないです／どちらも～ではありません`

例如：

- どちらも優しいです。  
  两位都很温柔。
- どちらも好きではありません。  
  两个都不喜欢。

# 语义边界

本句型专门用于“两者之中哪一个”。如果选项超过两个，通常使用：

- `どれが好きですか`：喜欢哪一个？
- `どのスポーツが好きですか`：喜欢哪种运动？

此外：

- `犬と猫とどちらが好きですか`：两者中更喜欢哪一个？
- `犬と猫、どちらにしますか`：狗和猫，你选择哪一个？

前者询问比较或喜好，后者询问实际选择。

# 相关表达

- `どちら`：较礼貌、正式的“两者哪一个／哪一方”。
- `どっち`：口语说法，语气更随意。
- `どちらも`：两者都。

# JLPT N4 提示

- `どちら`通常只比较两个对象。
- 标准形式常见`AとBとどちらが～ですか`。
- 第二个`と`在口语中可以省略。
- 回答比较时常用`A／Bのほうが～です`。
- `どちらも`表示“两者都”。
