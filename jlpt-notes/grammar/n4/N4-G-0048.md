# 核心

`动词辞书形／ない形＋ようにしてください`表示礼貌地请求对方尽量做到某事、注意确保某种状态，或避免某种结果，可译为“请尽量……／请注意……／请务必不要……”。

# 接续

- 动词辞书形＋ようにしてください  
  `するようにしてください`
- 动词ない形＋ようにしてください  
  `飲まないようにしてください`

否定形式直接使用动词的`ない形`：

- `忘れない＋ようにしてください` → 忘れないようにしてください
- `遅れない＋ようにしてください` → 遅れないようにしてください

# 例句

- 毎日運動するようにしてください。  
  请尽量每天运动。
- お酒を飲まないようにしてください。  
  请尽量不要喝酒。
- 忘れないようにしてください。  
  请注意不要忘记。
- 明日までにレポートを出すようにしてください。  
  请务必在明天之前提交报告。

# 语义边界

`～ようにしてください`通常用于需要对方努力、持续注意或避免某种结果的情况：

- 毎日薬を飲むようにしてください。  
  请注意每天吃药。
- 遅れないようにしてください。  
  请注意不要迟到。

如果只是一次性的直接请求，通常使用`～てください`或`～てもらえませんか`更自然：

- ちょっと傘を貸してください。  
  请借我一下伞。
- ちょっと傘を貸してもらえませんか。  
  可以请你借我一下伞吗？

`ちょっと傘を貸すようにしてください`并非完全无法理解，但不适合普通的一次性借伞请求，听起来像要求对方“设法确保借伞这件事”。

# 与相关句型的区别

- `毎日運動するようにします。`  
  我会尽量每天运动。→ 自己努力。
- `毎日運動するようにしてください。`  
  请尽量每天运动。→ 请求别人努力。
- `毎日運動してください。`  
  请每天运动。→ 更直接的请求或指示。

# JLPT N4 提示

- `～ようにしてください`是礼貌请求，不是单纯描述目的。
- 前项常用辞书形或`ない形`。
- 对方需要努力、持续注意或避免某种结果时，适合使用本句型。
- 一次性、直接的请求通常用`～てください`。
