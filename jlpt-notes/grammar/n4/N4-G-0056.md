# 核心

`普通形＋と思います`表示说话人的想法、判断、推测或意见，可译为“我认为……／我觉得……／我想……”。

# 接续

- 动词普通形＋と思います  
  `来ると思います`、`来ないと思います`
- い形容词普通形＋と思います  
  `おいしいと思います`
- な形容词＋だ＋と思います  
  `大切だと思います`
- 名词＋だ＋と思います  
  `学生だと思います`

这里的`【普通形（だ，だ）】`表示：**な形容词和名词的现在肯定形保留`だ`**。

- `大切だ` → `大切だと思います`
- `学生だ` → `学生だと思います`

# 例句

- 台風が来ますから、明日の試合は中止になると思います。  
  因为台风要来，我觉得明天的比赛会取消。
- この辞書は使いにくいと思います。  
  我觉得这本词典不好用。
- お金よりも健康のほうが大切だと思います。  
  我认为健康比金钱更重要。

# 询问意见

- 日本の食べ物についてどう思いますか。  
  你觉得日本食物怎么样？
- おいしいと思います。  
  我觉得很好吃。

# 相关语法：意向形＋と思っています

`意向形＋と思っています`是相关的意向表达，表示已经有计划或打算做某事：

- 将来自分の店を持とうと思っています。  
  我打算将来拥有自己的店。
- 来年、日本へ行こうと思っています。  
  我计划明年去日本。

本卡的核心是`普通形＋と思います`；`意向形＋と思っています`只作为相关语法了解。

# 易混项

- `～と思います`：认为、觉得、推测。
- `～と思っています`：一直这样想、打算。
- `～と言います`：说……，传达话语内容。
- `～つもりです`：明确的计划或打算。

# JLPT N4 提示

- 表示意见、判断、推测：`普通形＋と思います`。
- な形容词和名词现在肯定接续：`だ＋と思います`。
- `どう思いますか`是询问意见的常见表达。
