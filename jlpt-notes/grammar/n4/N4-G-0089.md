# 学习者原始输出

【普通形（な，の）】+はずます/はずがあります。前者表示应该... 可以表示推测或当然，后者表示不可能... ，也可以用于自己不相信某个事实

# 核心

- `～はずです`：根据已有信息、常识或逻辑作出有根据的预期，表示“应该……／按理说会……”。
- `～はずがありません`：表示从逻辑、常识或已知事实来看“不可能……／不应该……”，是强烈否定。
- `～はずがない` 是 `～はずがありません` 的普通体。

`はず` 表示说话人的判断或预期，并不保证事实一定如此。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + はずです／はずがありません | 来るはずです／来るはずがありません |
| い形容词 | 普通形 + はずです／はずがありません | 高いはずです |
| な形容词 | 词干 + `な` + はずです | 静かなはずです |
| 名词 | 名词 + `の` + はずです | 学生のはずです |

な形容词、名词的否定和过去形式按普通形接续：

- 静かではないはずです
- 学生だったはずです
- 学生ではないはずがありません

# ～はずです：用法一，有根据的推测

根据已知信息，判断某事应该会发生或应该处于某种状态。

- 田中さんはさっき電車に乗ったと言っていましたから、もうすぐこちらに着くはずです。  
  田中刚才说他上了电车，所以应该很快会到这里。
- 全国的に天候も順調だったので、野菜の値段は高くないはずです。  
  全国天气都很顺利，所以蔬菜价格应该不会高。

# ～はずです：用法二，按常理应该如此

表示从眼前的情况或常识判断，某结果理应成立。

- ストーブをつけても、まだ寒いですね。  
  そうですね。ああ、寒いはずです。あそこの窓が開いていますよ。  
  即使开了暖炉还是很冷啊。  
  是啊，按理说会冷，因为那边的窗户开着。

# ～はずがありません：强烈否定可能性

`～はずがありません` 表示说话人从逻辑、常识或已知事实判断，认为某事“不可能……／不应该……”。

- 天性の才能があって、誰よりも練習してきた彼が負けるはずがありません。  
  他天赋很好，又比任何人都努力练习，不可能会输。
- あの温厚な彼がそんなことをするはずがありません。  
  那么温和的他不可能做那种事。

# 语义边界

- `～はずです` 不是命令或义务。  
  `行くはずです`：按理说他会去。  
  `行くべきです`：应该去，这是义务或建议。
- 过去的 `～たはず` 可表示“我记得应该已经……”，即使现实结果与预期不同。  
  鍵は机の上に置いたはずだけど、ありません。  
  我记得应该把钥匙放在桌上了，但没有。
- `～はずがありません` 常用于对意外事实表示难以相信，而非客观证明事实绝对不可能。

# JLPT N4 提示

- 看到 `な形容词 + なはず`、`名词 + のはず`，不要误接 `だ`。
- `～はずです` 选“有依据的应该”；`～はずがありません` 选“按理不可能”。
- 若句意是义务、责任或道德上的“应该”，通常考虑 `～べきです`，而不是 `～はずです`。
