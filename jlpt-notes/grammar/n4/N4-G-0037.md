# 核心

`Aは Bに 动词て形＋やります`表示A为B做某事，而B是相对下位者、晚辈、孩子、宠物、植物等，即“为晚辈等做……”。

A是施惠者，B是受惠者；B不能和A是同一个人。

# 接续

动词て形＋やります

- 教えます → 教えてやります
- 買います → 買ってやります
- 散歩します → 散歩してやります
- 手伝います → 手伝ってやります

# 例句

- 私は息子に英語を教えてやりました。  
  我教儿子英语了。
- 妹に宿題を手伝ってやりました。  
  我帮妹妹做作业了。
- 犬を散歩させてやりました。  
  我带狗散步了。
- 花に水をやりました。  
  我给花浇水了。

`水をやります`是给植物浇水的常用表达。

# 与「～てあげます」的区别

| 形式 | 对受惠者的关系与语气 |
| --- | --- |
| `～てあげます` | 中性地为别人做事。 |
| `～てやります` | 为晚辈、孩子、宠物、植物等做事；语气较随便。 |

对朋友使用`～てあげます`更稳妥。对长辈、上司、老师或不熟的人不能使用`～てやります`，否则会显得不尊重、居高临下。

# 另一种「～てやる」

`～てやる`还可以表示“我非要做给你看／我来做”，带有强硬的意志或决心；这不是本课的授受用法。

- 絶対に勝ってやる。  
  我一定要赢给你看。

# JLPT N4 提示

- 本课的`～てやります`接动词て形。
- 先确认受惠者是否为晚辈、孩子、宠物或植物等。
- 与`～てあげます`相比，`～てやります`的敬意更低、语气更随便。
