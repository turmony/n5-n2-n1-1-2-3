# 核心

意向形主要表示“做……吧”“打算做……”。本课重点是按照一类、二类、三类动词进行变形。

# 1. 一类动词（五段动词）

将词尾的`う段`变成`お段`，再加`う`：

| 辞书形 | 意向形 |
| --- | --- |
| 書く | 書こう |
| 飲む | 飲もう |
| 話す | 話そう |
| 待つ | 待とう |
| 帰る | 帰ろう |
| 買う | 買おう |

特别注意：

- `う`→`おう`：買う→買おう
- `る`→`ろう`：帰る→帰ろう

# 2. 二类动词（一段动词）

去掉`る`，加`よう`：

- 食べる→食べよう
- 見る→見よう
- 起きる→起きよう
- 寝る→寝よう

# 3. 三类动词（不规则动词）

- する→しよう
- 来る（くる）→来よう（こよう）

# 4. い形容词、な形容词和名词的补充形式

有些教材会把非动词谓语的相关形式也放在“意向形”这一组中。严格说，下面的形式主要表示**推量**，即“恐怕……吧／大概……”，不表示动词意向形的“做……吧／打算做……”。

- 现代日语的い形容词：直接＋`だろう`
  - 高い→高いだろう
  - おいしい→おいしいだろう
- `去い＋かろう`是较文语、书面或古风的形式，现代日常会话不作为主要形式：
  - 高い→高かろう
  - よい→よかろう
- な形容词：词干＋`だろう`
  - 静かだ→静かだろう
  - 便利だ→便利だろう
- 名词：名词＋`だろう`
  - 学生だ→学生だろう
  - 先生だ→先生だろう

这些形式与动词意向形的意义不同：

- 行こう：走吧／打算走。
- 高いだろう：大概很高吧。（现代日语主要形式）
- 高かろう：大概很高吧。（较文语、书面或古风）
- 学生だろう：应该是学生吧。

# 与礼貌体的对应

意向形的礼貌表达通常是`～ましょう`：

- 行こう→行きましょう
- 食べよう→食べましょう
- しよう→しましょう

# 易混点

- 意向形不是所有动词都直接加`よう`。
- 一类动词要变成`お段＋う`。
- 二类动词才是去掉`る`后加`よう`。
- `する`和`来る`需要单独记忆。

# JLPT N4 提示

- 一类：词尾う段→お段＋う。
- 二类：去る＋よう。
- 三类：する→しよう，来る→こよう。
- 看到`～ましょう`时，可以联想到普通体意向形`～よう／～おう`。
- 现代日语中，い形容词主要直接接`～だろう`；`～かろう`较文语、书面或古风。
- 这些非动词形式属于补充的推量表达，不要和动词意向形混为一谈。
