# 核心

`～さ`把形容词名词化，表示某种性质的程度、大小或具体特征，可译为“……的程度／……的大小／……之处”。

# 接续

- い形容词去`い`＋`さ`  
  `高い` → `高さ`；`長い` → `長さ`；`暑い` → `暑さ`
- な形容词去`な`＋`さ`  
  `便利な` → `便利さ`；`静かな` → `静かさ`；`大変な` → `大変さ`

# 例句

- 富士山の高さは三千七百七十六メートルです。  
  富士山的高度是3776米。
- 前髪の長さはどうしますか。  
  刘海的长度要怎么处理？
- 子どもが生まれて、子育ての大変さがわかりました。  
  孩子出生后，我明白了育儿的辛苦。
- この箱の大きさはどのくらいですか。  
  这个箱子的大小是多少？

# 特殊形式

- `いい` → `よさ`，不能说`いさ`。
- `ない` → `なさ`。

`～さ`形成的是名词，可以作主语、宾语或与助词搭配：

- 高さがわかりません。  
  不知道高度。
- 大変さがわかりました。  
  明白了辛苦之处。
- 長さを測ります。  
  测量长度。

# 与「～み」的区别

- `高さ／長さ／大きさ`：较客观、可测量的程度。
- `悲しみ／苦しみ`：较偏内在感受或体验。
