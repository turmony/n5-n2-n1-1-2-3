# 核心

数量词后接不同助词，可以表达大约、限定、最低限度或超出预期等意思。本课总结六种形式：

1. `数量词＋ぐらい／くらい`：大约、左右。
2. `数量词＋ほど`：大约、左右，语气稍正式。
3. `数量词＋だけ`：只有、仅仅。
4. `数量词＋しか＋否定`：只有，强调数量少，带有“轻、薄、短、小、少／不足”的语气。
5. `数量词＋は`：至少、最低限度。
6. `数量词＋も`：多达、足足，强调数量多，带有“重、厚、长、大、多／超出预期”的语气。

# 例句与用法

## 1. 数量词＋ぐらい／くらい

- 東京から福岡まで新幹線で5時間ぐらいかかります。  
  从东京到福冈坐新干线大约需要5小时。

`ぐらい`和`くらい`意思基本相同。

## 2. 数量词＋ほど

- すみませんが、あと10分ほど待ってください。  
  不好意思，请再等大约10分钟。

`10分ほど`和`10分ぐらい`意思接近，但`ほど`稍正式。

## 3. 数量词＋だけ

- あなたと私、二人だけで話がしたいです。  
  我想只和你两个人谈谈。

`だけ`后面可以接肯定形式：`一人だけ来ました`。

## 4. 数量词＋しか＋否定

- 私は貯金が1万円しかありません。  
  我只有1万日元存款。

`しか`后面的谓语必须使用否定形式；本项强调数量少、不足，带有“轻、薄、短、小、少”的语气。

- × 1万円しかあります。

## 5. 数量词＋は

- 車の修理に2週間はかかります。  
  修车至少需要两周。

`2週間は`表示两周是最低限度，实际可能更久。

## 6. 数量词＋も

- 彼は貯金が1000万円もあります。  
  他竟然有1000万日元存款。

`1000万円も`强调数量多、超出预期，带有“重、厚、长、大、多”的语气。

# 六种形式对比

| 形式 | 主要意思 | 例句 |
| --- | --- | --- |
| `数量词＋ぐらい` | 大约、左右 | 5時間ぐらい |
| `数量词＋ほど` | 大约、左右，稍正式 | 10分ほど |
| `数量词＋だけ` | 只有、仅仅 | 二人だけ |
| `数量词＋しか＋否定` | 只有，强调少、不足 | 1万円しかありません |
| `数量词＋は` | 至少、最低限度 | 2週間はかかります |
| `数量词＋も` | 多达、足足，强调多、超出预期 | 1000万円もあります |
