# 核心

谦让语通过降低自己或自己一方的动作，间接表示对对方的尊敬。图片将其分为两类：动作涉及尊敬对象的谦让语Ⅰ，以及动作不直接涉及尊敬对象、但向听话人郑重表达的谦让语Ⅱ（丁重语）。

# 1. 谦让语Ⅰ：动作涉及对方

自己的动作直接指向或影响应受尊敬的人。

## ① お／ご～します

### 接续

- `お＋动词ます形去ます＋します`
- `ご＋动作性名词＋します`

### 例子

- コーヒーをお入れします。  
  我来给您冲咖啡。
- この件は私がご説明します。  
  这件事由我向您说明。

和语动词一般使用`お`，汉语动作性名词一般使用`ご`。

## ② 专用谦让语

- 明日15時にそちらへ伺います（うかがいます）。  
  明天十五点去您那里拜访。

这里的`伺います`降低说话人的动作，同时尊敬动作所涉及的对方。

# 2. 谦让语Ⅱ（丁重语）：动作不涉及对方

自己的动作没有直接作用于尊敬对象，但为了礼貌地向听话人叙述，而使用郑重、谦逊的表达。

## ① 使役て形＋いただきます

表示在得到对方允许、理解或关照的情况下做某事。

- お先に帰らせていただきます。  
  请允许我先回去。
- 来週、休ませていただきます。  
  请允许我下周休息。

## ② 使役て形＋いただけませんか

用于非常礼貌地请求对方允许自己做某事。

- 来週、休ませていただけませんか。  
  下周能允许我请假吗？

## ③ 专用丁重语

- 明日はずっと家におります。  
  明天我会一直在家。

这里的动作并不直接涉及听话人，但用`おります`代替`います`，使表达更加郑重。

# 主要谦让语对照

| 普通表达 | 谦让语 |
|---|---|
| します | いたします（致します） |
| 食べます・飲みます | いただきます |
| もらいます | いただきます |
| あげます | さしあげます（差し上げます） |
| います | おります |
| 思います | ぞんじます（存じます） |
| 知っています | ぞんじています（存じています） |
| 見ます | はいけんします（拝見します） |
| 行きます・来ます | まいります（参ります） |
| 对方所在处へ行きます・来ます | うかがいます（伺います） |
| 聞きます・尋ねます | うかがいます（伺います） |
| 言います | もうします（申します）／もうしあげます（申し上げます） |

# 重要区别

## ① 参ります与伺います

- `まいります（参ります）`属于丁重语，郑重地表达自己的移动，目的地不一定是尊敬对象所在之处。
- `うかがいます（伺います）`表示前往尊敬对象所在之处，动作直接涉及对方；还可以表示“请教、询问”。

例：

- 明日、東京へ参ります。  
  明天去东京。
- 明日、先生のお宅へ伺います。  
  明天去老师家拜访。

## ② 申します与申し上げます

- `もうします（申します）`属于丁重表达，常用于郑重地说出自己的姓名、身份等。
- `もうしあげます（申し上げます）`的动作明确指向对方，谦让程度更高。

例：

- 私は王と申します。  
  我姓王。
- 心からお礼を申し上げます。  
  衷心向您表示感谢。

## ③ いたします与なさいます

- `します→いたします（致します）`：谦让语，用于自己或自己一方的动作。
- `します→なさいます`：尊敬语，用于应受尊敬者的动作。

# 易混点

- 谦让语用于自己或自己一方的动作，目的不是抬高自己，而是降低己方、尊敬对方。
- 与外部人员交谈时，也可以对己方家人、同事的相关动作使用谦让语。
- `いただきます`既可以对应`食べます／飲みます`，也可以对应`もらいます`，需要根据宾语和语境判断。
- `うかがいます（伺います）`对应`聞きます`时，主要表示“请教、询问”，不能机械替换所有“听”的用法。

# JLPT N4 提示

- 先判断动作是否涉及尊敬对象，再区分谦让语Ⅰ和谦让语Ⅱ。
- 重点记忆`まいります／うかがいます`和`もうします／もうしあげます`的区别。
- 注意尊敬语与谦让语的主语不同：`なさいます`用于对方，`いたします`用于己方。
- 掌握图片中的主要专用谦让语及其普通形式。
