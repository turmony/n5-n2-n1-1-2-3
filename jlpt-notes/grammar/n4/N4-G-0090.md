# 学习者原始输出

【普通形】+し，【普通形】+し　表示理由，评价的列举，也可以只列举一个

# 核心

`～し、～し` 用于列举多个理由、事实或评价，再引出结论、判断、建议或行动。

除了明确列出多个项目外，也可以只说一个 `～し`；此时往往暗示“除此以外还有其他理由”，语气比单用 `から` 更委婉、保留余地。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + `し` | 雨が降っているし |
| い形容词 | 普通形 + `し` | 安いし |
| な形容词 | 词干 + `だし` | 便利だし |
| 名词 | 名词 + `だし` | 日曜日だし |

礼貌体中也可使用 `ますし／ですし`：

- 雨も降っていますし、タクシーで行きましょう。
- この店は便利ですし、よく利用します。

# 用法一：列举理由

列举多个原因，说明为什么作出某个判断、建议或行动。

- 時間もないし、雨も降っているし、タクシーで行こう。  
  没时间了，又在下雨，坐出租车去吧。
- 今日は日曜日だし、銀行は休みだと思います。  
  今天是星期日，我想银行也休息。

# 用法二：列举评价

列举事物的优点、缺点或特征，以表达整体评价。

- 北海道は景色もいいし、食べ物もおいしいし、それに物価も安い。  
  北海道风景好，食物也好吃，而且物价也便宜。
- このホテルは駅から近いし、部屋もきれいだし、便利です。  
  这家酒店离车站近，房间也干净，很方便。

# 只列举一个理由

只用一个 `し` 时，通常暗示还有未说出口的其他理由。

- もう遅いし、そろそろ帰ります。  
  已经很晚了，而且还有别的原因，所以我差不多该回去了。
- 今日は疲れたし、外食しよう。  
  今天累了，而且还有别的考虑，出去吃吧。

# 易混点

- `～から`：直接说明一个主要原因。  
  雨が降っているから、タクシーで行こう。  
  因为下雨，所以坐出租车去吧。
- `～し`：列举理由，或暗示还有其他理由。  
  雨も降っているし、タクシーで行こう。  
  在下雨嘛，坐出租车去吧。

# JLPT N4 提示

- な形容词、名词接 `し` 时用 `だし`，不能用 `なし／のし`。  
  ○ 便利だし  
  ○ 日曜日だし
- 句中出现两个或以上的 `し`，通常是在列举理由或评价。
- 只有一个 `し` 时，也不代表错误；要理解其“还有别的理由”的语感。
