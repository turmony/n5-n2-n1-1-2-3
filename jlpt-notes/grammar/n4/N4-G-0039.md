# 核心

`Aは Bに 动词て形＋いただきます`表示A谦逊地得到B为自己做某事的帮助，即“承蒙B为我做……”。

`～ていただきます`是`～てもらいます`的谦逊表达，而不是`～てあげます`的对应形式。

A是受惠者，B是施惠者／动作执行者。B通常是老师、上司、长辈、客户等需要表示敬意的人。

# 接续

动词て形＋いただきます

- 教えます → 教えていただきます
- 見せます → 見せていただきます
- 読みます → 読んでいただきます

名词＋を いただきます也表示谦逊地“得到／接受……”。

- 先生に本をいただきました。  
  我从老师那里得到了书。

# 例句

- 私は清水先生に日本語を教えていただきました。  
  我承蒙清水老师教我日语。
- 部長に推薦状を書いていただきました。  
  我承蒙部长帮我写了推荐信。

# 与「～てもらいます」的区别

| 形式 | 语气 |
| --- | --- |
| `～てもらいます` | 中性地得到别人帮助。 |
| `～ていただきます` | 谦逊地得到长辈、上司、老师等的帮助。 |

- 私は友達に料理を作ってもらいました。  
  我请朋友给我做了饭。
- 私は先生に料理を作っていただきました。  
  我承蒙老师为我做了饭。

# 使用注意

`いただきます`是说话者谦逊地表达“自己得到帮助”，同时对B表示敬意。

对自己的家人一般不使用`～ていただきます`来抬高对方，通常说`～てもらいます`即可。

- 私は母に料理を作ってもらいました。  
  我请妈妈给我做了饭。

B不能和A是同一个人。

# 委婉请求：～て いただけませんか

`いただけます`是`いただきます`的可能形。`动词て形＋いただけませんか`可非常礼貌地请求对方。

- もう一度説明していただけませんか。  
  能否请您再说明一次？

# JLPT N4 提示

- `～ていただきます`接动词て形。
- 重点是“我谦逊地接受他人的帮助”，与`～てもらいます`的受惠者视角相同。
- 看到老师、上司、客户等施惠者时，可优先考虑`～ていただきます`。
