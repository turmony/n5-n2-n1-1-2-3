# 核心

`Aは Bに 动词て形＋あげます`表示A出于好意为B做某事，B从这个动作中受益，即“A帮B……／A为B……”。

A是施惠者，B是受惠者。

# 接续

动词て形＋あげます

- 持ちます → 持ってあげます
- 作ります → 作ってあげます
- 洗います → 洗ってあげます
- 送ります → 送ってあげます

# 基本用法

- 私は友達に料理を作ってあげました。  
  我给朋友做了饭。
- 荷物を持ってあげます。  
  我帮你拿行李。
- 荷物を持ちましょうか。  
  我帮您拿行李好吗？

主动提出帮助时，`～ましょうか`比直接说`～てあげます`更自然。

# 受惠者「Bに」不另出现的情况

受惠者已经由其他成分明确表示时，句中通常不再另加`Bに`。

## 1. 受惠者同时是动词的对象

- 私は友達を駅まで送ってあげました。  
  我送朋友到车站了。

`友達を`是`送ります`的对象；朋友也正是从“送到车站”这一动作中受益的人。因此不另说`友達に`。

## 2. 受惠者由所属关系表明

- 私は友達の服を洗ってあげました。  
  我帮朋友洗了衣服。

`友達の服`表示朋友的衣服，`友達`已通过所属关系表明是受惠者。此时通常不必再加`友達に`；说成`友達に友達の服を`会显得重复、不自然。

# 易混项

| 形式 | 视角与含义 |
| --- | --- |
| `～てあげます` | 我／某人为别人做事。 |
| `～てもらいます` | 我请别人为我做事，或得到别人的帮助。 |
| `～てくれます` | 别人为我／我方的人做事。 |

- 私は友達に料理を作ってあげました。  
  我给朋友做饭。
- 私は友達に料理を作ってもらいました。  
  我请朋友给我做饭。
- 友達が料理を作ってくれました。  
  朋友给我做饭了。

# 使用注意

对长辈、上司等地位较高的人直接使用`～てあげます`，有时会有“施恩”的语感。此类场合应选择更谦逊、礼貌的表达。

# JLPT N4 提示

- `～てあげます`接动词て形。
- 判断受惠者时，先找“谁从这个动作中获益”。
- 当受惠者已经出现在`～を`或`～の`等成分中时，通常不另用`～に`重复表示。
