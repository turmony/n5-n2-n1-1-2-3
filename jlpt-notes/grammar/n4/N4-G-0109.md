# 学习者原始输出

N4第109个语法：【普通形（去だ，去だ）】+かい？。【普通形（な，な）+ん】/疑问词+だい？表示疑问，上对下的

# 核心

**`～かい？／～んだい？／疑问词 + だい？`都是口语疑问表达。**

多用于男性对晚辈、孩子、部下或关系亲近的人说话。语气可以亲切、关心，但对长辈、老师、客户或不熟悉的人使用，会显得随便甚至居高临下。

# 1. ～かい？：……吗？

用于一般询问。语气比单纯的 `～か？`更柔和一些，但仍是较随意、男性化的表达。

## 接续

| 词类 | 接续 |
| --- | --- |
| 动词、い形容词 | 普通形 + かい？ |
| な形容词、名词 | 词干／名词 + かい？ |

な形容词、名词现在肯定时去掉 `だ`。

- おなかが空いたかい？  
  饿了吗？
- おお、久しぶり。元気だったかい？  
  哦，好久不见。你还好吗？
- 君は学生かい？  
  你是学生吗？

# 2. ～んだい？：……呢？／为什么……？

`んだい`来自 `のだ`，常用于询问事情的原因、背景或具体情况，带有“到底是怎么回事？”的语气。

## 接续

| 词类 | 接续 |
| --- | --- |
| 动词、い形容词 | 普通形 + んだい？ |
| な形容词、名词 | 词干／名词 + な + んだい？ |

- どうして泣いているんだい？  
  你为什么在哭呢？
- どこが痛いんだい？  
  哪里疼呢？

# 3. 疑问词 + ～だい？

直接询问不知道的内容，常见于 `何だい？／どこだい？／いつだい？`。

- 手に持っているそれは何だい？  
  你手里拿着的那个是什么？

# 易混项

| 形式 | 语气 |
| --- | --- |
| `～ですか／～ますか` | 一般礼貌提问，适用范围广。 |
| `～かい？` | 随意、男性化的一般提问。 |
| `～んだい？` | 随意、男性化；更强调询问原因、背景或情况。 |
| `～でしょうか` | 委婉、正式的礼貌提问。 |

# JLPT N4 提示

- `～かい／～だい`主要考查说话人关系和语气：常见于长辈对晚辈、上司对下属。
- `んだい`前，な形容词和名词要接 `な`：静かなんだい？／学生なんだい？
- `何だい？`中的 `だい`直接接疑问词，不需要加 `ん`。
- 对老师、客户等应改用 `ですか／ますか／でしょうか`。
