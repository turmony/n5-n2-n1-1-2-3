# 学习者原始输出

【普通形（去だ，去だ）】+だろう。有两种用法。1：推测（语调降调）。2：要求对方同意（语调升调）

# 核心

`～だろう` 是普通体的推测、确认表达，相当于“……吧／大概……／……对吧？”。

它有两种主要用法：

1. 句末降调：表示推测，“大概……吧”。
2. 句末升调：向对方确认并期待对方认同，“……对吧？”。

# 接续

| 词类 | 接续 | 例子 |
| --- | --- | --- |
| 动词 | 普通形 + `だろう` | 降るだろう／降らないだろう |
| い形容词 | 普通形 + `だろう` | 寒いだろう |
| な形容词 | 词干 + `だろう` | 静かだろう |
| 名词 | 名词 + `だろう` | 学生だろう |

な形容词和名词原有的 `だ` 不重复使用：

- × 静かだだろう  
  ○ 静かだろう
- × 学生だだろう  
  ○ 学生だろう

# 用法一：推测（降调）

说话人根据情况判断某事大概如此，但不完全确定。句末语调下降。

- 明日は雨が降るだろう。  
  明天大概会下雨吧。
- 4月の北海道はまだ寒いだろう。  
  四月的北海道应该还很冷吧。
- 彼の言っていることは本当だろう。  
  他说的话大概是真的吧。

# 用法二：要求对方确认、同意（升调）

说话人认为对方应该同意某个事实，或带着质问、提醒的语气向对方确认。句末语调上升，常写作 `だろう？`。

- 先月5千円貸しただろう？ 早く返してくれよ。  
  上个月我借给你五千日元了吧？快还我。
- ほら、痛くないだろう？  
  你看，不疼吧？
- そんな言い方は失礼だろう？  
  那种说法很失礼吧？
- 登山っておもしろいね。  
  だろう？ 次は筑波山に登ってみようよ。  
  爬山很有意思呢。  
  对吧？下次去爬筑波山吧。

# 语义边界

- `だろう` 是普通体，常用于熟人之间、自言自语或较随意的场合。对上级、陌生人或正式场合，通常用更礼貌的 `でしょう`。
- 升调的 `だろう？` 有时会显得较强势，尤其是在责问或要求对方承认事实时。
- `だろう` 表示推测，不等于百分之百确定的事实。

# 与「でしょう」的区别

| 形式 | 语气 |
| --- | --- |
| `だろう` | 普通、随意，有时较男性化或强势 |
| `でしょう` | 更礼貌、柔和，适用范围更广 |

- 明日は雨が降るでしょう。  
  明天大概会下雨吧。（较礼貌）

# JLPT N4 提示

- 看到 `だろう`，先根据语调和上下文判断：是“推测”，还是“对吧？”的确认。
- な形容词、名词接 `だろう` 时不可重复加 `だ`。
- 要求礼貌表达时，优先选择 `でしょう`。
