# 学习者原始输出

お/ご+名词/动词/形容词等，有三种用法。1，美化。2，尊敬。3，谦让。

# 核心

`お／ご`可接名词、动词、形容词等，主要有美化语、尊敬语、谦让语三种作用。`お／ご`本身不自动决定敬意类型，必须根据所指对象、句子主语及后续表达判断。

# 三种用法

| 用法 | 判断重点 | 例子 |
|---|---|---|
| 美化语／郑重语 | 不特别抬高某个人，只使表达文雅、柔和 | お金、お酒、お買い物、ご飯 |
| 尊敬语 | 抬高对方、上级或第三者的事物、状态或动作 | お名前、お仕事、お忙しい、お待ちです、ご出席になります |
| 谦让语 | 用于自己为对方做的动作，降低自己 | お渡しします、お願いします、ご説明します |

# 用法与例句

## ① 美化语／郑重语

お茶はいかがですか。  
茶怎么样？

`お茶`不一定表示“对方的茶”，主要使说法显得文雅、客气。

## ② 尊敬语

先生はただ今、お忙しいです。  
老师现在很忙。

`お忙しい`抬高老师的状态。`お待ちです`、`お読みになります`等也用于对方的动作或状态。

## ③ 谦让语

資料をお渡しします。  
我把资料交给您。

`お渡しします`表示说话人把资料交给对方，动作朝向并服务于尊敬对象。

# お与ご的选择

- 和语词一般使用`お`：お名前、お待ち、お読み
- 汉语词一般使用`ご`：ご心配、ご出席、ご説明
- 存在固定例外，不能只凭词源机械判断，例如`お電話`。

# 易混点

- `お仕事`等词必须看语境：说对方的工作时可表示尊敬；一般谈“工作”时也可能只是美化。
- 谦让用法中的`お／ご～します`仍须符合“动作朝向、服务于或涉及尊敬对象”的条件；详见N4-G-0081。
- 并不是所有词都能任意加`お／ご`，应优先记忆固定搭配，如`お金／ご飯／お名前／ご心配／ご説明します`。

# JLPT N4 提示

- 判断题先看“是谁的事物、谁的动作”：对方一方通常是尊敬，自己一方为对方做事通常是谦让。
- 没有明确敬意对象、主要使措辞文雅时，多为美化语。
- 题目常考`お／ご`的搭配及同一前缀在不同语境中的功能。
