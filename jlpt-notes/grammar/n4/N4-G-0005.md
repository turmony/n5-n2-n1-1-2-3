# 核心

`动词ます形去ます + やすいです`表示“容易……／很容易……”。`～やすい`整体是一个い形容词。

# 接续

- 書きます → 書きやすいです
- 食べます → 食べやすいです
- 分かります → 分かりやすいです

# 两类常见含义

## 1. 动作容易进行

- このボールペンは書きやすいです。  
  这支圆珠笔很好写／容易用来写字。

## 2. 某种情况容易发生

- このコップは割れやすいです。  
  这个杯子容易碎。

这里表达的是物品具有容易破碎的性质或倾向，不是说它已经实际碎了很多次。

# 活用

`～やすい`按い形容词活用：

| 形式 | 例句 |
| --- | --- |
| 现在肯定 | このペンは書きやすいです。 |
| 现在否定 | このペンは書きやすくないです。 |
| 过去肯定 | このペンは書きやすかったです。 |
| 过去否定 | このペンは書きやすくなかったです。 |

# 易混项

- `～やすい`：容易做……
- `～にくい`：难做……

このペンは書きにくいです。  
这支笔不好写／难写。

# JLPT N4 提示

- 不接动词辞书形，必须接动词ます形去掉「ます」后的词干。
- `やすい`是可活用的い形容词，不是副词。
- 描述物品性质时，可译为“好……／容易……／易于……”。
