# 学习者原始输出

N4第120个语法：讲的是动词变化的顺序，由图得知只能从顺位1到顺位6的变化次序，同一个顺位中的变化形式只能选择一种，红色的代表之后不能再进行变化。使役形的可能形/受身形/尊敬形的后续变化都要视作二类动词进行变化。否定形后的变化都要视作い形容词的变化。将图中的顺位表格需要画出来

# 核心

动词的各种变化有固定的优先顺序：**只能从顺位1依次向后变化；同一顺位只能选一种形式。** 红色形式表示在这张“再变化”图中不能继续作后续变化。

| 顺位1 | 顺位2 | 顺位3 | 顺位4 | 顺位5 | 顺位6 |
| --- | --- | --- | --- | --- | --- |
| 使役形 | 可能形 | 丁宁形（ます形） | 命令形（终止） | て形（终止） | 条件形（终止） |
|  | 受身形 |  | 肯定形／辞书形 | 过去形 |  |
|  | 尊敬形 |  | 否定形（ない形） | 意向形（终止） |  |
|  |  |  | 禁止形（终止） |  |  |

```text
原形 → 使役形 → 可能／受身／尊敬形 → ます形
                              ↓
                 命令／辞书／否定／禁止形
                              ↓
                   て形／过去形／意向形
                              ↓
                           条件形
```

# 核心规则

1. **按顺位从左到右变化**  
   `話す → 話せる → 話せます → 話せません`  
   原形 → 可能形（顺位2）→ 丁宁形（顺位3）→ 否定形（顺位4）。

2. **同一顺位只能选一种**  
   顺位2的可能、受身、尊敬三者不能并列叠加；但使役形（顺位1）后，可以再接顺位2的变化。

3. **使役形后的可能／受身／尊敬形，按二类动词变化**  
   `読ませる → 読ませられる → 読ませられます`  
   注意：`読ませられる`可能因语境表示“能让人读”或“被迫读”。

4. **否定形之后按い形容词方式变化**  
   `話せない → 話せなくて／話せなかった／話せなければ`

5. **“终止”只指本图中的再变化终点**  
   它不表示后面绝对不能接任何助词或语法；而是表示不能再按这张表继续作动词形态变化。

# 常见链条

- `話す → 話せる → 話せて`  
  日本語が話せて、得しました。

- `話す → 話せる → 話せない → 話せなくて`  
  日本語が話せなくて、困りました。

- `話す → 話せる → 話せない → 話せなければ`  
  日本語が話せなければ、通訳を頼みます。

# 易错点

- `～ない`之后不是继续按动词规则变化，而是按い形容词规则：`ない → なくて／なかった／なければ`。
- `ます形`在顺位3，因此可出现在可能、受身、尊敬等形式之后：`話せます／読まれます／いらっしゃいます`。
- `～ましょう`属于意向表达，位于顺位5；例如：`がんばります → がんばりましょう`。
