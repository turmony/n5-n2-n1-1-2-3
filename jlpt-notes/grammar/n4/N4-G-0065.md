# 核心

`～まま`表示前面的状态保持不变。主要有两种用法：

1. 保持A的状态做B：在A的状态下进行B。
2. A的状态不变并持续到现在或某个时间点。

# 接续

- 动词`た形`／`ない形`＋`まま`
  - `電気をつけたまま`
  - `何も食べないまま`
- い形容词＋`まま`
  - `若いまま`
- な形容词＋`なまま`
  - `静かなまま`
- 名词＋`のまま`
  - `昔のまま`

# 1. 保持前面状态做B

表示“保持A的状态做B”“在A状态下做B”。

- 息子はいつも電気をつけたまま、寝ています。  
  儿子总是开着灯睡觉。
- 靴をはいたまま、部屋に入らないでください。  
  请不要穿着鞋进房间。
- 何も食べないまま、学校へ行きました。  
  什么都没吃就去了学校。

其中：

- `Vた＋まま`：做了动作后，保持该动作产生的状态。
- `Vない＋まま`：没有做某动作，就保持未做的状态进行后项。

# 2. 前面状态不变并持续

- 父は昨日の朝、家を出たまま帰ってきません。  
  父亲从昨天早上离开家后就一直没回来。
- この町は昔のままです。  
  这个城镇和以前一样，没有改变。
- 彼は子どものままです。  
  他一直没有改变，仍像个孩子。

# 与相关形式的区别

- `～まま`：强调前项状态保持不变，后项在该状态下发生或持续。
- `～ながら`：主要表示“边……边……”，两个动作通常同时进行。
- `～て`：单纯连接动作或状态，不一定强调前项状态持续不变。

# JLPT N4 提示

- 动词只能接`た形`或`ない形`：`Vたまま`、`Vないまま`。
- な形容词现在肯定接`な`，名词接`の`：`静かなまま`、`昔のまま`。
- 注意不要把`Vないまま`误解成单纯的`Vないで`；`まま`更突出“未做该动作的状态保持着”。
