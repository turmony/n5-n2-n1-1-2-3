# 学习者原始输出

N4第104个语法：【普通形（な，の）】+場合+（は）表示~情况/场合，前面接未来可能会发生的事情，后面跟判断，指示，要求或者建议等。

# 核心

**`A 場合（は）、B`：在……情况下／如果遇到……的情况，就……。**

前项 A 通常是尚未发生、但有可能发生的情况，或作为判断依据的条件；后项 B 常接判断、规定、指示、请求、建议或应对措施。语气比 `～とき` 更正式、书面。

# 接续

| 词类 | 接续 |
| --- | --- |
| 动词 | 普通形 + 場合（は） |
| い形容词 | 普通形 + 場合（は） |
| な形容词 | 词干 + な場合（は） |
| 名词 | 名词 + の場合（は） |

# 基本用法

- バイトを休む場合は、店長にメールしてください。  
  如果要请假不去打工，请给店长发邮件。
- 事故にあった場合、保険会社に連絡しましょう。  
  如果发生事故，请联系保险公司。
- 音声ガイド機が必要な場合は、受付で借りることができます。  
  如果需要语音导览器，可以在服务台借。
- 小学生以下の子供の場合、入場料は無料です。  
  小学生及以下的儿童，门票免费。

# 语义边界

`場合`强调“假设出现某种情况时，该如何处理或如何判断”，不适合单纯叙述过去经历、确定条件，或不可能实现的幻想。

# 与「とき／たら」的区别

| 情况 | 合适表达 | 例句 |
| --- | --- | --- |
| 未来可能发生的情况，需要说明处理办法 | `場合／とき／たら`均可 | パスポートをなくした場合は／ときは／たら、大使館に行ってください。 |
| 过去反复发生的场合 | `とき` | 子供のとき、よくこの公園で遊びました。 |
| 确定条件 | `たら` | 十時になったら、出かけましょう。 |
| 不可能或反事实的假想 | `たら` | 生まれ変わったら、鳥になりたい。 |

# JLPT N4 提示

- `場合（は）`常见于通知、规则、说明书、服务指南等较正式的语境。
- 前项可以是动词过去形：`事故にあった場合`，意思是“如果发生了事故”。
- 后项出现 `～てください／～ましょう／～ことができます／無料です` 等表达时，常可考虑 `場合（は）`。
- 名词接续是 `名词 + の場合`，不要漏掉 `の`。
