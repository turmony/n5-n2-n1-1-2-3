# 核心

可能形表示“能够……”“会……”。本课重点是按照一类、二类、三类动词进行变形。

# 1. 一类动词（五段动词）

将词尾的`う段`变成`え段`，再加`る`：

| 辞书形 | 可能形 |
| --- | --- |
| 書く | 書ける |
| 読む | 読める |
| 話す | 話せる |
| 待つ | 待てる |
| 死ぬ | 死ねる |
| 遊ぶ | 遊べる |
| 帰る | 帰れる |
| 買う | 買える |

# 2. 二类动词（一段动词）

去掉`る`，加`られる`：

- 食べる→食べられる
- 見る→見られる
- 起きる→起きられる
- 寝る→寝られる

# 3. 三类动词（不规则动词）

- する→できる
- 来る（くる）→来られる（こられる）

# 例句

- 日本語が話せます。  
  会说日语。
- 納豆が食べられます。  
  能吃纳豆。
- 明日は来られません。  
  明天不能来。

# 易混点

- 一类动词：`う段→え段＋る`。
- 二类动词：去`る`＋`られる`。
- `する`不能变成`しられる`，而是`できる`。
- `来る`变成`来られる（こられる）`。
- 可能形中的对象常用`が`：`日本語が話せます`；原来的`を`在口语中有时也能听到，但N4阶段优先掌握`が`。

# JLPT N4 提示

- 变成可能形后，动词整体按二类动词活用：`話せる→話せない／話せた`。
- 一类和二类的规则不要混淆：`書く→書ける`，而`食べる→食べられる`。
