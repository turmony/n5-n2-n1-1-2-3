# 核心

`动词ます形去ます + 方（かた）`表示“……的方法／……的做法”。

# 接续与例句

- 食べます → 食べ方：吃法。
- 使います → 使い方：使用方法。
- 行きます → 行き方：去法／前往的方法、路线。
- この漢字の読み方を教えてください。  
  请告诉我这个汉字的读法。

# 「方」的常见读法

| 读法 | 主要含义 | 例子 |
| --- | --- | --- |
| かた | 方法、做法 | 食べ方、使い方、考え方 |
| かた | 对人的礼貌称呼 | あの方は学校の先生です。 |
| ほう | 方向、方位 | あっちの方にコンビニがあります。 |
| ほう | 比较、偏好的一方 | コーヒーの方が好きです。 |

# 语义边界

- `食べ方`是“吃的方法”，不是单纯的“吃”。
- `コーヒーの方が好きです`表示“我更喜欢咖啡”，常用于两项或多项比较，不限于严格二选一。
- 「方」读作「ほう」不只用于方向或比较；固定词中也常见，如`方法（ほうほう）`、`方言（ほうげん）`。

# JLPT N4 提示

- 动词必须先变为ます形，再去掉「ます」接「方」。
- 「方」读作「かた」时，注意区分“方法”和敬称“人”。
- 「方」读作「ほう」时，常结合`～の方`、`～方が`理解方向、方位或比较偏好。
