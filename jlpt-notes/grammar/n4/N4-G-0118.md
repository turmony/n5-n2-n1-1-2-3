# 学习者原始输出

N4第118个语法：讲了ぞ、ぜ、な、さ这四个终助词的用法，进行总结

# 核心

`ぞ・ぜ・な・さ`都是置于句末、为语气增色的口语终助词。整体偏随意；`ぞ／ぜ`尤其带男性口吻，不宜对上级或正式场合使用。

| 终助词 | 核心语气 | 常见用法与例句 |
| --- | --- | --- |
| `ぞ` | 强烈提醒、通知、强调 | そこにいると危ないぞ。／絶対に合格するぞ。 |
| `ぜ` | 提醒、通知；比`ぞ`稍随意，也可鼓动 | あとは頼んだぜ。／台湾へ遊びに行こうぜ。 |
| `な` | 感叹、确认、叮嘱、劝告等，功能最多 | 本当にきれいな花火だなあ。／そうだな。／傘を持って行きな。 |
| `さ` | 引出话题、填充停顿；或带自信地断言 | この前さ、友達とさ……／大変だけど、なんとかなるさ。 |

# 「な」的主要用法

- **感叹**：普通形 + `な`  
  本当にきれいだなあ。

- **征求确认／附和**：普通形 + `な`  
  このラーメン、おいしかったな。  
  そうだな、また来よう。

- **随意地补充、吸引对方注意**：  
  この前な、友達とな、公園に行ったときな……  
  这类`な`主要起口语停顿、拉近距离的作用。

- **劝告**：动词ます形去`ます` + `な`（≈ `～なさい`，较随意）  
  傘を持って行きな。

- **禁止**：动词辞书形 + `な`  
  この仕事が終わるまでは帰るな。  
  注意：这里的`な`不是普通终助词，而是禁止表达。

# 易混点

`～な`既可能是“劝告”，也可能是“禁止”，关键看前面形式：

- `帰りな`：回去吧。
- `帰るな`：不许回去。

四个词都应优先理解为会话语气；考试中重点辨认说话人的态度与场合。
