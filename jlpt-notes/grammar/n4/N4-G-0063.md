# 核心

`～なくて＋B`有两种主要用法：

1. **表示原因**：因为不……／因为没能……。
2. **表示否定并列**：不……，而且也不……。

`B`通常不能是请求、命令、劝诱、意志等个人意志表达。

# 接续

- 动词`ない形`去`ない`＋`なくて`  
  `行かない` → `行かなくて`
- い形容词：`くない`→`くなくて`  
  `高くない` → `高くなくて`
- な形容词：`じゃない`→`じゃなくて`  
  `静かじゃない` → `静かじゃなくて`
- 名词：`じゃない`→`じゃなくて`  
  `学生じゃない` → `学生じゃなくて`

较正式的说法是`ではなくて`：`静かではなくて`、`学生ではなくて`。

# 1. 表示原因

- 旅行に行けなくて、残念です。  
  因为没能去旅行，所以很遗憾。
- 電車が来なくて、困りました。  
  因为电车没来，所以我很为难。
- 部屋が静かじゃなくて、勉強できません。  
  因为房间不安静，所以无法学习。

# 2. 表示否定并列

- この部屋は水も出なくて、電気も使えません。  
  这个房间既没有水，也不能用电。
- 今日は忙しくなくて、暇です。  
  今天不忙，很闲。
- 彼は学生じゃなくて、会社員です。  
  他不是学生，而是公司职员。

# 后项不能是个人意志

`～なくて`后面通常不能接请求、命令、劝诱或意志等表达：

- × 雨が降らなくて、出かけましょう。
- ○ 雨が降らないので、出かけましょう。  
  因为不下雨，我们出去吧。
- × お金がなくて、貸してください。
- ○ お金がないので、貸してください。  
  因为没有钱，请借给我。

# 与「～ないで」的区别

- 朝ご飯を食べないで学校へ行きました。  
  没吃早饭就去学校了。→ 附带状况。
- 朝ご飯を食べなくて、お腹がすきました。  
  因为没吃早饭，所以肚子饿了。→ 原因。

`～ないで`后面可以接个人主动做的动作；`～なくて`主要表示原因或否定并列。

# JLPT N4 提示

- 动词：`ない→なくて`。
- い形容词：`くない→くなくて`。
- な形容词、名词：`じゃない→じゃなくて`。
- 表示原因或否定并列。
- 后项不能是请求、命令、劝诱等个人意志表达。
