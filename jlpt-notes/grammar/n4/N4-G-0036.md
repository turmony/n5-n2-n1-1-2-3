# 核心

`Aは Bに 动词て形＋くれます`表示A为B做某事，而B是说话者自己或说话者的我方成员，即“某人为我／我方做……”。

A是施惠者／动作执行者，B是受惠者。这个句型从说话者或我方受惠者的角度表达，常带有感谢、受惠的语气。

# 接续

动词て形＋くれます

- 作ります → 作ってくれます
- 送ります → 送ってくれます
- 洗います → 洗ってくれます
- 教えます → 教えてくれます

# 基本例句

- 友達は私に料理を作ってくれました。  
  朋友给我做了饭。
- 母は私に日本語を教えてくれました。  
  妈妈教了我日语。
- 友達が料理を作ってくれました。  
  朋友给我做了饭。

当受惠者是说话者自己时，`私に`常可省略。

# 受惠者「私に」不另出现的情况

受惠者已经由其他成分明确表示时，句中通常不再另加`私に`。

## 1. 受惠者同时是动词的对象

- 友達は私を駅まで送ってくれました。  
  朋友送我到车站了。

`私を`是`送ります`的对象；“我”也正是受惠者，所以不能再重复说`私に`。

## 2. 受惠者由所属关系表明

- 友達は私の服を洗ってくれました。  
  朋友帮我洗了衣服。

`私の服`已通过所属关系表明“我”是受惠者，通常不必再加`私に`；说成`私に私の服を`会显得重复、不自然。

# 易混项

| 形式 | 视角与含义 |
| --- | --- |
| `～てあげます` | 我／我方为别人做事。 |
| `～てもらいます` | 我／我方得到别人的帮助。 |
| `～てくれます` | 别人为我／我方做事。 |

- 私は友達に料理を作ってあげました。  
  我给朋友做饭。
- 私は友達に料理を作ってもらいました。  
  我请朋友给我做饭。
- 友達が料理を作ってくれました。  
  朋友给我做饭了。

# JLPT N4 提示

- `～てくれます`接动词て形。
- 受惠者通常是说话者自己、家人或说话者视为我方的人。
- 先找“谁得到帮助”；若是我／我方得到别人的帮助，优先考虑`～てくれます`。
- 受惠者已在`～を`或`～の`等成分中出现时，通常不另用`～に`重复表示。
