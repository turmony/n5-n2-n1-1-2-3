# 核心

`～がる`表示从外部观察到某人表现出某种感情、感觉或愿望。

动词ます形去ます＋`たがります／たがっています`，表示第三人称想做某事的样子；い形容词去`い`、な形容词去`な`后接`がります／がっています`，表示表现出某种感情或感觉。

# 接续

## 动词愿望

`动词ます形去ます＋たがる`

- `食べます` → `食べたがる`
- `行きます` → `行きたがる`
- `飲みます` → `飲みたがる`

礼貌形式：`食べたがります`、`食べたがっています`

## い形容词

去掉`い`，加`がる`：

- `欲しい` → `欲しがる`
- `寂しい` → `寂しがる`
- `怖い` → `怖がる`

## な形容词

去掉`な`，加`がる`：

- `嫌いな` → `嫌がる`
- `不安な` → `不安がる`

# 例句

- 弟はバイクを欲しがっています。  
  弟弟表现出想要摩托车的样子。
- 子どもはお菓子を食べたがっています。  
  孩子想吃点心。
- 彼女は新しい服を欲しがっています。  
  她看起来想要新衣服。
- 弟は注射を怖がっています。  
  弟弟害怕打针的样子。

# 与「～たい／～ほしい」的区别

- 私はバイクが欲しいです。  
  我想要摩托车。→ 第一人称直接说自己的愿望。
- 弟はバイクを欲しがっています。  
  弟弟表现出想要摩托车的样子。→ 根据外在表现描述第三人称。
- あなたはバイクが欲しいですか。  
  你想要摩托车吗？→ 直接询问第二人称愿望。

一般不使用`あなたはバイクを欲しがっていますか`来直接询问第二人称的内心愿望。

# 语义边界

`～がる`重点是“从外部看起来表现出某种感情或愿望”，不一定能完全确定对方的真实内心：

- `欲しがっています`：从行为、表情等看起来很想要。
- `欲しいようです`：根据情况推测似乎想要。

注意：`～たがる`不是“たい去掉い再加がる”，而是“动词ます形去ます＋たがる”：

- `食べます` → `食べたがる`
- `見ます` → `見たがる`

# JLPT N4 提示

- `～たい／～ほしい`常用于第一人称或直接询问第二人称。
- `～たがる／～ほしがる`常用于从外部描述第三人称。
- `～がる`表示外在表现，不等于直接确认对方内心。
