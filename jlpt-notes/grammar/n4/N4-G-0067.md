# 核心

本课有两个相关形式：

1. `普通形＋かどうか＋B`：表示“是否……”。固定形式是`～かどうか`，不能只写成`～かどう`。
2. `疑问词＋普通形＋か＋（助词）＋B`：表示“谁、什么、哪里、什么时候……吗”。

这里的B通常是`知っています`、`分かりません`、`調べます`、`決めます`等，构成间接疑问。

# 接续

- 动词普通形＋`かどうか`／疑问词＋动词普通形＋`か`
- い形容词普通形＋`かどうか`／疑问词＋い形容词普通形＋`か`
- な形容词：现在肯定形去掉`だ`
  - `静かだ`→`静かかどうか`
  - `便利だ`→`便利か`
- 名词：现在肯定形去掉`だ`
  - `学生だ`→`学生かどうか`
  - `先生だ`→`先生か`

# 1. ～かどうか：是否……

- 佐藤さんが来るかどうか、知りません。  
  我不知道佐藤先生是否会来。
- この店が便利かどうか、調べます。  
  我调查一下这家店是否方便。
- 彼が学生かどうか、分かりません。  
  我不知道他是不是学生。

# 2. 疑问词＋～か：……吗／什么时候、谁、哪里……

- 会議は何時から始まるか、知っていますか。  
  你知道会议几点开始吗？
- お店の前にいる人は誰か、分かりません。  
  我不知道店门前的人是谁。
- どこへ行くか、まだ決めていません。  
  还没有决定去哪里。

疑问词后的助词可以根据句子结构保留或省略：

- `どこへ行くか`
- `何を食べるか`
- `誰が来るか`

# 与直接疑问句的区别

- `電話番号を知っていますか。`：你知道电话号码吗？（直接提问）
- `電話番号を知っているかどうか、分かりません。`：不知道是否知道电话号码。（间接疑问）

# JLPT N4 提示

- `～かどうか`表示“是否”，不能漏掉最后的`か`。
- 普通形中，な形容词和名词的现在肯定形接本句型时要去掉`だ`。
- `疑问词＋～か`和`～かどうか`都属于间接疑问，句末B通常不是单独的`ですか`。
