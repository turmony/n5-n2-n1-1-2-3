# 核心

「を」可标记移动经过的空间：横断歩道を渡ります、公園を散歩します、空を飛びます；此时动词仍可能是自动词。

# 自动词与他动词

- **自动词（自動詞）**：不以直接宾语为必需成分，描述主体移动、状态或事物自身发生的变化。基本形式常是「名词が＋自动词」。  
  ドアが開きます。——门开了。
- **他动词（他動詞）**：动作作用于某个对象；初级句型常是「动作主体が＋对象を＋他动词」。  
  ドアを開けます。——把门打开。

有「を」不等于一定是他动词：在「空を飛びます」「公園を散歩します」中，「を」是经过点，不是宾语。

- ドアが開きます（自动词）／ドアを開けます（他动词）
- 教室を出ます（离脱点）／紙飛行機を飛ばします（宾语）

# 判断提示

先问「を」后名词是不是被动作直接作用、改变的对象：是则多为他动词；若它表示经过的空间或离开的地点，则不据此判断为他动词。
