# 核心：ます形的用途

动词的「ます形」用于礼貌地陈述、提问或回答，常见于对不熟悉的人、老师、顾客或正式场合。

- 毎日、日本語を勉強します。——每天学习日语。（现在的习惯）
- 明日、友達に会います。——明天见朋友。（将来的安排）

「～ます」表示非过去，可表示现在的习惯或将来。

| 形式 | 含义 | 例句 |
| --- | --- | --- |
| ～ます | 现在／将来肯定 | 行きます。——去。／会去。 |
| ～ません | 现在／将来否定 | 行きません。——不去。／不会去。 |
| ～ました | 过去肯定 | 行きました。——去了。 |
| ～ませんでした | 过去否定 | 行きませんでした。——没去。 |

「読みます」整体常称“ます形”；其中「読み」是ます词干（连用形），可接「たい」「に行く」等表达：読みたい、読みに行きます。

# 三类动词变化

| 类别 | 变换规则 | 例子 |
| --- | --- | --- |
| 第一类动词（五段） | 词尾的う段假名变为同行い段＋ます | 書く→書きます；話す→話します；読む→読みます；待つ→待ちます；買う→買います |
| 第二类动词（一段） | 去掉词尾「る」＋ます | 食べる→食べます；見る→見ます；起きる→起きます |
| 第三类动词（不规则） | 单独记忆 | する→します；来る（くる）→来ます（きます） |

## 第一类词尾变化

| 辞书形词尾 | ます形词尾 | 例子 |
| --- | --- | --- |
| う | い＋ます | 買う→買います |
| つ | ち＋ます | 待つ→待ちます |
| る | り＋ます | 帰る→帰ります |
| く | き＋ます | 書く→書きます |
| ぐ | ぎ＋ます | 泳ぐ→泳ぎます |
| す | し＋ます | 話す→話します |
| ぬ | に＋ます | 死ぬ→死にます |
| ぶ | び＋ます | 遊ぶ→遊びます |
| む | み＋ます | 読む→読みます |

# 判断与易错点

- 不以「る」结尾的动词基本都是第一类。
- 以「～る」结尾、且「る」前多为い段或え段的动词，很多是第二类；但不能只看「る」。
- 常见第一类「る」动词：帰る、入る、走る、切る、知る、要る。
- × 食べります　○ 食べます；× 読むます　○ 読みます；× 来るます　○ 来ます（きます）。
- 「行く」是第一类：行く→行きます。
