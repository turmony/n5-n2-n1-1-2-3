# 核心用法

- 礼貌体句子 + か：构成疑问句。

# 三类礼貌体疑问句

- 是非问句：询问某件事是否成立。
  - あなたは学生ですか。
  - はい、学生です。／いいえ、学生じゃありません。

- 疑问词问句：用何、だれ、どこ等询问信息。
  - お仕事は何ですか。
  - 高校の教師です。

- 选择问句：在两个或多个选项中选择。
  - これはボールペンですか、ノートですか。
  - ボールペンです。

是非问句通常以「はい／いいえ」开始回答，但不必只说这两个词；疑问词问句需要提供所询问的信息。

# 句末语调

A：昨日、初めて寿司を食べました。

B：そうですか。↘——原来如此。句末下降，表示听到新信息后的确认或回应。

B：おいしかったですか。↗——好吃吗？句末上升，表示真正提出疑问。

这里关注的是整句的句末语调，不是「か」这个字本身固定只有一种音调。

# 易混项

- 「そうですか」用上升语调时，也可以变成“是这样吗？”的确认问题。
- 图中谈论的是昨天吃的寿司，因此说「おいしかったですか」，而不是「おいしいですか」。
- 疑问词问句不能只回答「はい／いいえ」。

# N5 要点

先判断问题要的是“是／否”、具体信息，还是选项，再选择合适的回答。
