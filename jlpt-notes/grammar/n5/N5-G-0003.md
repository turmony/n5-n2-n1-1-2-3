# 核心用法

- な形容词 + です：……的；处于……的状态。
- な形容词 + じゃありません：不……。
- な形容词 + ではありません：不……；较正式。

な形容词在句末使用礼貌体时，形式与名词句相同。

# 例句

- この部屋は静かです。——这个房间很安静。
- この町は静かじゃありません。——这个城镇不安静。
- 田中さんは元気ではありません。——田中精神不太好。

# 名词与な形容词的区别

- 名词 + の + 名词：日本の会社（日本的公司）。
- な形容词 + な + 名词：静かな部屋（安静的房间）、元気な人（有精神的人）。

「な」只在な形容词放在名词前修饰名词时使用；句末不加「な」。

# 易混项

- 「元気です」正确；不能说「元気なです」。
- 「静かな部屋」正确；句尾则说「部屋は静かです」。
- 名词修饰名词的基础形式是「名词 + の + 名词」，但也存在如「日本語学校」这样的固定复合名词。

# N5 要点

- 名词：学生です／学生じゃありません。
- な形容词：元気です／元気じゃありません。
- 修饰名词时，名词常接「の」，な形容词接「な」。
