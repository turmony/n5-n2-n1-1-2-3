# 核心

`地点 + で + 动作／事件` 表示人在哪里进行动作，或某个事件在哪里发生。

- 図書館で勉強します。——在图书馆学习。
- 公園で友だちと遊びます。——在公园和朋友玩。
- 公園でコンサートがあります。——公园有音乐会。

# 「で」与「に」

| 表达 | 含义 |
| --- | --- |
| 図書館で勉強します。 | 「で」：学习动作发生的地点。 |
| 図書館にいます。 | 「に」：人存在的地点。 |
| 図書館に本があります。 | 「に」：物品存在的地点。 |

- 问“在哪里做某事？”→ 用「で」。
- 问“谁／什么在哪里存在？”→ 用「に」。

# 「で」与「を」

- 公園で友だちと遊びます。——「で」：动作进行地点。
- 公園を散歩します。——「を」：移动经过的路线。

# 图片中的「に」与「で」

- この紙に名前と電話番号を書いてください。  
  请把姓名和电话号码写在这张纸上。  
  「に」表示书写的落点、附着面。
- ここに車を止めてください。  
  请把车停在这里。  
  「に」强调车停放后的到达位置。
- ここで車を止めてください。  
  请在这里把车停下来。  
  「で」强调“停车”动作在此处发生。

# 常用例句

- 学校で日本語を勉強します。——在学校学习日语。
- レストランで昼ごはんを食べます。——在餐厅吃午饭。
- コンビニで水を買います。——在便利店买水。
- 家でテレビを見ます。——在家看电视。

# JLPT 提示

- `地点 + で + 动作`：动作地点。
- `地点 + で + 事件`：事件发生地点。
- `地点 + に + います／あります`：存在地点。
- `地点 + を + 歩く／散歩する／通る`：经过路线。
