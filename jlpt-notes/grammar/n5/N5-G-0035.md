# 核心

「くれます」表示“给我／给我方的人”。它不是泛指“给”，而是强调别人把东西给说话人，或给属于说话人这一方的人。

> 施惠者 は 受惠者 に 物 を くれます。

# 图片中的表达

- ○ 私は佐藤さんに花をあげました。——我给佐藤花。
- × 佐藤さんは私に本をあげました。——对方给“我”时，本课不用「あげます」。
- ○ 佐藤さんは私に本をくれました。——佐藤给了我书。

# 使用范围

- 别人给第一人称：○  田中さんは私に本をくれました。
- 别人给第一人称这一方的人：○  田中さんは私の妹にお菓子をくれました。
- 第一人称给别人：×  私は田中さんに本をくれました。  
  应改为：私は田中さんに本をあげました。
- 第三人称给不属于“我方”的第三人称：×  田中さんは鈴木さんに本をくれました。  
  应改为：田中さんは鈴木さんに本をあげました。

# 与「もらいます」的区别

- 佐藤さんは私に本をくれました。——从给的人角度说：佐藤给了我书。
- 私は佐藤さんに本をもらいました。——从收到的人角度说：我从佐藤那里得到了书。

两句描述同一件事，区别在叙述重点。

# 助词关系

- 「は」：给东西的人。
- 「に」：收到东西的人。
- 「を」：给出的东西。

# 常用例句

- 友達は私に誕生日プレゼントをくれました。——朋友送了我生日礼物。
- 先生は私たちに宿題をくれました。——老师给了我们作业。

# 易错点

- × 母は友達にケーキをくれました。  
  如果“朋友”不属于我方，应使用「あげました」。
- ○ 母は私にケーキをくれました。——妈妈给了我蛋糕。

# JLPT 提示

看到「くれます」时，先确认接受者是不是“我／我方的人”。是，则用「くれます」；不是，则通常用「あげます」。
