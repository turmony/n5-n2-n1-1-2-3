# 核心

「～くします／～にします」表示人主动使某物变成某种状态，或从选项中决定、选择某项。

# 三种接续

| 前项 | 接续 | 例句 |
| --- | --- | --- |
| い形容词 | 去「い」＋くします | テレビの音を大きくします。——把电视声音调大。 |
| な形容词 | 词干＋にします | 部屋を静かにします。——把房间弄安静。 |
| 名词 | 名词＋にします | ご飯の量を半分にします。——把饭量减半。 |

# 「なる」与「する」

| 状态变化 | 主动改变 |
| --- | --- |
| 髪が長くなりました。<br>头发变长了。 | 髪を短くします。<br>把头发弄短。 |
| 部屋がきれいになりました。<br>房间变干净了。 | 部屋をきれいにしました。<br>我把房间弄干净了。 |

- `なる`：变化的对象多用「が」。
- `する`：被主动改变的对象通常用「を」。

# 选择、决定的「～にします」

`N にします` 还常表示选择或决定为某项，不一定真的把某物变成另一物。

- 飲み物はコーヒーにします。——饮料我就选咖啡。
- 次の会議は火曜日にします。——下次会议定在星期二。
- これにします。——我就要这个／我选这个。

# 请求对方改变

`～く／にしてください` 表示请对方主动使状态发生改变。

- 静かにしてください。——请安静。
- もう少し大きくしてください。——请再调大一点。

# JLPT 提示

- `～くします／～にします`：人为决定或主动改变。
- `～くなります／～になります`：自然变化、结果变化或成长变化。
- `N にします` 可表示“决定选N”。
