# 核心

`名词 + で + 动词` 中的「で」可表示完成动作所使用的工具、手段、方式或语言，相当于“用……”。

# 图片例句

- カッターで紙を切ります。——用裁纸刀切纸。`カッター` 是工具。
- “thank you”は日本語で「ありがとう」です。——“thank you”用日语说是“ありがとう”。`日本語` 是表达所使用的语言。
- これは日本語で何ですか。——这个用日语怎么说？

# 工具

- ペンで名前を書きます。——用笔写名字。
- はしでご飯を食べます。——用筷子吃饭。
- スマホで写真を撮ります。——用手机拍照。
- カッターで紙を切ります。——用裁纸刀切纸。

# 手段、方式

- 電話で予約します。——用电话预约。
- メールで送ります。——用邮件发送。
- バスで学校へ行きます。——坐公交车去学校。

# 语言

- 日本語で話します。——用日语说。
- 英語でメールを書きます。——用英语写邮件。
- 「ありがとう」は英語で何ですか。——“ありがとう”用英语怎么说？

# 与动作地点的「で」

| 句子 | 「で」的作用 |
| --- | --- |
| カッターで紙を切ります。 | 工具：用裁纸刀 |
| 日本語で話します。 | 语言：用日语 |
| バスで行きます。 | 手段：坐公交 |
| 学校で日本語を勉強します。 | 地点：在学校 |

一句话可同时出现两种「で」：

- 学校で日本語で話します。——在学校用日语说话。  
  第一个「で」是地点；第二个「で」是语言。

# 易混点

- ペンで書きます：用笔写；「で」表工具。
- 紙に書きます：写在纸上；「に」表书写的落点、附着面。
- 日本語で話します：用日语说。
- 日本語を勉強します：学习日语。不能用「で」替代宾语助词「を」。

# JLPT 提示

- `工具 + で + 动词`：用某工具做某事。
- `语言 + で + 动词`：用某语言表达。
- `交通工具 + で + 行く／来る／帰る`：乘坐某交通工具移动。
- 注意与「地点 + で + 动作」的区别。
