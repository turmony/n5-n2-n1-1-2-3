# 核心

「～ませんか」用于开放式邀请，把是否接受的选择留给对方；「～ましょう」用于更积极的共同提议、已有共识后的行动或说话人有权作出的安排。

**接续**  
`动词ます形去掉ます + ませんか／ましょう`

- 行きます → 行きませんか／行きましょう
- 食べます → 食べませんか／食べましょう
- します → しませんか／しましょう
- 来ます（きます）→ 来ませんか／来ましょう

# 1. ～ませんか：开放式邀请

**形式**  
`Vます词干 + ませんか`

意思是“要不要……？”“一起……好吗？”。适合首次邀请、关系不太熟，或希望语气更委婉的场合。

- いっしょに映画を見ませんか。——一起看电影好吗？
- 今週末、食事に行きませんか。——这个周末一起去吃饭好吗？

**常见回应**

- はい、いいですね。——好呀。
- すみません、ちょっと……。——不好意思，有点……

# 2. ～ましょう：积极提议／一起做吧

**形式**  
`Vます词干 + ましょう`

意思是“……吧”“一起……吧”。语气比「ませんか」更积极，常用于已形成共同意向、刚达成共识，或说话人负责安排的情形。

- A：少し休みませんか。  
  B：はい、休みましょう。  
  A：要不要稍微休息一下？  
  B：好，我们休息吧。
- もう時間ですね。じゃ、10分休みましょう。——已经到时间了。那么，休息十分钟吧。

# 「ませんか」与「ましょう」

| 情境 | 更自然的表达 | 原因 |
| --- | --- | --- |
| 第一次询问朋友愿不愿意周末吃饭 | 今週末、食事に行きませんか。 | 先让对方选择是否愿意。 |
| 对方已答应，确认一起行动 | じゃ、食事に行きましょう。 | 双方已有共同决定。 |
| 老师宣布课堂休息 | 10分休みましょう。 | 是组织者作出的安排。 |

「ましょう」不是完全不考虑对方的意志，而是更默认对方会同意，或说话人能够推动、安排这一行动。因此，在需要先确认对方意愿时，优先用「ませんか」。

# 相关表达

## 普通体邀请

- いっしょに映画を見ない？——一起看电影吗？  
  朋友之间的随意说法。
- いっしょに映画を見ないか。——一起看电影吗？  
  偏男性化或较硬，不作为初学者的通用礼貌表达。

## 「～ましょうか」：主动帮忙

「ましょうか」也常表示“要我来……吗？”，与邀请对方一起做不同。

- 荷物を持ちましょうか。——我帮你拿行李吧？
- 窓を開けましょうか。——我来开窗吧？

# JLPT 提示

- `～ませんか`：询问式邀请；对方可以自然地接受或拒绝。
- `～ましょう`：共同提议、已达成共识后的行动或安排。
- 看到 `～ましょうか` 时，先判断是否表示“我来帮你做吗”。
