# 核心

`名词A と 名词B` 表示“A 和 B”的并列。后面只有一个动词时，该动词必须在意义上能同时自然地适用于所有并列名词。

# 图片例句

- 休みの日は土曜日と日曜日です。——休息日是星期六和星期日。✅
- パンと牛乳を買いました。——买了面包和牛奶。✅
- 朝ご飯はパンと卵を食べます。——早餐吃面包和鸡蛋。✅
- 朝ご飯はパンと牛乳を食べます。——❌ 牛乳通常用「飲む」，不自然地与パン共用「食べる」。
- 朝ご飯はパンを食べます。それから牛乳を飲みます。——早餐吃面包，然后喝牛奶。✅
- 朝ご飯はパンと牛乳です。——早餐是面包和牛奶。✅

# 判断标准

问题不在于面包和牛奶不能并列，而在于并列后的谓语能否同时自然地适用于每个名词。

| 句子 | 判断 | 原因 |
| --- | --- | --- |
| パンと牛乳を買います。 | ✅ | 两者都可“买” |
| パンと卵を食べます。 | ✅ | 两者都可“吃” |
| パンと牛乳を食べます。 | ❌ | 牛奶通常“喝”，不“吃” |
| パンと牛乳です。 | ✅ | 「です」说明早餐内容，不要求同一动作 |

# 自然例句

- 机の上に本とノートがあります。——桌上有书和笔记本。
- 月曜日と水曜日に日本語を勉強します。——周一和周三学习日语。
- コーヒーと紅茶を飲みます。——喝咖啡和红茶。
- 母と父に電話します。——给妈妈和爸爸打电话。

# 「と」与「や」

- パンと牛乳を買います。——买面包和牛奶；明确列出这两项。
- パンや牛乳を買います。——买面包、牛奶等；只是举例，暗示可能还有别的。

# 与动作伙伴的「と」

- 友だちと映画を見ます。——和朋友看电影。`友だち` 是共同动作人。
- 友だちと先生が来ます。——朋友和老师来了。两人是并列主语。

# JLPT 提示

- 基本形式：`N1 と N2`。
- 并列名词后只接一个谓语时，该谓语必须适用于所有并列项。
- `と` 是较完整、明确的列举；`や` 有“……等”的举例意味。
- 看到「と」时，要判断它是名词并列还是动作伙伴。
