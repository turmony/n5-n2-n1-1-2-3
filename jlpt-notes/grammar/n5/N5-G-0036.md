# 核心

本课的「やります」表示“给、给予”，用于给地位较低的人、自己的孩子、宠物、动物或植物等。

> 施惠者 は 受惠者 に 物 を やります。

「やる」还可表示较随意地“做”，如「宿題をやります」。本卡重点是授受动词“给予”的用法。

# 图片中的关系

- 给上位者：用「あげます」。
- 给同等地位者：用「あげます」。
- 给下位者、自己的孩子、宠物、动物或植物：可用「あげます」或「やります」。
- 「やります」特别强调接受者处于较低的位置，或是动物、植物等。

# 使用范围

- 给自己的孩子：○  母は子どもにお菓子をやります。
- 给宠物／动物：○  私は犬にえさをやります。
- 给植物：○  母は花に水をやります。
- 给自己：×  施惠者不能把东西给自己；别人给“我”时，根据叙述视角使用「くれます」或「もらいます」。

# 与「あげます」的区别

- 「あげます」：中性地表示“给”，可用于平辈、上位者或一般对象。
- 「やります」：表示给下位者、孩子、动物或植物；对成年人使用时可能显得居高临下，应谨慎。

# 常用例句

- 父は弟に新しい自転車をやりました。——爸爸给弟弟一辆新自行车。
- 私は毎朝、庭の花に水をやります。——我每天早晨给院子里的花浇水。
- 宿題をやります。——做作业。（此处「やります」是“做”）

# 易错点

- × 先生にプレゼントをやります。
- ○ 先生にプレゼントをあげます。

老师属于上位者，不能用「やります」。

# JLPT 提示

看到「やります」表示“给予”时，先判断接受者是谁：孩子、宠物、动物、植物或较低地位者可以使用；平辈或上位者使用「あげます」。
