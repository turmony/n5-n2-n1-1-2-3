# 核心

位置词通常和「の」「に」一起使用，说明人、动物或物体在哪里。

> A は B の 位置词 に あります／います。

人、动物用「います」；物体、植物、设施用「あります」。

# 位置词

- 上（うえ）：上面
- 下（した）：下面
- 前（まえ）：前面
- 後ろ（うしろ）：后面
- 左（ひだり）：左边
- 右（みぎ）：右边
- 中（なか）：里面
- 外（そと）：外面
- 隣（となり）：旁边、紧挨着
- 間（あいだ）：中间
- 向かい（むかい）：正对面、对面
- そば：旁边、附近
- 近く（ちかく）：附近

# 基本例句

- りんごは机の上にあります。——苹果在桌子上。
- かばんは机の下にあります。——包在桌子下面。
- 先生は教室の前にいます。——老师在教室前面。
- 駅は銀行の後ろにあります。——车站在银行后面。
- 田中さんは私の左にいます。——田中在我的左边。
- 犬は家の中にいます。——狗在房子里面。
- 猫は家の外にいます。——猫在房子外面。

# 特殊位置表达

- 銀行は郵便局の隣にあります。——银行在邮局旁边。
- 駅は銀行と学校の間にあります。——车站在银行和学校之间。
- コンビニは銀行の向かいにあります。——便利店在银行正对面。
- 猫は私のそばにいます。——猫在我身边。
- 学校の近くに公園があります。——学校附近有公园。

# 易混点

- 「隣」：紧挨着的旁边。  
  銀行は郵便局の隣にあります。
- 「そば／近く」：附近，不一定紧挨着。  
  銀行の近くに駅があります。
- 「前」：前面。
- 「向かい」：正对面，通常指隔着路、走廊或面对面的位置。

# JLPT 提示

位置词前通常用「の」连接参照物，位置词后用「に」表示存在地点。

> A は B の 上にあります。  
> A は B と C の 間にあります。  
> A は B の 向かいにあります。
