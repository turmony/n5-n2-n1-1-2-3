# 核心：动作伙伴或对方

`名词 + と + 动词` 表示一起做动作的人，或动作、关系所面对的对方。

**形式**  
`人 + と + 动词`

**例句**

- （私は）友だちと映画を見ます。——我和朋友看电影。
- 妹と買い物に行きます。——和妹妹去购物。
- だれとテニスをしますか。——你和谁打网球？

共同完成的动作可加「いっしょに」强调“一起”：

- 友だちといっしょに映画を見ます。——和朋友一起看电影。

# 「と」与「といっしょに」

「と」不总能换成「といっしょに」。

- 田中さんと結婚しました。——和田中结婚了。  
  `田中さんといっしょに結婚しました` 不表示“与田中结婚”，而容易被理解为“和田中一起分别去结婚”。
- 先生と会います。——和老师见面。

在一句话里可能同时出现两种关系：

- 友だちといっしょに中学生とけんかをしました。  
  第一个「といっしょに」是共同动作人“和朋友一起”；第二个「と」是吵架的对方“和中学生”。

# 用法总览

| 排序 | 用法 | 形式 | 例句 |
| --- | --- | --- | --- |
| 1 | 动作伙伴／对方 | `N と V` | 家族と旅行します。——和家人旅行。 |
| 2 | 名词并列 | `N1 と N2` | パンと牛乳を買います。——买面包和牛奶。 |
| 3 | 比较对象 | `N と 同じ／違う／似ている` | このノートは私のノートと違います。——这本笔记和我的不同。 |
| 4 | 引用 | `普通形 + と 言う／思う` | 明日は雨だと思います。——我认为明天会下雨。 |
| 5 | 条件、自然结果 | `普通形 + と` | 春になると、暖かくなります。——一到春天就暖和。 |
| 6 | 变化结果（进阶、偏书面） | `N と なる／する` | 氷が水となります。——冰变成水。 |

# 1. 名词并列

`N1 と N2` 连接两个或更多名词；所列项目通常被理解为该语境下的完整集合。

- 机の上に本とノートがあります。——桌上有书和笔记本。
- 月曜日と水曜日にサッカーの練習があります。——周一和周三有足球训练。

不能用并列「と」连接两个完整句子。句子中的「と」若表示前后关系，通常是下面的条件用法。

## 「と」与「や」

- パンと牛乳を買います。——买面包和牛奶；这里指这两项。
- パンや牛乳を買います。——买面包、牛奶等；只是举例，暗示还有别的。

# 2. 比较对象

与「同じ」「違う」「似ている」等词搭配，表示比较的基准。

- このかばんは私のかばんと同じです。——这个包和我的包一样。
- 田中さんはお父さんと似ています。——田中和父亲很像。

# 3. 引用

把说的话、想法或读法当作后面动词的内容。

- 先生は「宿題です」と言いました。——老师说：“这是作业。”
- 明日は休みだと思います。——我认为明天放假。
- この漢字は「やま」と読みます。——这个汉字读作“やま”。

接名词或ナ形容词时，普通形要用「だ」：`休みだと思います`。

# 4. 条件、自然结果

`普通形 + と` 表示前项一成立，后项自然、必然或习惯性地发生。

- このボタンを押すと、切符が出ます。——一按这个按钮，票就出来。
- 春になると、暖かくなります。——一到春天就暖和。

初级阶段先避免让后项使用说话人的请求、命令或意志：

- 駅に着いたら、電話してください。——到了车站后，请打电话。（用「たら」）
- 駅に着くと、電話してください。——不自然。

# 5. 变化结果（了解即可）

`N と なる／する` 表示成为、定为或视为；多见于书面、说明和正式表达。日常“变成”更常先学 `N に なる`。

- 氷が水となります。——冰变成水。

# JLPT 提示

本课优先掌握“动作伙伴／对方”和“名词并列”。看到句子中的「と」时，先判断它前面是名词还是普通形：

- 名词前接「と」：多考虑伙伴、并列、比较或引用内容。
- 普通形后接「と」：多考虑引用或条件。
