# 核心

两个表达都表示“想要”，但想要的内容不同。

> 名词 が 欲しいです。  
> 想要某个物品、人或状态。

> 动词ます形去掉ます ＋ たいです。  
> 想做某个动作。

# 「～が欲しいです」

- カメラが欲しいです。——我想要相机。
- お金が欲しいです。——我想要钱。
- 恋人が欲しいです。——我想要恋人。
- 自由な時間が欲しいです。——我想要自由时间。

「欲しいです」前面放的是希望拥有的事物、人或状态。

# 动作性名词

如果想表达“希望做某项活动”，不直接用「动作性名词が欲しいです」，而使用「したいです」。

- × 旅行が欲しいです。
- ○ 旅行したいです。
- ○ 旅行に行きたいです。

「旅行」表示“旅行这项活动”时，用「したいです」表达“想去旅行”。但「休みが欲しいです」正确，因为“休息日／假期”可被看作希望得到的状态或安排。

# 「～たいです」的变形

- 食べます → 食べたいです
- 飲みます → 飲みたいです
- 行きます → 行きたいです
- します → したいです
- 来ます → 来たいです

# 例句

- 寿司を食べたいです。——我想吃寿司。
- 日本へ行きたいです。——我想去日本。
- 旅行したいです。——我想旅行。

# 与「を／が」的关系

- 寿司を食べます。——吃寿司。  
  普通动作句中，动作对象用「を」。
- 寿司を食べたいです。——想吃寿司。  
  N5 基础表达中，使用「を」最稳妥。
- 寿司が食べたいです。——也正确。  
  「たい」带有表达愿望、状态的性质，口语中常用「が」突出想吃的东西。

# 易错点

- × 寿司を好きです。
- ○ 寿司が好きです。——喜欢寿司。
- × 寿司が食べます。
- ○ 寿司を食べます。——吃寿司。

# 使用范围

「欲しいです」「たいです」直接表达的是说话人自己的愿望；询问对方愿望时也可以使用。

- 何が欲しいですか。——你想要什么？
- 何を食べたいですか。——你想吃什么？

# JLPT 提示

先判断想要的是东西还是动作：想要物品、人、状态时用「名词が欲しいです」；想做动作时用「动词ます形去ます＋たいです」。
