# 核心

副词（副詞）不发生词形变化，主要修饰动词、形容词或整个谓语，补充程度、数量、方式、时间等信息。

| 作用 | 副词 | 例句 |
| --- | --- | --- |
| 程度 | とても | 北海道はとても寒いです。——北海道非常冷。 |
| 否定程度 | あまり～ない | この辞書はあまり便利じゃありません。——这本词典不太方便。 |
| 方式／方向 | まっすぐ | この道をまっすぐ行きます。——沿这条路一直走。 |
| 数量 | たくさん | たくさんご飯を食べました。——吃了很多饭。 |

# 图片中的少数用法

- もっとゆっくり話してください。——请再说慢一点。  
  「もっと」修饰副词「ゆっくり」，再共同修饰「話してください」。
- 机の位置はもっと右です。——桌子的位置更靠右。  
  「もっと」与位置名词「右」搭配，说明位置。
- 昼ご飯はまだです。——午饭还没吃／还没有准备好。  
  「まだ」省略了具体内容；「です」是礼貌结句，不宜严格理解为副词直接修饰「です」。

# 易混项

- 「あまり」在 N5 常与否定搭配：`あまり便利じゃありません`。
- 「たくさん」既可表示动作所涉及的量，也可用`たくさんの人`修饰名词。
- `まだです`的具体含义取决于上下文；问“吃了吗？”时相当于`まだ食べていません`。

# JLPT 提示
