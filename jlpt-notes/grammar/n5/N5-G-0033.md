# 核心

「あげます」从给予者角度表示“给出去”；「くれます」表示别人给我或我方的人。关键是礼物移动的方向与说话人的立场。

# 基本句型

- `施惠者 は 受惠者 に 东西 を あげます`
- `施惠者 は 我／我方的人 に 东西 を くれます`

# 图片中的「あげます」

- 私は佐藤さんに花をあげました。——我送花给佐藤。✅
- 佐藤さんは鈴木さんに花をあげました。——佐藤送花给铃木。✅
- 佐藤さんは私に本をあげました。——❌ 应为「佐藤さんは私に本をくれました」。
- 佐藤さんは私の兄に本をあげました。——❌ 应为「佐藤さんは私の兄に本をくれました」。

# 授受方向

| 场景 | 正确表达 | 原因 |
| --- | --- | --- |
| 我给佐藤礼物 | 私は佐藤さんにプレゼントをあげます。 | 我是给予者。 |
| 我给你礼物 | 私はあなたにプレゼントをあげます。 | 我给对方。 |
| 佐藤给铃木礼物 | 佐藤さんは鈴木さんにプレゼントをあげます。 | 两人都不属于“我方”。 |
| 佐藤给我礼物 | 佐藤さんは私にプレゼントをくれます。 | 礼物朝“我”而来。 |
| 佐藤给我哥哥礼物 | 佐藤さんは私の兄にプレゼントをくれます。 | 哥哥属于“我方”。 |
| 我给佐藤礼物 | 私は佐藤さんにプレゼントをくれます。❌ | 「くれる」不能用于“我给别人”。 |

# 常用例句

- 母は私にケーキをくれました。——妈妈给了我蛋糕。
- 友だちは私に写真をくれました。——朋友给了我照片。
- 私は友だちに写真をあげました。——我送照片给朋友。
- 田中さんは鈴木さんに本をあげました。——田中送书给铃木。

# 助词关系

- `に`：接收者／动作对方。
- `を`：被给出的物品。

母は私にケーキをくれました中，私に是接收者，ケーキを是被给出的物品。

# JLPT 提示

- `あげます`：我／他人给对方或第三方。
- `くれます`：他人给我或我方的人。
- 遇到授受动词时，先判断东西是否朝“我／我方”移动。
