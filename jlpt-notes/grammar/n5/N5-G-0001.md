# 核心用法

- 名词 + です：是……
- 名词 + じゃありません：不是……；「ではありません」的缩略形式，较口语、自然。
- 名词 + ではありません：不是……；较正式，可用于书面语或郑重的谈话。

「じゃ」是「では」的缩略形式。两者都是礼貌否定，意思相同；「ではありません」并非只能用于书面语。

# 例句

- わたしは学生です。——我是学生。
- わたしは会社員じゃありません。——我不是公司职员。
- 田中さんは先生ではありません。——田中不是老师。

# 易混项

「学生じゃないです」也常用于日常的礼貌口语；本卡优先掌握课程中的「じゃありません／ではありません」。

# N5 要点

- 提问：学生ですか。
- 回答：はい、学生です。／いいえ、学生ではありません。
- 「ではありません」和「じゃありません」后面不能再加「です」。
