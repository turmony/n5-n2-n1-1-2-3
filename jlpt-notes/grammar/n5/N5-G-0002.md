# 核心用法

- 动词的ます形 + ます：做……；会做……；将要做……
- 动词的ます形 + ません：不做……；不会做……

「ます／ません」是动词的礼貌体非过去式。根据语境，「ます」可表示现在的习惯、将来的动作或一般事实。

# 变形例

- 食べる → 食べます／食べません
- 行く → 行きます／行きません
- する → します／しません
- 来る → 来ます（きます）／来ません（きません）

# 例句

- わたしは毎朝コーヒーを飲みます。——我每天早晨喝咖啡。
- 今日は会社へ行きません。——今天不去公司。
- 明日、東京へ行きます。——明天去东京。

# 易混项

- 不是直接在所有动词后加「ます」；动词须先变为对应的ます形。例如「行く」→「行きます」，不能说「行くます」。
- 名词句的礼貌体用「です／ではありません」；动词句用「ます／ません」。
- 「～ないです」也可用于日常礼貌口语；本卡优先掌握课程中的「～ません」。

# N5 要点

- 提问：食べますか。——吃吗？
- 回答：はい、食べます。／いいえ、食べません。
- 「～ます」不只表示“正在做”，也可表示习惯和将来。
