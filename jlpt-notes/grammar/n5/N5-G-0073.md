# 核心

「なかった形」表示简体过去否定，意思是“没有……／没做……／不是……”。

- 昨日、学校へ行かなかった。——昨天没去学校。
- この本は高くなかった。——这本书不贵。
- 昨日は休みじゃなかった。——昨天不是休息日。

# 三类动词的なかった形

| 类别 | 变化规则 | 例子 |
| --- | --- | --- |
| 第一类动词（五段） | 将词尾从う段改为同行あ段，直接＋なかった；「う」改为「わ」 | 書く→書かなかった；読む→読まなかった |
| 第二类动词（一段） | 去掉「る」＋なかった | 食べる→食べなかった；見る→見なかった；起きる→起きなかった |
| 第三类动词（不规则） | 单独记忆 | する→しなかった；来る（くる）→来なかった（こなかった） |

| 辞书形词尾 | 改为 | 再加 | 例子 |
| --- | --- | --- | --- |
| う | わ | なかった | 買う→買わなかった |
| つ | た | なかった | 待つ→待たなかった |
| る | ら | なかった | 帰る→帰らなかった |
| く | か | なかった | 書く→書かなかった |
| ぐ | が | なかった | 泳ぐ→泳がなかった |
| す | さ | なかった | 話す→話さなかった |
| ぬ | な | なかった | 死ぬ→死ななかった |
| ぶ | ば | なかった | 遊ぶ→遊ばなかった |
| む | ま | なかった | 読む→読まなかった |

# 形容词和名词的なかった形

| 类别 | 规则 | 例子 |
| --- | --- | --- |
| 一类形容词（い形容词） | 去「い」＋くなかった | 高い→高くなかった；おいしい→おいしくなかった |
| な形容词 | 词干＋じゃなかった | 静か→静かじゃなかった；便利→便利じゃなかった |
| 名词 | 名词＋じゃなかった | 学生→学生じゃなかった；休み→休みじゃなかった |

# 易错点

- 「う」要变为「わ」后再加「なかった」：買う→買わなかった。
- 「ある」的过去否定是「なかった」：昨日、時間がなかった。——昨天没有时间。
- 「いい」的なかった形是「よくなかった」。
- 「きれい」是な形容词：きれいじゃなかった，不是「きれくなかった」。
- 普通体用「行かなかった」；礼貌地说通常用「行きませんでした」。
