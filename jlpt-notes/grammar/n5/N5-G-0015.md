# 核心：交通工具、手段

交通工具用「名词 + で」表示移动方式。

**形式**  
`交通工具 + で + 地点へ／に + 行く／来る／帰る`

**例句**

- 私は自転車で学校へ行きます。——我骑自行车去学校。
- 電車で東京へ行きます。——坐电车去东京。
- 飛行機で日本へ来ました。——坐飞机来到日本。

# 「歩いて」与「徒歩で」

- `歩いて` 是动词「歩く」的て形：`歩いて学校へ行きます。`——走路去学校。
- `徒歩` 是名词，因此可接「で」：`徒歩で学校へ行きます。`——步行去学校。
- `歩いてで学校へ行きます` 是错误形式；动词て形后不能再接表示手段的「で」。

日常会话中「歩いて行きます」更自然；「徒歩で行きます」也正确，常见于书面说明、路线与较正式表达。

# 用法总览

| 排序 | 用法 | 简单说明 |
| --- | --- | --- |
| 1 | 动作、事件发生的地点 | 在哪里做某事／发生什么事 |
| 2 | 手段、方法、交通工具 | 用什么做、以什么方式移动 |
| 3 | 原因、理由 | 因为什么而出现结果 |
| 4 | 材料 | 用什么材料制作 |
| 5 | 人数、成员构成 | 几个人一起做 |
| 6 | 状态、样子 | 以什么状态做 |
| 7 | 范围、标准、限定条件 | 在什么范围内、以什么条件判断 |
| 8 | 时间、价格、数量 | 花多久、多少钱、多少构成结果 |

> 此顺序按 N5 初级教材与日常表达的实用出现优先度整理，不是全部日语文体的精确语料排名。

# 1. 动作、事件发生的地点

**形式**  
`地点 + で + 动作／事件`

**例句**

- レストランで昼ごはんを食べます。——在餐厅吃午饭。
- 公園でコンサートがあります。——公园有音乐会。

# 2. 手段、方法、交通工具

**形式**  
`名词 + で + 动词`

**例句**

- ペンで字を書きます。——用笔写字。
- 日本語で話します。——用日语说。
- バスで学校に行きます。——坐公交去学校。

# 3. 原因、理由

**形式**  
`名词 + で + 结果`

**例句**

- 病気で学校を休みました。——因生病没去学校。
- 台風で電車が遅れました。——因台风电车晚点。

# 4. 材料

**形式**  
`材料 + で + 制作动词`

**例句**

- 木で机を作ります。——用木头做桌子。
- りんごでジュースを作ります。——用苹果做果汁。

# 5. 人数、成员构成

**形式**  
`人数／群体 + で + 动词`

**例句**

- ひとりで勉強します。——一个人学习。
- 家族全員で旅行しました。——全家一起旅行。

# 6. 状态、样子

**形式**  
`状态名词 + で + 动词`

**例句**

- はだしで歩きます。——光脚走路。
- 大きい声で話します。——大声说话。

# 7. 范围、标准、限定条件

**形式**  
`范围／条件 + で + 判断、比较`

**例句**

- 世界で一番長い川はナイル川です。——在世界范围内最长的河是尼罗河。
- これで十分です。——这样就足够了。

# 8. 时间、价格、数量

**形式与例句**

- `时间 + で + 完成／变化`  
  この仕事は一日で終わります。——这项工作一天就完成。
- `价格 + で + 买う`  
  この本を千円で買いました。——我用一千日元买了这本书。
- `数量 + で + 总价`  
  四つで五百円です。——四个五百日元。

# 易混项

- 学校で勉強します：动作地点。  
  学校に先生がいます：存在地点。
- 車で行きます：名词「车」+ 格助词「で」。  
  歩いて行きます：动词て形，不能加「で」。
- 静かで便利です中的「で」是な形容词的连接形式，不是本课的格助词「で」。
