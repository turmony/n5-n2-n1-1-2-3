# 核心用法

- い形容词 + です：……的。
- 去掉词尾「い」+ くないです：不……。

い形容词的基础否定使用「～くないです」，不能像名词、な形容词那样直接接「じゃありません」。因此「おいしいじゃありません」是错误形式；应说「おいしくないです」。

# 变形例

- おいしい → おいしいです／おいしくないです
- 高い → 高いです／高くないです
- 寒い → 寒いです／寒くないです

# 「いい／よい」的例外

- いいです、よいです：都表示“好”；日常会话中「いいです」更常用。
- 否定按「よい」变化：よくないです。
- 不能说「いくないです」。

# 例句

- 台湾料理はおいしいです。——台湾菜很好吃。
- この店の料理はおいしくないです。——这家店的菜不好吃。
- このかばんは高くないです。——这个包不贵。

# 易混项

- 「おいしいじゃありません」错误；い形容词的否定要将词尾「い」变为「くないです」。
- い形容词修饰名词时直接放在名词前：おいしい料理、高いかばん。
- 「きれい」虽以「い」结尾，却是な形容词：きれいです／きれいじゃありません／きれいな部屋。
- 不能只根据词尾「い」判断词类。

# N5 要点

- 名词、な形容词否定：～じゃありません。
- い形容词否定：～くないです。
- 「いい」的否定固定为「よくないです」。
