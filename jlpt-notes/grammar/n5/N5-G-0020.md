# 核心：～ましょう

`动词ます形去掉ます + ましょう` 表示“……吧”“一起……吧”，用于提出积极的共同提议，或在双方已有共识后确定接下来的行动。

- 帰ります → 帰りましょう
- 食べます → 食べましょう
- します → しましょう
- 来ます（きます）→ 来ましょう

# 邀请后确定安排

- A：明日の夜、いっしょに映画を見ませんか。  
  明天晚上一起看电影好吗？
- B：いいですね。何時ですか。  
  好呀，几点？
- A：じゃ、夜7時に新宿駅で会いましょう。  
  那么，晚上七点在新宿站见吧。

先用「ませんか」询问意愿；对方同意后，用「ましょう」提出或确定具体安排。

# 补充：意向形

意向形是「～ましょう」的随意对应表达，可用于朋友间的邀请，也可表示自己的决心。

- 会いましょう → 会おう。——见面吧。
- 明日から早く寝よう。——从明天起我要早点睡。

## 一类动词：辞书形词尾变「お段＋う」

| 辞书形词尾 | 意向形 | 例子 |
| --- | --- | --- |
| う | おう | 買う → 買おう |
| つ | とう | 待つ → 待とう |
| る | ろう | 帰る → 帰ろう |
| む | もう | 読む → 読もう |
| ぶ | ぼう | 遊ぶ → 遊ぼう |
| ぬ | のう | 死ぬ → 死のう |
| く | こう | 書く → 書こう |
| ぐ | ごう | 泳ぐ → 泳ごう |
| す | そう | 話す → 話そう |

## 二类动词：去「る」＋よう

- 食べる → 食べよう
- 見る → 見よう
- 起きる → 起きよう

## 三类动词：特殊变化

- する → しよう
- 来る（くる）→ 来よう（こよう）

# 易错点

- 帰る → 帰ろう：虽然以「る」结尾，却是一类动词。
- 食べる → 食べよう：是二类动词。

因此，不能只根据是否以「る」结尾判断意向形；需要先判断动词类别。

# JLPT 提示

- `～ましょう` 是本课核心：礼貌地提议或确定共同安排。
- 意向形是补充：用于随意邀请，也可表达自己的决心。
- 对老师、上司或不熟的人，避免直接使用「帰ろう」等意向形。
