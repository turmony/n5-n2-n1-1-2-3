# 核心

助词「に」可以表示人、动物或物体存在所在的地点，常与「います」「あります」搭配。

> 地点 に 人／动物 が います。  
> 地点 に 物体／设施 が あります。

# 图片例句

- 教室に学生がいます。——教室里有学生。  
  「教室に」表示学生存在的地点。学生是有生命的人，因此用「います」。
- 学校にプールがあります。——学校里有游泳池。  
  「学校に」表示游泳池存在的地点。游泳池是无生命的设施，因此用「あります」。

# 存在地点「に」与动作地点「で」

- 「に」：表示人、动物、物体或设施存在在哪里。
- 「で」：表示动作、活动、事件在哪里进行或发生。

> 学校でお祭りがあります。  
> 学校举行祭典／学校有祭典活动。

「お祭り」是活动、事件类名词。句中的重点不是“一个物体固定存在于学校”，而是“祭典这一活动在学校举行”，所以地点使用「で」。

# 对比

- 学校にプールがあります。——学校里有游泳池。  
  游泳池是设施，表示存在，用「に」。
- 学校でお祭りがあります。——学校举行祭典。  
  祭典是活动，表示活动举行的地点，用「で」。

# 常用例句

- 公園に犬がいます。——公园里有狗。
- 机の上に本があります。——桌子上有书。
- 体育館で試合があります。——体育馆有比赛。
- 駅でイベントがあります。——车站有活动。

# 易错点

- × 学校にお祭りがあります。
- ○ 学校でお祭りがあります。

本课中，「お祭り」属于活动、事件，因此用「で」表示举行地点。

# JLPT 提示

看到「います／あります」时，先判断后面的名词：人、动物、物体、设施存在时，地点用「に」；比赛、祭典、会议、活动等事件举行时，地点用「で」。
