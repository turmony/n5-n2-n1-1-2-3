# 核心

`名词 + から` 表示“从……”“离……”，指出时间、空间或位置关系的起点。

# 用法总览

| 用法 | 例句 | 含义 |
| --- | --- | --- |
| 时间起点 | 朝9時から仕事をします。 | 从早上九点开始工作。 |
| 移动出发点 | 東京から沖縄へ行きます。 | 从东京去冲绳。 |
| 进入经由点 | あそこのドアから入ってください。 | 请从那边的门进入。 |
| 距离／位置的参照起点 | 私の家は駅から遠いです。 | 我家离车站远。 |

# 1. 时间起点

- 朝9時から仕事をします。——从早上九点开始工作。
- 授業は8時からです。——课程从八点开始。
- 授業は8時から12時までです。——课程从八点到十二点。

# 2. 移动出发点

- 東京から沖縄へ行きます。——从东京去冲绳。
- 家から学校まで歩きます。——从家走到学校。

「から」表示离开的地方；「へ／に」表示前往的方向或到达点。

# 3. 进入经由点

- あそこのドアから入ってください。——请从那边的门进入。
- この道から駅へ行けます。——可以从这条路去车站。

这里的「から」强调进入或前往时所经过的入口、通道。

# 4. 距离／位置的参照起点

- 私の家は駅から遠いです。——我家离车站远。
- 学校はここから近いです。——学校离这里近。

这类句子没有移动动词。「駅」「ここ」只是测量距离时的参照起点；整句说明两个地点的远近关系。

# 易混点

- 東京から沖縄へ行きます：`から` 是出发点。
- 東京で仕事をします：`で` 是动作地点。
- 学校に行きます：`に` 是到达点。

# JLPT 提示

- `时间 + から`：从某时开始。
- `地点 + から + 行く／来る／帰る`：从某地出发。
- `入口／通道 + から + 入る`：从某处进入。
- `地点 + から + 近い／遠い`：以某地为距离参照点。
- `から～まで`：从……到……。
