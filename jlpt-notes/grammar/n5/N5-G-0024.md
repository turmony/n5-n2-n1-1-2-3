# 核心

`名词 + まで` 表示“到……为止”，指出时间或空间范围的终点，也可表示数量、次数等的上限。

# 用法总览

| 用法 | 例句 | 含义 |
| --- | --- | --- |
| 时间终点 | 夜6時まで働きます。 | 工作到晚上六点。 |
| 空间终点 | 友だちを駅まで車で送ります。 | 开车把朋友送到车站。 |
| 数量／次数上限 | 一人四冊まで本を借りることができます。 | 每人最多可借四本书。 |

# 1. 时间终点

- 夜6時まで働きます。——工作到晚上六点。
- 図書館は5時までです。——图书馆到五点为止。
- 授業は8時から12時までです。——课程从八点到十二点。

`から～まで` 表示完整范围：“从……到……”。

# 2. 空间终点

- 友だちを駅まで車で送ります。——开车把朋友送到车站。
- 家から学校まで歩きます。——从家走到学校。
- 駅までバスで行きます。——坐公交车到车站。

「まで」强调移动或范围的终点；「に」则更强调到达点。

- 駅に行きます。——去车站。
- 駅まで行きます。——一直去到车站／到车站为止。

# 3. 限界：数量、次数等上限

- 一人四冊まで本を借りることができます。——每人最多可借四本书。
- この部屋は20人まで入れます。——这个房间最多能进二十人。
- ここから駅まで10分です。——从这里到车站是十分钟。

数量用法里的「四冊まで」是“最多四本”，不表示必须正好借四本。

# 「まで」与「までに」

- 6時まで働きます。——工作持续到六点；强调动作一直持续到终点。
- 6時までに来てください。——请在六点以前到；强调六点是完成“来”的截止时限。

初级阶段先记住：有持续过程时多用「まで」；有“在某时之前完成”的截止要求时用「までに」。

# JLPT 提示

- `时间 + まで`：到某时为止。
- `地点 + まで`：到某地为止。
- `数量 + まで`：最多……。
- `から～まで`：从……到……。
