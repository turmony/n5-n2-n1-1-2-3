# 核心形式

- な形容词 + `でした`：过去很……／过去处于……状态。
- な形容词 + `じゃありませんでした`：过去不……。
- な形容词 + `ではありませんでした`：过去不……；较正式。

| 时间 | 肯定 | 否定 |
| --- | --- | --- |
| 非过去 | 静かです | 静かじゃありません |
| 过去 | 静かでした | 静かじゃありませんでした |

# 过去的事实与感想

- **过去的事实、状态**  
  この川は昔、とてもきれいでした。  
  这条河从前非常漂亮。

- **对过去经历的感想**  
  昨日、お花見をしました。とてもきれいでした。  
  昨天去赏花了。非常漂亮。

后一句说的是昨天看到花时的感受，因此用过去式 `きれいでした`。

# 易混项

- `な` 只用于修饰名词：`静かな部屋`。句末说 `部屋は静かでした`，不说 `静かなでした`。
- `きれい` 虽以「い」结尾，却是な形容词：`きれいでした` 正确；`きれいくなかったです` 错误。
- 过去否定必须完整使用 `静かじゃありませんでした`，不能用 `静かじゃありません` 表示过去。
- な形容词在礼貌体句尾的形式与名词句相同：`学生でした`／`静かでした`；但修饰名词时，名词用 `の`，な形容词用 `な`。

# 例句

- 昨日のホテルは静かでした。——昨天的酒店很安静。
- その町は便利じゃありませんでした。——那个城镇过去不方便。
- 去年、東京はにぎやかでした。——去年东京很热闹。

# N5 要点

- 时间词如 `昨日`、`去年`、`昔` 常提示过去语境。
- 疑问：昨日のホテルは静かでしたか。——昨天的酒店安静吗？
- 回答：はい、静かでした。／いいえ、静かじゃありませんでした。
