# 核心

`名词A や 名词B（など）` 表示只列举其中一部分，意思是“A、B 等”。「や」所列项目是代表例子，不表示已经列出全部。

# 图片例句

- パンと牛乳を買いました。——买了面包和牛奶；「と」明确列出这两项。
- パンや牛乳（など）を買いました。——买了面包、牛奶等；还可能买了其他东西。

# 「や」与「と」

| 助词 | 列举性质 | 例句 | 含义 |
| --- | --- | --- | --- |
| と | 完整、封闭式列举 | パンと牛乳を買いました。 | 买了面包和牛奶。 |
| や | 部分、开放式列举 | パンや牛乳を買いました。 | 买了面包、牛奶等。 |

「と」不带“等等”的意思；「や」把所举名词当作代表例子。

# 「など」

「など」接在最后一个名词后，进一步强调“等等”。

- パンや牛乳などを買いました。——买了面包、牛奶等。
- 机の上に本やノートなどがあります。——桌上有书、笔记本等。

「や」本身已有举例意味，因此「など」可以省略；加上后“等等”的意味更明显。

# 自然例句

- スーパーで野菜や果物を買います。——在超市买蔬菜、水果等。
- 新聞や雑誌を読みます。——读报纸、杂志等。
- この店ではパンやケーキなどを売っています。——这家店卖面包、蛋糕等。
- 休みの日は映画や音楽を楽しみます。——休息日享受电影、音乐等。

# 接续与边界

- 「や」主要连接名词，不能直接连接完整句子或动词。
- 并列后的助词接在最后一个名词后：`パンや牛乳を買います`。
- 多个名词共用同一动词时，该动词仍须在意义上适用于所有名词：
  - パンや牛乳を買います。✅
  - パンや牛乳を食べます。❌ 牛乳通常用「飲む」。

# JLPT 提示

- `N1 や N2`：A、B 等。
- `N1 や N2 など`：A、B 等等。
- `と`：完整、明确列举；`や`：部分举例列举。
