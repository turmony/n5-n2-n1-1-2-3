# 核心用法

- 名词 A + の + 名词 B：A 与 B 有某种关系，可先理解为“A 的 B”。
- 「の」的具体关系必须结合语境判断，不能只机械翻译成“的”。

# 四种常见关系

- 所属：わたしはソニーの社員です。——我是索尼的职员。
- 所有：これはわたしの傘です。——这是我的伞。
- 所在：ポストは市役所の前です。——邮箱在市政府前面。
- 所产／来源：これは日本のりんごです。——这是日本产的苹果／日本的苹果。

# 多义表达

これは母の絵です。——这是一幅母亲的画。

根据语境，可能表示：

- 画中画的是母亲：母亲的肖像画。
- 这幅画属于母亲：母亲所有的画。
- 母亲画的画：母亲创作的画。

# 易混项

- 「の」不只表示所有，也可表示所属、地点、来源、人物关系或创作者等。
- 两个名词之间需要表达关系时，基础形式是「名词 + の + 名词」。
- 「母の絵」不能脱离语境固定为一种中文意思。

# N5 要点

先识别 A 和 B 的关系，再理解「A の B」的意思。
