# 核心

在授受动词及接受一方的动作中，「から」表示动作的授方、来源，相当于“从……那里”。

> 接受者 は 授方 から 物 を 动词。

# 常用动词

- 借りる：借入
- もらう：得到、收到
- 習う：向某人学习

# 图片例句

- 私は友達に自転車を借りました。
- 私は友達から自転車を借りました。——我从朋友那里借了自行车。

在这类“从对方获得”的动作中，人的「に」可以换成「から」。

- 私は友達からお土産をもらいました。——我从朋友那里收到了特产。
- 私は友達から中国語を習いました。——我向朋友学习了中文。

# 团体、机构作授方

银行、学校、公司等团体或机构作来源时，优先使用「から」，强调“来源”。

- 私は銀行からお金を借りました。——我从银行借了钱。
- 私は学校から奨学金をもらいました。——我从学校得到了奖学金。

「銀行にお金を借りました」并非绝对语法错误，但本课中优先使用「銀行からお金を借りました」。

# 不能用「から」的情况

- 私は友達にお土産をあげました。——我给朋友特产。
- 私は友達に中国語を教えました。——我教朋友中文。

这里东西或知识从“我”流向朋友；朋友是接受者或动作对象，因此使用「に」，不能改成「から」。

# 判断方法

- 东西、知识、钱从对方流向我：用「から」。  
  友達から本をもらいます。
- 东西、知识从我流向对方：用「に」。  
  友達に本をあげます。

# 「から」的其他意思

- 起点：朝9時から働きます。——从早上九点开始工作。
- 原因：仕事で使いますから、日本語を勉強します。——因为工作中要用，所以学习日语。

本卡的「から」表示动作的授方、来源，不表示起点或原因。

# JLPT 提示

先判断动作方向。对方是“给我、借我、教我”的来源时，用「から」；对方是“我给、我教”的接受者时，用「に」。
