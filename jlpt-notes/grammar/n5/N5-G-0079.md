# 核心

连体词只能在名词短语中修饰名词，本身不能单独作谓语，也不能变化为否定或过去形式。

**结构**：连体词＋（其他修饰语）＋名词

「その赤い傘」中，「その」修饰「傘」，中间可以有「赤い」等其他修饰语。

# 常见连体词

| 类别 | 连体词 | 例子 |
| --- | --- | --- |
| 指示类 | この、その、あの、どの | この本、あの人、どのかばん |
| 指示类 | こんな、そんな、あんな、どんな | こんな家、どんな映画 |
| 其他 | ほんの、大きな、小さな、おかしな、ある、たいした | ほんの気持ち、大きな夢、ある日 |

- ほんの：一点点、仅仅。
- 大きな／小さな：大的／小的，只用于修饰名词。
- おかしな：奇怪的。
- ある：某个。例：ある日（有一天）。
- たいした：重要的、了不起的；常见于否定。

# 图片例句

- すてきな家ですね。私もこんな家に住みたいです。——真漂亮的房子啊。我也想住在这样的房子里。
- あの人はどなたですか。——那位是谁？
- その赤い傘を見せてください。——请给我看看那把红伞。
- これ、ほんの気持ちです。どうぞ。——这个只是小小心意，请收下。
- 山田さんはおかしな服装をしています。——山田穿着奇怪的服装。
- 私は大きな夢があります。——我有一个远大的梦想。

# 与形容词的区别

「小さい」是一类形容词，可单独作谓语和变化：小さいです／小さくない／小さかった。

「小さな」是连体词，只修饰名词：小さなかばん。  
× 小さなです　× 小さなない　× 小さなかった。

「大きな／大きい」也遵循同样的区别。

# 易错点

- 「この／その／あの／どの」后面必须有名词：× このです　○ この本です。单独说“这个”用「これ」。
- 「どの＋名词」用于多个对象中提问：どの本ですか。
- 「どんな＋名词」询问性质或类别：どんな本ですか。
- 连体词不接「だ」：× 大きなだ夢　○ 大きな夢。
