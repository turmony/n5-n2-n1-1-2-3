# 核心

助词「に」可以表示动作所到达、接触或作用的对象，即动作的“接触点”。

> 名词 に 动词

接触点可以是实际接触的物体，也可以是抽象的对象。

# 物理接触

- 車が壁にぶつかりました。——车撞到了墙壁。

「壁に」是车辆撞上的实际接触点。「ぶつかる」常与「に」搭配，表示“撞到……”。

# 抽象接触

- 私は駅で友達に会いました。——我在车站遇到了朋友。

「駅で」表示见面动作发生的地点；「友達に」表示“见到”的对象，即动作接触到的人。这里是人与人相遇的抽象接触。

# 与「と」的区别

- 私は駅で友達に会いました。——我在车站见到了朋友。  
  「に会う」强调“朋友”是见到的对象。
- 私は駅で友達と会いました。——我在车站和朋友见面了。  
  「と会う」强调朋友是一起进行“见面”这一相互动作的同伴。

在「会う」的句子中，「に」和「と」都能使用；「に会う」偏重遇见、见到，「と会う」偏重相约或相互见面。

# 常用例句

- ボールが窓に当たりました。——球撞到了窗户。
- 私は先生に会いました。——我见到了老师。
- 駅で友達と会いました。——我在车站和朋友见面了。

# 易错点

- × 車が壁をぶつかりました。
- ○ 車が壁にぶつかりました。

「壁」是撞上的接触点，因此用「に」，不用「を」。

# JLPT 提示

看到「に」时，可以判断它是否表示动作的目标或接触点。物理上如“撞到墙”，抽象上如“遇见朋友”，都可以使用「に」。
