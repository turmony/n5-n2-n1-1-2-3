# 核心

在给予、借用、传递等动作中，可用 `动作对方 に + 动作作用对象 を + 动词`。`に` 表接收者、给予者或其他动作对方；`を` 表被给予、借用或直接作用的东西。

# 图片中的目的语数量

| 类型 | 例句 | 说明 |
| --- | --- | --- |
| 目的语 0 | 私はプールで泳ぎます。／彼女は笑っています。 | 「泳ぐ」「笑う」不需要目的语。 |
| 目的语 1 | ご飯を食べます。／ドアを開けます。 | `を` 标记动作直接作用的对象。 |
| 目的语 2 | 恋人にプレゼントをあげます。／友達に傘を借ります。 | `に` 标记动作对方；`を` 标记物品。 |

# 图片例句

- 私は恋人にプレゼントをあげます。——我送礼物给恋人。  
  恋人に是接收者；プレゼントを是被送出的礼物。
- 私は友達に傘を借ります。——我向朋友借伞。  
  友達に是借用动作的对方／借出者；傘を是被借的物品。

# 常用句型

- 母に花をあげます。——送花给妈妈。
- 先生に手紙を書きます。——给老师写信。
- 友だちに本を貸します。——把书借给朋友。
- 友だちに本を借ります。——向朋友借书。
- 父に写真を見せます。——给爸爸看照片。

# 「借りる」的に与から

- 友だちに傘を借ります。——向朋友借伞；强调动作对方。
- 友だちから傘を借ります。——从朋友那里借伞；强调来源。

两句都正确。N5 阶段可先记：`に` 看作动作对方，`から` 看作来源。

# 不能机械套用

- 友だちに電話します。——给朋友打电话；对方用「に」。
- 友だちと会います。——和朋友见面；「会う」的对象用「と」。
- 友だちと傘を借ります。——和朋友一起借伞；「と」是共同动作人，不是借出者。

# JLPT 提示

- `人 に 物 を あげる／貸す／見せる`：给某人某物。
- `人 に／から 物 を 借りる`：向某人／从某人那里借某物。
- `を` 是动作直接作用的对象；`に` 常为动作对方、接收者或关联人。
- 不同动词支配的助词不同，不能把所有“对人”的动作都说成「人に」。
