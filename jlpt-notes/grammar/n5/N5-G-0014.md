# 基本规则

- 助词写作「へ」，读作「え」。
- 普通假名读「へ（he）」；作为助词时读「え（e）」。

# 用法总览

| 排序 | 用法 | 简单说明 |
| --- | --- | --- |
| 1 | 实际移动的方向、目的地 | 去、来、回等移动朝向哪里 |
| 2 | 朝某方向前进 | 向北、向车站等方向移动 |
| 3 | 书信、邮件的收件对象 | 表示“写给谁” |
| 4 | 与も／は／と结合 | 在方向含义上补充“也、对比、强调” |

> 此顺序按 N5 日常表达的实用出现优先度排列，不是所有日语文体的精确语料统计。

# 1. 实际移动的方向、目的地

表示人或物朝某个地点移动。

**形式**  
`地点 + へ + 行く／来る／帰る／出かける`

**例句**

- 明日、東京へ行きます。——明天去东京。
- うちへ帰ります。——回家。

# 2. 朝某方向前进

表示朝某个具体或抽象方向移动。

**形式**  
`方向／地点 + へ + 進む／向かう／飛ぶ`

**例句**

- 台風は北へ進んでいます。——台风正向北移动。
- 駅へ向かいます。——前往车站。

# 3. 书信、邮件的收件对象

表示信息、信件是写给谁的，主要用于信件、明信片和邮件开头。

**形式**  
`人 + へ`

**例句**

- 田中さんへ——给田中。
- 友だちへ——给朋友。

送礼物的接收者在 N5 基础句中用「に」：`友だちにプレゼントをあげます`。书面语中有时可见「～へ贈る」，但不作为本课基础替换规则掌握。

# 4. 与も／は／と结合

这些不是新的「へ」含义，而是在方向关系上加入附加语气。

**形式与例句**

- `地点 + へも + 移动动词`  
  日本へも行きます。——也去日本。
- `地点 + へは + 移动动词`  
  日本へは行きません。——日本倒是不去。
- `方向 + へと + 移动动词`  
  北へと進みます。——向北方前进。  
  「へと」更强调方向，属于后续表达。

# 「に」与「へ」

|  | に | へ |
| --- | --- | --- |
| 重点 | 到达、落点 | 方向、朝向 |
| 例句 | 東京に行きます | 東京へ行きます |
| 范围 | 时间、对象、地点、结果等多种用法 | 主要表示方向与到达点 |

- `東京に行きます` 与 `東京へ行きます` 都正确。
- 初级阶段，`へ` 更突出“往东京的方向”，`に` 更容易使人注意“抵达东京”的落点。
- `学校に着きます` 优先用「に」；时间点、接收者、存在地点、变化结果等也不能都换成「へ」。

# 易混项

- 教室へ行きます：朝教室移动。  
  教室に先生がいます：老师存在于教室。  
  「へ」不能替换存在地点的「に」。
- 7時に起きます ✔；7時へ起きます ✘。
- 台風は北へ進んでいます：自然地强调“向北”。
