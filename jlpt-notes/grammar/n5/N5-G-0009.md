# 核心用法

- 名词 + でした：过去是……。
- 名词 + じゃありませんでした：过去不是……。
- 名词 + ではありませんでした：过去不是……；较正式。

# 四种形式对照

| 时态 | 肯定 | 否定 |
| --- | --- | --- |
| 非过去 | 学生です | 学生じゃありません |
| 过去 | 学生でした | 学生じゃありませんでした |

# 例句

- 昨日は日曜日でした。——昨天是星期日。
- 去年、わたしは会社員でした。——去年我是公司职员。
- 田中さんは学生ではありませんでした。——田中过去不是学生。

# 易混项

- 「でした」只用于过去，不表示现在。
- 「じゃありませんでした」较自然；「ではありませんでした」较正式。
- 不能说「学生じゃありませんです」；过去否定应完整使用「じゃありませんでした」。

# N5 要点

- 昨日、去年、先週等时间词常提示过去。
- 疑问：昨日は休みでしたか。——昨天是休息日吗？
