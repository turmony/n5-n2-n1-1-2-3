# 核心用法

- 名词 + も：也……、同样……。
- 「も」表示把另一项加入已经成立的情况中。

例：高橋さんは学生です。山田さんも学生です。——高桥是学生，山田也是学生。

# 与助词的连接

- は → も（替换）：わたしは学生です。弟も学生です。
- が → も（替换）：寿司が好きです。ラーメンも好きです。
- を → も（绝大多数情况下替换）：新聞を買いました。雑誌も買いました。少数书面强调场合可见「をも」。
- へ → も（大多数情况下替换）：京都へ行きました。奈良も行きました。少数可保留为「へも」：奈良へも行きました。
- に + も → にも：母にプレゼントをあげました。父にもあげました。
- で + も → でも：電車で行くことができます。バスでも行くことができます。

# 语义边界

「も」有时替换原助词，有时保留原助词并组合。初学阶段先记：

- 「は／が／を」通常由「も」替换。
- 「に／で」通常保留，成为「にも／でも」。
- 「へ」大多数情况下由「も」替换，也可用「へも」明确保留方向关系。

# 易混项

- 助词「は」写作「は」，读作「わ」；同一名词要表示“也”时用「も」，不说「はも」。
- 一句中同时出现「は」和「も」时，通常是它们分别连接不同成分：この店はラーメンもおいしいです。
- 「にも／でも」中的「に／で」仍表示对象、目的地、地点或手段等关系。

# N5 要点

先看名词后的原助词，再判断「も」是替换它还是与它组合。
