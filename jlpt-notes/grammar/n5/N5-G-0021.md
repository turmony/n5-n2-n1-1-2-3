# 核心

助词「を」写作「を」，读作「お（o）」。最基本的作用是标记他动词的动作对象；与移动动词搭配时，还可表示经过点或离开点。

# 用法总览

| 用法 | 形式 | 例句 |
| --- | --- | --- |
| 动作作用对象 | `N を 他动词` | ご飯を食べます。——吃饭。 |
| 产生／改变结果的对象 | `N を V` | 穴を掘ります。——挖洞。 |
| 经过点 | `地点 を 移动动词` | 橋を渡ります。——过桥。 |
| 离开点 | `地点 を 离开动词` | 教室を出ます。——离开教室。 |

# 1. 动作作用对象

- ご飯を食べます。——吃饭。
- ビールを飲みます。——喝啤酒。
- 本を読みます。——看书。
- 音楽を聞きます。——听音乐。

# 2. 产生／改变结果的对象

- 穴を掘ります。——挖洞；「穴」是挖这个动作产生的结果。
- お湯を沸かします。——烧开水；「お湯」是被烧至沸腾的对象。

这里的“结果对象”不是“做某事的目的”，而是动作完成后出现或状态被改变的结果。

# 3. 经过点

- 橋を渡ります。——过桥。
- この道を通ります。——经过这条路。
- 公園を散歩します。——在公园散步。
- 毎朝、この道を歩きます。——每天早晨走这条路。

「橋」「道」「公園」在这里不是被动作直接改变的对象，而是移动的路线或经过地点。

# 4. 离开点

- 教室を出ます。——离开教室。
- 家を出ます。——离开家／出门。
- 電車を降ります。——下电车。
- 大学を卒業します。——从大学毕业。

# 易混点

- 橋を渡ります：`を` 表示经过点。
- 学校に行きます：`に` 表示到达点。
- 教室を出ます：`を` 表示离开点。
- 教室に入ります：`に` 表示进入的到达点。

# JLPT 提示

看到「を」时，先看后面的动词：

- 食べる、飲む、読む、聞く：动作对象。
- 掘る、沸かす：产生或改变的结果对象。
- 渡る、通る、歩く、散歩する：经过点。
- 出る、降りる、卒業する：离开点。
