# 核心用法：动作发生的时间点

`时间词 + に + 动词`

「に」表示动作或事件发生的时间点。

- 7時に起きます。——七点起床。
- 6月15日に試合があります。——6月15日有比赛。

# 时间词与「に」

| 时间类别 | 例子 | 规则 |
| --- | --- | --- |
| 精确时刻 | 7時、8時30分 | 基础规则中要加：7時に起きます。 |
| 日期 | 6月15日、12月25日 | 要加：12月25日に会います。 |
| 时段＋精确时刻 | 朝7時 | 要加：朝7時に出ます。关键是精确时刻「7時」。 |
| 星期 | 月曜日、日曜日 | 可加可不加：月曜日に行きます／月曜日、行きます。 |
| 节日、纪念日、假期 | クリスマス、誕生日、夏休み | 通常加：クリスマスに食事をします。 |
| 相对时间 | 今、昨日、今日、明日、いつ | 不加：明日行きます；不能说「明日に行きます」。 |
| 宽泛时段 | 朝、昼、夜 | 初级表达通常不加：朝シャワーを浴びます。 |

「クリスマスに」正确；它属于节日或事件的时间，并非仅仅因为是“绝对时间”。

# 其他用法：按初级日语日常表达的实用出现优先度排序

> 此排序针对 N5 初级教材和日常基础表达的学习优先度，不是跨所有日语文体的精确语料百分比。公开语料研究确认「に」本身是高频格助词，但没有提供所有语义类别可直接通用的统一频率排名。

1. **到达点／移动终点**  
   学校に行きます。——去学校。  
   `に` 可与 `へ` 互换；`へ` 更突出方向，`に` 更突出抵达点。

2. **行为对象、接收者、对方**  
   先生に質問します。——向老师提问。  
   友達にプレゼントをあげます。——送礼物给朋友。

3. **存在地点、放置或附着的位置**  
   机の上に本があります。——桌上有书。  
   壁にポスターを貼ります。——把海报贴在墙上。

4. **目的**  
   買い物に行きます。／泳ぎに行きます。  
   ——去买东西／去游泳。  
   形式：名词或动词ます形去掉「ます」+ に + 行く／来る／帰る。

5. **频率的基准**  
   一週間に3回授業があります。——每周有三次课。

6. **变化、结果**（后续重点学习）  
   医者になります。——成为医生。  
   这里的名词 + に表示变化后的结果。

7. **被动句中的动作发出者**（后续重点学习）  
   先生にほめられました。——被老师表扬了。

# 易混项

- 学校に行きます：`に` 是到达点；学校で勉強します：`で` 是动作发生地点。
- 教室に先生がいます：老师存在于教室；教室で会議があります：会议在教室举行。存在地点用 `に`，事件举行地点通常用 `で`。
- 明日、病院へ行きます：`明日` 后不能加 `に`。
- 朝8時に家を出ます：`朝` 本身很宽泛，但句中有精确时刻 `8時`，所以要加 `に`。
- 「について」「によって」「のに」「に対して」等是后续各自独立的复合语法，不能简单等同于本课的单独格助词「に」。
