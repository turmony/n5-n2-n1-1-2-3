# 核心

「ない形」表示简体非过去否定，即“不……／没有……／不是……”。

- 明日、学校へ行かない。——明天不去学校。
- この本は高くない。——这本书不贵。
- 田中さんは学生じゃない。——田中不是学生。

# 三类动词的ない形

| 类别 | 规则 | 例子 |
| --- | --- | --- |
| 第一类动词（五段） | 将辞书形词尾的う段假名变为同行あ段＋ない | 書く→書かない；読む→読まない；話す→話さない；待つ→待たない |
| 第二类动词（一段） | 去掉「る」＋ない | 食べる→食べない；見る→見ない；起きる→起きない |
| 第三类动词（不规则） | 单独记忆 | する→しない；来る（くる）→来ない（こない） |

| 辞书形词尾 | ない形词尾 | 例子 |
| --- | --- | --- |
| う | わない | 買う→買わない |
| つ | たない | 待つ→待たない |
| る | らない | 帰る→帰らない |
| く | かない | 書く→書かない |
| ぐ | がない | 泳ぐ→泳がない |
| す | さない | 話す→話さない |
| ぬ | なない | 死ぬ→死なない |
| ぶ | ばない | 遊ぶ→遊ばない |
| む | まない | 読む→読まない |

# 形容词和名词的ない形

| 类别 | 规则 | 例子 |
| --- | --- | --- |
| 一类形容词（い形容词） | 去「い」＋くない | 高い→高くない；おいしい→おいしくない |
| な形容词 | 词干＋じゃない | 静か→静かじゃない；便利→便利じゃない |
| 名词 | 名词＋じゃない | 学生→学生じゃない；日本人→日本人じゃない |

「じゃない」较口语；较正式或书面可说「ではない」。

# 易错点

- 「う」变「わない」，不是「あない」：買う→買わない。
- × 食べらない　○ 食べない；× 来るない　○ 来ない（こない）。
- 「ある」的ない形是「ない」：机の上に本がない。——桌上没有书。
- 「いい」的ない形是「よくない」。
- 「きれい」是な形容词：きれいじゃない，不是「きれくない」。
