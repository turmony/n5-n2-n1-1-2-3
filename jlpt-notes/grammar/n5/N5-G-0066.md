# 核心

「疑问词＋（助词）＋も＋否定」表示全面否定，即“没有任何……／谁也不……／哪里也不……”。句末必须是否定形式。

- 何も＋否定：什么也不……
- 誰も＋否定：谁也不……
- どこも／どこにも＋否定：哪里也不……

# 例句

- 今朝は何も食べませんでした。——今天早上什么也没吃。
- 明日はどこも行きません。うちにいます。——明天哪里也不去，待在家里。
- 今日は誰とも話したくないです。——今天不想和任何人说话。
- 妖怪はどこにもいません。人間の想像です。——妖怪哪里也不存在，是人类的想象。
- 冷蔵庫に何もありません。——冰箱里什么也没有。

# 助词与「も」

| 要表达的关系 | 形式 | 例句 |
| --- | --- | --- |
| 做某事的对象 | 何も | 何も食べません。——什么也不吃。 |
| 存在／去往的地点 | どこにも | どこにも行きません。——哪里也不去。 |
| 一起做事的人 | 誰とも | 誰とも話しません。——不和任何人说话。 |
| 接受动作的对象 | 誰にも | 誰にも会いません。——谁也不见。 |

「を」「が」「は」常被「も」取代；「に」「と」「から」等通常保留，形成「にも」「とも」「からも」。

# 易错点

- 必须与否定搭配：× 何も食べます。　○ 何も食べません。
- 「何でも食べます」是“什么都吃”，属于全面肯定，不能混淆。
- 「誰も」是“谁也不”；表达“和谁也不说话”用「誰とも」。
- 「どこにもいません」用于人或动物；「どこにもありません」用于物品。
