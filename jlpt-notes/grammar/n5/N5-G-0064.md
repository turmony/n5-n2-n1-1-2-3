# 核心

「～あとで」表示“……之后／……以后”，在A发生或完成后做B。

- 动词た形＋あとで：仕事が終わったあとで
- 名词＋の＋あとで：会議のあとで

动词用「た形」表示A在B之前完成；整句是不是过去时由后项B决定。  
ご飯を食べたあとで、勉強します。——吃饭后学习。（未来的安排）

# 例句

- 仕事が終わったあとで、映画を見ます。——工作结束后看电影。
- 会議のあとで、社長室に来てください。——会议结束后，请来社长办公室。
- 食事のあとで、映画を見ます。——吃饭后看电影。
- 手を洗ったあとで、ご飯を食べます。——洗手后吃饭。
- 授業が終わったあとで、図書館へ行きます。——下课后去图书馆。

# 与「～てから」的区别

两者都可表示“A之后做B”，在许多语境中能互换；不过关注点不同。

| 形式 | 侧重点 |
| --- | --- |
| Aてから、B | 强调A完成后再进行B；A、B的连续关系较强，A常是B前的步骤。 |
| Aたあとで、B | 交代B发生在A之后；时间关系较宽松，A与B之间也可以有其他事情。 |

- 仕事が終わってから、病院へ行きました。——强调下班后就去医院，衔接较紧。
- 仕事が終わったあとで、病院へ行きました。——下班后去了医院；中间是否有别的事未说明。

# 易错点

- 动词前面用た形：× 食べますあとで　○ 食べたあとで
- 名词与「あとで」之间要用「の」：× 会議あとで　○ 会議のあとで
- 本课固定学习「～たあとで」；也可见「～たあと、…」的形式，初学时先不要混写。
