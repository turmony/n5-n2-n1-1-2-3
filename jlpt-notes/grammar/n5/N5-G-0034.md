# 核心

「もらいます」表示“得到、收到”，主语是得到东西的人（受惠者）。

> 受惠者 は 施惠者 に／から 物 を もらいます。

「もらいです」不是本课要使用的表达；礼貌形式是「もらいます」。

# 谁从谁那里得到：图片中的入门判定

- 第一人称从第二人称获得：○  私はあなたに本をもらいます。
- 第一人称从第三人称获得：○  私は田中さんに本をもらいます。
- 第二人称从第一人称获得：×  这张图的表达规则下，改用「私はあなたに本をあげます」。
- 第三人称从第一人称获得：×  这张图的表达规则下，改用「私は鈴木さんに本をあげます」。
- 第三人称从第三人称获得：○  鈴木さんは佐藤さんに花をもらいました。

这里的“×”并不表示对方现实中不能收到我的东西，而是表示：当“我”是给东西的人时，本课采用“我给出去”的叙述视角，用「あげます」。

# 与「あげます」的区别

- 「もらいます」：强调谁得到了东西。  
  私は友達にプレゼントをもらいました。
- 「あげます」：强调谁给出了东西。  
  私は友達にプレゼントをあげました。

# 助词关系

- 「は」：得到东西的人。
- 「に／から」：给东西的人。
- 「を」：得到的东西。

# 图片例句

- 佐藤さんは鈴木さんに花をあげました。——佐藤给铃木花。
- 鈴木さんは佐藤さんに花をもらいました。——铃木从佐藤那里得到了花。

# 常用例句

- 私は先生から日本語の本をもらいました。——我从老师那里得到了日语书。
- 母は友達に花をもらいました。——妈妈从朋友那里收到了花。

# 易错点

- × 私は田中さんを本をもらいました。
- ○ 私は田中さんに本をもらいました。

# JLPT 提示

看到「もらいます」时，先找“谁得到了东西”；这个人就是句子的主语。再确认给予者用「に／から」，物品用「を」。
