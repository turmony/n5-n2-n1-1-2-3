# 核心

「～くなります／～になります」表示状态、性质、身份、季节、时间等发生变化，成为某种状态。

# 三种接续

| 前项 | 接续 | 例句 |
| --- | --- | --- |
| い形容词 | 去「い」＋くなります | 寒くなりました。——变冷了。 |
| な形容词 | 词干＋になります | 静かになりました。——变安静了。 |
| 名词 | 名词＋になります | 医者になります。——成为医生。 |

# 例句

- 春になりました。——到春天了。
- 来月、18歳になります。——下个月就满18岁了。
- 10時になりました。——到十点了。
- この部屋はきれいになりました。——这个房间变干净了。
- 日本語が上手になりました。——日语变好了。

# 「いい」的特殊变化

「いい」变为「よく」，不能说「いくなります」。

- 天気がよくなりました。——天气变好了。
- 病気がよくなりました。——病好了。

# 「なる」与「する」

| 表达 | 含义 |
| --- | --- |
| 部屋がきれいになりました。 | 房间变干净了；强调状态改变。 |
| 部屋をきれいにしました。 | 我把房间弄干净了；强调有人主动造成变化。 |

对应关系：

- い形容词：`～くなります` ↔ `～くします`
- な形容词／名词：`～になります` ↔ `～にします`

# JLPT 提示

- `～くなります／～になります`：自然变化、结果变化、成长变化。
- `～くします／～にします`：人为决定或主动改变。
- 「春」「10時」「18歳」都是名词，因此用 `～に なります`。
