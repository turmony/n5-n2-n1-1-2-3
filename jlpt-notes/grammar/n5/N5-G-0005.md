# 核心用法

- 名词 + は：提示句子的主题，表示“关于……，接下来要说的是……”。
- 助词写作「は」，读作「わ」。

# 主题与主语

- 主题等于主语：わたしは大学生です。——至于我，是大学生。
- 主题不等于主语：お弁当は妻が作りました。——便当是妻子做的。

后一句中，「お弁当」是谈话主题；执行“做”这个动作的主语是「妻」，所以用「が」。

# 为什么需要「は」

この本は田中さんが書きました。——这本书是田中写的。

「この本は」先设定谈话范围：现在说的是“这本书”。「田中さんが」再说明写书的人是谁。因此「は」能把句子的主题与动作执行者区分开。

对比：田中さんがこの本を書きました。强调“写书的人是田中”。

# 主题省略

主题在上下文已经明确时可以省略：

- 明日、何をしますか。——明天做什么？
- 完整说法：あなたは明日、何をしますか。

# 易混项

- 「は」不总是等于主语；它标示的是谈话主题。
- 主题只能在对话双方已清楚时省略。
- 初学阶段可先理解为“至于／说到……”，不要只翻译成“是”。

# N5 要点

- 「は」读作「わ」。
- 主题不等于动作执行者时，常与「が」一起出现：AはBが～。
