# 学习者原始输出

N3第6个语法：  A=动词ます形去ます+【かけて/かける】+B。A=动词ます形去ます+【かけの/かけだ】+名词。表示刚开始做A。快要做A。

# 核心

表示动作 A 已经开始，但尚未完成，处于“做到一半／未完成”的状态。部分动词也可表示“差一点就……”。

# 接续

- 动词ます形去ます＋かける／かけて
- 动词ます形去ます＋かけの＋名词
- 动词ます形去ます＋かけだ

# 形式区别

- **～かける／～かけて**：作动词使用。  
  書きかける（开始写但没写完）；書きかけてやめた（写到一半停下了）。
- **～かけの＋名词**：修饰名词，表示“做了一半的……”。  
  食べかけのパン（吃到一半的面包）。
- **～かけだ**：作为谓语说明某物未完成。  
  このレポートは書きかけだ。（这份报告写到一半。）

# 语义边界

- 基本含义不是单纯“刚开始”，而是“已开始但未完成”。
- 对表示瞬间结果的动词，常可表示“差一点就……”，如「死にかける」「倒れかける」。

# 易混

- **～始める**：只强调“开始做”，不强调是否完成。
- **～かける**：强调动作停留在未完成状态。

# JLPT 考点

辨别动词形式与名词修饰形式：句中作动作时用～かける／～かけて；修饰名词时用～かけの；说明未完成状态时用～かけだ。

# 例句

1. 読みかけの本を机の上に置いた。
   - 我把读到一半的书放在桌上。
2. 食べかけていたケーキを冷蔵庫に入れた。
   - 我把吃到一半的蛋糕放进了冰箱。
3. 車にひかれかけた。
   - 差点被车撞到。
