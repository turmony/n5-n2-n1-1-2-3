# 核心与接续

## **【名詞】＋にくらべて（に比べて）／とくらべて（と比べて）**

**以 B 为比较基准，说明 A 与 B 相比的评价或程度差异。** 常译为“与 B 相比，A……／比起 B，A……”。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 名词 | 名词＋にくらべて／とくらべて | 北海道にくらべて／前回会った時とくらべて |

基本句型是 **A は B にくらべて（とくらべて）～**。B 是比较基准，A 是被说明或评价的一方：

- **A は B にくらべて大きい。**＝A 比 B 大。
- **A は B より（も）大きい。** 与上句意思接近；视频把「より（も）」作为已学的近似表达。

「にくらべると（に比べると）／とくらべると（と比べると）」也是常见相关形式，仍然把后面的对象作为比较结果，例如「去年に比べると、今年は暑い」。本课板书重点是「にくらべて／とくらべて」，不要把「と」误记成必须添加在「に比べて」后面。

当比较基准是动词或形容词所表示的事件、状态时，通常先用形式名词「の／こと」名词化，再接本句型；例如「以前勉強したことに比べて」。若比较基准本身已经是名词短语（「前回会った時」「去年の同じ月」等），直接接「に比べて／と比べて」。

# 语义边界与适用条件

1. **比较方向由 A、B 和谓语共同决定**：「北海道に比べて沖縄は暖かい」是“冲绳比北海道暖和”，不能机械译成“北海道比冲绳暖和”。阅读时先找「は」标记的 A，再看谓语描述 A 的差异。
2. **B 是基准，不一定是两个同类实体**：可以比较地点、时期、人物、数量、状态或事件，如「以前の作品」「前回会った時」「去年の同じ月」。
3. **可以表示程度变化或评价**：不仅用于“更大／更小”，也可接「おもしろくなくなった」「ずいぶん痩せた」「半分以下になった」等变化结果。
4. **「に比べて」与「と比べて」基本都表示比较**。课程说明「に比べて」更突出把 A、B 拿来比较的语感；独立资料把「Aに比べてB」概括为对比、把「Aと比べてB」概括为比较。这是常见语感倾向，不应当作所有句子都不能互换的硬性规则。
5. **语体**：「より（も）」较基础、口语中常用；「に比べて」稍正式，书面语和说明文很常见。日常会话并非不能使用「に比べて」。
6. **「に比べ」是书面或句中省略「て」的形式**：如「去年の同じ月に比べ、売り上げは……」。这里仍是本句型，不要误判为另一种助词接续。

# 原课板书例句

以下日文按原视频板书、日语讲解和字幕互相核对，中文为整理译文。

1. 冬になると寒さが厳しい北海道に比べて、一年中温暖な沖縄は、国内はもちろん、外国からも観光客が多く来ます。
   - 与一到冬天就很寒冷的北海道相比，常年温暖的冲绳不仅有国内游客，也有很多外国游客前来。
   - 句中「北海道に比べて」给出比较基准，「沖縄は」是被说明的一方；长句中的修饰成分不改变这两个角色。
2. 北海道に比べて、沖縄は観光客が多く来ます。
   - 与北海道相比，冲绳来的游客更多。
3. AはBより（も）大きい。／AはBに比べて（と）大きい。
   - A 比 B 大；这是课程用来并列比较「より」和「に比べて／と比べて」的板书框架。

# 课程例句

以下四句来自原视频05:30后的例句页，中文为整理译文。

1. あの作家の最近の小説は、以前の作品に比べておもしろくなくなった。
   - 那位作家最近的小说与以前的作品相比，变得没那么有趣了。
   - 「以前の作品」是基准；「おもしろくなくなった」表示评价下降，不是说作品绝对没有趣味。
2. 子どもは大人に比べて、集中力が続かないと言われています。
   - 据说孩子与大人相比，集中注意力的时间难以持续。
   - 这是课程例句中的一般性说法，不把它扩展成对每个孩子都成立的事实。
3. 上野さんは前回会った時と比べて、ずいぶん痩せました。
   - 上野先生和上次见面时相比，瘦了很多。
   - 「前回会った時」是名词性时间短语，直接接「と比べて」。
4. 去年の同じ月に比べ、売り上げは半分以下になってしまった。
   - 与去年同月相比，销售额降到了不到一半。
   - 「に比べ」是「に比べて」的书面式省略，「半分以下になってしまった」表示结果令人遗憾。

视频对话还使用了「昔に比べて今の子は幸せだねぇ」和「家でゲームするより楽しかった気がするなぁ」；前句是本课比较表达，后句是「より」的对照，说明两种表达在比较句中可能出现，但不能把「より」和「に比べて」的接续表混写。

# 自然例句（自拟）

1. 去年に比べて、今年は電気代が高くなりました。
   - 与去年相比，今年电费变贵了。
2. 東京と比べて、この町は夜が静かです。
   - 与东京相比，这座城镇晚上很安静。
3. 以前の説明に比べると、今回の説明のほうが分かりやすいです。
   - 和以前的说明相比，这次的说明更容易理解。
4. 一人で勉強するのに比べて、友達と練習するほうが会話の機会が多いです。
   - 与独自学习相比，和朋友练习时会话机会更多。

# 易混项与 JLPT 考点

| 表达 | 重点 | 对照 |
|---|---|---|
| にくらべて／とくらべて | 以 B 为基准说明 A 的评价或程度差异 | 沖縄は北海道にくらべて暖かい |
| より／よりも | 基础的比较表达，较常用于口语；比较顺序与「に比べて」不同 | 沖縄は北海道より暖かい |
| にくらべると／とくらべると | 「比べる」的と条件式相关形式，意义仍是“与……相比” | 去年に比べると今年は暑い |
| に対して | 对于、针对；也可表示对比关系，不等于单纯列出比较基准 | 兄が賛成なのに対して、弟は反対だ |
| ほど | 表示程度或“没有……那么……”等结构，不是本课的比较基准标记 | 今年は去年ほど寒くない |

- **接续题**：○ 北海道に比べて、○ 前回会った時と比べて；× 北海道のに比べて、× 北海道だに比べて。普通名词直接接「に／と比べて」，不加「の」或「だ」。
- **方向题**：看到「AはBに比べて～」时，B 是参照项，谓语首先说明 A；「日本は中国に比べて物価が高い」不是说中国物价更高。
- **词形题**：动词短语作基准时，不能把动词辞书形直接硬接而省略名词化；常见形式是「V辞書形＋の／こと＋に比べて」，或把整段改成名词短语。
- **变体题**：「に比べて／と比べて／に比べると／と比べると」要按题干的时态和语气选择；「に比べ」常见于书面句中，仍可还原为「に比べて」。
- **语义题**：题目常把「より」和「に比べて」互换，或利用 A、B 顺序制造干扰；先确定比较基准，再判断形容词或变化结果的方向。
- **语体题**：不要把「に比べて」误判成只能用于正式公文，也不要把「より」误判成不能用于书面语；这里是常见倾向而非绝对限制。
