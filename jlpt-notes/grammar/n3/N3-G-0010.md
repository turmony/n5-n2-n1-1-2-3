# 学习者原始输出

N3第10个语法：名词A+【から見て/から見ると/から見れば/から見たら】+ B。表示：从A来看，~。B是判断，评价，推测等词，如果是から見ると/から見れば/から見たら的话，后面就是一种假定表现

# 核心

从 A 的立场、角度来看，或根据 A 来判断，得出 B。

A 可以是判断的立场、评价的角度，也可以是作为判断依据的情况。B 表示判断、评价或推测。

# 接续

名词＋以下任一形式：

| 形式 | 接续规则 |
|---|---|
| からみて（から見て） | 名词＋からみて |
| からみると（から見ると） | 名词＋からみると |
| からみれば（から見れば） | 名词＋からみれば |
| からみたら（から見たら） | 名词＋からみたら |

# 理解校对

- 接续和基本意思正确。B 是表示判断、评价、推测的内容，不限定为某类词。
- 「からみると／からみれば／からみたら」使用条件形式，但这里通常表示“如果从 A 的角度来看”，不代表后面的 B 一定是假设或不确定的事情。

# 语义边界

- 四种形式在这个用法中意思接近，都可译为“从……来看”。
- 「からみて」直接提出判断角度；后三种以条件形式提出“从这个角度来看”的前提，「からみたら」较口语。
- 条件形式不等于 B 是假设。例如「親からみれば、子どもはいつまでも子どもだ」是从父母立场作出的判断。
- 此处的「みる」不一定指用眼睛看，也可以指考虑、评价。

# 图片例句

> コストの面から見ると、実現が難しい。
>
> 从成本方面来看，很难实现。

这里 A 是「コストの面」，即评价角度；B 是「実現が難しい」，即判断。句子并不是说“实现困难”是假定发生的事。

# 易混项

- **～にとって**：强调“对 A 而言”的意义、价值或影响。
  「私にとって、家族が一番大切だ。」对我而言，家人最重要。
- **～からみると**：强调“从 A 的立场或依据出发作判断”。
  「専門家から見ると、この説明は不十分だ。」从专家的角度来看，这个说明不充分。
- **～からいうと（から言うと）**：同样可以提出评价角度，但不能在所有句子中直接替换。例如表达“从专家的立场看”，用「専門家からみると」更合适。

# JLPT 考点

- 接续是名词＋からみて等，不加「の」。
- 判断 A 是立场、角度还是依据，后项是否与之构成合理的判断关系。
- 不要因为出现「と／ば／たら」，就把整句理解成尚未发生的假设。

# 自然例句

> 子どもから見れば、一時間はとても長い。
>
> 从孩子的角度来看，一个小时很长。

> この成績から見て、合格は難しいだろう。
>
> 从这个成绩来看，恐怕很难合格。
