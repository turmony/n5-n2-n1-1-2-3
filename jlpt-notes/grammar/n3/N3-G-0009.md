# 学习者原始输出

n3第9个语法：【普通形（な形容词である，名词である）】+かれ[に]は+B。表示：既然... ，后相B是决定，判断，义务等。な形容词である，名词である的意思是这两个的现在肯定形用である体。图片给了例子介绍该语法与另外两个语法在该例子的用法是一样

## 学习者对接续栏的修订要求

例子那一栏，不够直观地看到接续规则，直接写接续规则，动词就是普通形，い形容词也是普通形，剩下两个说明现在肯定形是である体

# 核心

既然 A，就当然应该／必须／一定要 B。

把 A 当作已经成立或确定的前提，强调由此产生的责任、决心或理所当然的判断。后项常接决心、义务、要求、劝告和判断等表达。

# 接续

| 类型 | 接续规则 |
|---|---|
| 动词 | 普通形＋からには |
| い形容词 | 普通形＋からには |
| な形容词 | 普通形（现在肯定形用「である」）＋からには |
| 名词 | 普通形（现在肯定形用「である」）＋からには |

- 原文「かれ[に]は」为笔误，正确形式为「から［に］は」。图片中的「に」可以省略，学习时先记完整形式「からには」。
- 学习者对「である」的理解正确：这里特别说明的是现在肯定形式，不能直接接成「学生だからには」「必要だからには」。过去、否定等形式仍按相应普通形接续，例如「学生だったからには」。

# 语义边界

- A 不一定是过去完成的动作，也可以是身份、现状或已经确定的未来行动。
- B 不只是客观描述结果，通常带有“既然如此，就该这样”的态度。
- 普通「から」可以单纯说明原因；「からには」更强调接受前提后应承担的责任或应有的结果。

# 图片例句与易混

图片右侧句尾被遮挡，以下为补全例句：

> 仕事を引き受けたからには、最後まで責任を持ってやらなければならない。
>
> 既然接下了工作，就必须负责到底。

在这个例句中，可以换成：

- **引き受けたいじょう（以上）は**：强调既成事实及随之而来的责任。
- **引き受けたうえ（上）は**：强调既已作出决定，就应贯彻到底，语气较郑重。

学习者所说的“在该例子中用法一样”是准确的；三者在这里意思接近，但接续和语体并非在所有句子里都完全相同。

# JLPT 考点

- 根据前项词性判断接续，特别注意な形容词、名词的现在肯定形式用「である」。
- 后项常见「～なければならない」「～べきだ」「～つもりだ」「～てほしい」「～はずだ」。
- 判断句子是否包含“既然前提成立，就应有相应行动／判断”的语气，区分单纯表示原因的「から」。

# 自然例句

> 日本に留学するからには、日本語をしっかり勉強するつもりだ。
>
> 既然要去日本留学，我就打算认真学习日语。

> 約束したからには、守るべきだ。
>
> 既然答应了，就应该遵守承诺。
