# 核心

## 功能一：说明或定义事物含义的表达方式

**最上位意味カテゴリー：**

- **「というのは〜〔名詞句〕だ」：** ものごとの関係（事物之间的关系）
- **「とは」：** ものごとの関係（事物之间的关系）
- **「って」：** ものごとの関係（事物之间的关系）

**中位意味カテゴリー：**

- **「というのは〜〔名詞句〕だ」：** 関連・対応（关联与对应）
- **「とは」：** 説明（说明）
- **「って」：** 説明（说明）

**意味：**

- **「というのは〜〔名詞句〕だ」：** 関連（关联）
- **「とは」：** 定義（定义）
- **「って」：** 主題（主题）

**くわしい意味記述：**

- **というのは〜〔名詞句〕だ：** Xというのは，Yという意味です・Yのことです。単語・語句・文が意味している内容を説明したり，定義したりするときに使う表現。「Xというと」の「というと」は会話では「っていうのは」「って」の形で用いられる。（「Xというのは」表示“是Y的意思”或“指Y”。这是用于说明或定义单词、短语或句子所表达内容的表达方式。「Xというと」中的「というと」在会话中采用「っていうのは」「って」的形式。）
- **とは：** 定義や意味を説明する時に使う。話し言葉で使う。話し言葉では「〜って」を使う。「というのは」よりも書き言葉的。（用于说明定义或含义。用于口语；口语中使用「〜って」。比「というのは」更偏书面。）
- **って：** 定義や意味を説明する時に使う。話し言葉で使う。書き言葉では「〜とは」を使う。（用于说明定义或含义。用于口语；书面语中使用「〜とは」。）

**派生語：** 「というのは〜〔名詞句〕だ」：未列出；「とは」：というのは；「って」：未列出

### 例句

1. 「あけおめ」というのは「あけましておめでとう」のことだ。

   （“あけおめ”就是“あけましておめでとう”的简称。）

2. ファクトリーショップというのは工場の直営のお店で、（うーん）ま、工場にくっついてたりしてて、だから２級品とかＢ級品とかをすごい安く売ってるお店じゃんね。

   （所谓工厂直营店，就是由工厂直接经营的商店，嗯，比如店铺附设在工厂旁边，所以会非常便宜地出售二等品或B级品之类的商品。）

3. ムラサキとはしょう油のことである。

   （“ムラサキ”是指酱油。）

4. エアコンって、なんのことですか。

   （“エアコン”是指什么？）
