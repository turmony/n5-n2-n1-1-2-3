# 学习者原始输出

N3第14个语法：名词A+こそ。表示强调，正是A，...。其中A不能是讨厌和轻视

# 核心

「名词＋こそ」突出强调该名词，表示“正是……”“……才是”。从其他可能的人、事物、时间等之中，突出强调这一项。

# 接续

名词＋こそ。

主语后的「が」通常由「こそ」替代：あなたこそ，不是「あなたがこそ」。

# 图片例句与寒暄

> あなたこそうちの会社に必要な人材だ。
>
> 你才是我们公司需要的人才。

强调的是「あなた」，不是其他人。

> A：どうぞよろしく。
>
> 请多关照。
>
> B：こちらこそよろしく。
>
> 我才要请您多关照。

「こちらこそ」把对方的客气话回应到自己这一方，也常用于回应感谢或道歉。

# 理解校对与语义边界

核心理解正确。不是 A 不能是讨厌、轻视的对象，而是不能用「こそ」本身表达“……之类的、……这种人”的轻蔑语气。

图片将下面的句子作为不合适的例子：

> あなたこそうちの会社に必要ない。

这里要区分两种意图：

- 如果想轻蔑地说“你这种人，我们公司不需要”，应使用「あなたなんて」，不是用「こそ」表达轻蔑。
- 如果有明确的对比语境，想反驳“你才是公司不需要的人”，「あなたこそ」可以成立，不过语气很尖锐。

不能记成「こそ不能用于负面对象或否定句」。图片的叉号适合理解为针对“轻蔑用法”的教学提示，不宜扩大为绝对禁用规则。

# 易混项

| 形式 | 重点 | 例子与意思 |
|---|---|---|
| ～こそ | 突出强调“正是这一项” | 今度こそ成功したい。／这次一定要成功。 |
| ～は | 提出话题或形成对比 | 私は行きます。／我会去。 |
| ～だけ | 限定“只有” | 私だけ行きます。／只有我去。 |
| ～なんて | 可表达轻视、贬低，也有其他用法 | あなたなんて必要ない。／你这种人根本不需要。 |

「こそ」不等于“只有”；强调某一项，不一定排除其他所有项。

# JLPT 考点

- 注意固定回应「こちらこそ」。
- 「今度こそ」「今年こそ」常表达“这次／今年一定要……”的决心，往往暗含之前未能实现。
- 注意「こそ」强调的对象及其与「が」的替代关系。
- 区分突出强调、限定范围和轻蔑语气；不要将负面语境一概视为「こそ」的禁用条件。

# 补充自然例句

> 今年こそ日本語能力試験に合格したいです。
>
> 今年一定要通过日语能力考试。

> これこそ私が探していた本です。
>
> 这正是我一直在找的书。

> 困ったときこそ、助け合うことが大切です。
>
> 正是在困难的时候，互相帮助才格外重要。
