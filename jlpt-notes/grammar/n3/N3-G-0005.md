# 学习者原始输出

N3第5个语法：  A=【（动词辞书形/动词ない形）/（名词+の）】+おそれ（恐れ）がある。表示恐怕A。A是负面的内容。

# 核心

表示有发生 A 的危险、可能或担忧，常译为“恐怕会……”“有……的风险”。A 是可能发生的不良事态。

# 接续

- 动词辞书形＋おそれがある
- 动词ない形＋おそれがある
- 名词＋の＋おそれがある

# 语义边界

- 多用于灾害、事故、损失、失败、疾病扩散等负面风险。
- 语气较正式，常见于新闻、通知、报告和警告。
- 不适合用于说话人能自行决定的行为或请求。

# 易混

- **～かもしれない**：只表示“可能”，正面、负面、中性内容都可用。
- **～おそれがある**：强调负面后果的风险与担忧。

# JLPT 考点

判断 A 是否为负面、非意志性的潜在事态；若只是中性或正面的可能性，通常不用～おそれがある。注意动词可接辞书形或ない形，名词接「の」。

# 例句

1. 大雨で、川が氾濫するおそれがある。
   - 因为大雨，河流恐怕有泛滥的危险。
2. このままでは、締め切りに間に合わないおそれがある。
   - 再这样下去，恐怕赶不上截止日期。
3. この地域では、津波のおそれがある。
   - 这一地区有发生海啸的风险。
