# 核心与接续

## **A【名词】＋はともかく（として），B／A【普通形（去だ・去だ）】＋か＋はともかく（として），B。**

先把A暂放一边、不讨论其好坏或重要性，转而强调B；常译为“暂且不论A，先说B”。名词可直接接；疑问或从句作A时，用「普通形（去だ・去だ）＋か」再接「はともかく（として）」。这里的「普通形（去だ・去だ）」表示：动词、い形容词使用普通形；な形容词和名词的现在肯定形去掉「だ」，其他时态仍用普通形。「として」可加可不加，语气更完整。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 名词 | 名词＋はともかく（として） | 値段はともかく、品質はいい。 |
| 动词 | 动词普通形＋か＋はともかく（として） | 何を買うかはともかくとして、店へ行こう。 |
| い形容词 | い形容词普通形＋か＋はともかく（として） | 難しいかどうかはともかく、挑戦してみる。 |
| な形容词 | な形容词普通形（现在肯定去だ）＋か＋はともかく（として） | 便利かどうかはともかく、少し高い。 |
| 名词 | 名词直接＋はともかく（として）／名词现在肯定去だ＋か＋はともかく（として） | 値段はともかく、品質はいい。／学生かどうかはともかく、参加できる。 |

# 语义边界与适用条件

- A不是被否定，而是暂不作为当前判断重点；B是说话人真正要传达的事项。
- 名词可直接接；疑问或从句作A时用「普通形（去だ・去だ）＋か＋はともかく（として）」。「として」不是必须成分。
- 与「はさておき」相近；「はともかく」更常用于“先不管A，B仍成立”的口语说明。

# 课程例句与自然例句

- 彼女が作ってくれた料理は見た目はともかく、とてもおいしかった。——她做的菜外观暂且不论，味道非常好。
- 何を学ぶかはともかくとして、大学を卒業したほうがいい。——先不论学什么，还是应该大学毕业。
- 顔はともかく、すごくやさしい子なの。——长相暂且不论，她是个非常温柔的孩子。
- 結果はともかく、最後まで努力したことが大切だ。——结果先不说，坚持努力到最后很重要。

# 易混项及 JLPT 考点

- 「はもちろん」是“当然包括A”，与暂不讨论A的「はともかく」方向相反。
- 「はさておき」也表示先搁置A，但语体较书面；「を問わず」表示不论条件、范围，不是话题暂置。
- JLPT接续题常考两种结构：名词直接接「はともかく（として）」；普通形（な形容词、名词现在肯定去「だ」）＋か＋はともかく（として）。不要把「か」结构误写成「名词のはともかく」。
