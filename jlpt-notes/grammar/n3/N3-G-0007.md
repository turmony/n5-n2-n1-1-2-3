# 学习者原始输出

N3第7个语法：  A=动词ます形去ます+がち。表示经常A/有A倾向。前面一般是负面内容

补充疑问：解释图片中的“な形容词/名词”指的是什么。

# 核心

表示某种事情容易反复发生，或某人容易处于某种状态，常译为“常常……”“容易……”“有……的倾向”。

# 接续

- 动词ます形去ます＋がち
- 名词＋がち

# “な形容词／名词”的含义

它指接上～がち以后形成的「～がち」的用法性质，并不是“な形容词直接接～がち”。

- **忘れがちだ**：～がち作谓语。
- **忘れがちな人**：～がち像な形容词一样，用「な」修饰名词。
- **病気がちの祖父**：～がち像名词一样，用「の」修饰名词。

因此，「忘れがち」「病気がち」正确；「静かがち」「便利がち」错误。静か、便利等な形容词不能直接接～がち。

# 语义边界

- 前面通常是负面、不理想的行为、状态或结果。
- 不只是单纯频率高，还带有“容易落入这种情况”的倾向。
- 常见于「忘れがち」「休みがち」「病気がち」。

# 易混

- **～やすい**：表示“容易发生／容易做”，不一定带负面评价。
- **～がち**：通常带不理想、令人担心的倾向。
- **～始める**：表示开始；～がち不表示开始，而表示反复出现的倾向。

# JLPT 考点

注意接续为动词ます形去ます或名词；同时能辨别「～がちな＋名词」与「～がちの＋名词」都是由接续后的～がち来修饰名词，不能把な形容词直接接到～がち前。

# 例句

1. 彼は約束を忘れがちだ。
   - 他常常忘记约定。
2. 忘れがちなことは、メモしておくといい。
   - 容易忘记的事最好先记下来。
3. 祖父は病気がちのため、心配です。
   - 爷爷容易生病，所以令人担心。
4. 彼は学校を休みがちだ。
   - 他常常缺课。
