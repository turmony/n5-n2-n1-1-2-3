# 学习者原始输出

N3第2个语法：  A=【普通形（な，の）】+うえに+B。表示不但A而且B。A和B必须是相同的情感色彩，例如都是正面的或者都是负面的

补充：A＝【普通形（な，の）】＋上（うえ）に＋B  。名词＋の＋上に  。な形容词词干/名词词干 +である+うえに。

# 核心

在 A 的基础上再补充 B，表示“不但 A，而且 B”。常用于叠加同一方向的评价、特征或理由。

# 接续

- 动词普通形＋上に
- い形容词普通形＋上に
- な形容词词干＋な＋上に
- 名词＋の＋上に
- 较正式的表达：な形容词词干／名词＋である＋上に

# 语义边界

- A、B 通常具有相同的评价方向，例如都正面或都负面。
- 若一正一负，通常不适合用～上に；想单纯并列不同性质的信息时，可考虑～だけでなく等表达。
- A、B 多为同一对象的不同特点，或能共同构成同一方向的理由。

# 易混

- **～だけでなく**：单纯表示“不但……而且……”，并列限制相对少。
- **～上に**：带有在原有评价或理由上进一步叠加的语气，通常要求两项评价方向一致。

# JLPT 考点

重点判断接续形式与 A、B 的评价方向：な形容词用「な」，名词可用「の」；在较正式语境中，な形容词和名词也可接「である上に」。

# 例句

1. この店の刺身は安いうえに、おいしい。
   - 这家店的生鱼片不但便宜，而且好吃。
2. この店の刺身は高いうえに、おいしくない。
   - 这家店的生鱼片不但贵，而且不好吃。
3. 彼は親切なうえに、仕事もできる。
   - 他不但亲切，工作能力也强。
4. この町は交通が不便であるうえに、店も少ない。
   - 这个城镇不但交通不便，商店也少。
