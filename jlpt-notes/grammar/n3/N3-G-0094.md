# 核心

## 功能一：A处放入立场、视点、判断材料（根据）等，B处放入感想、评价、判断、推测等内容

**最上位意味カテゴリー：**

- **「からいって」：** ものごとの関係（事物之间的关系）
- **「からいうと」：** ものごとの関係（事物之间的关系）
- **「からいえば」：** ものごとの関係（事物之间的关系）

**中位意味カテゴリー：**

- **「からいって」：** 判断の立場（判断的立场）
- **「からいうと」：** 判断の立場（判断的立场）
- **「からいえば」：** 判断の立場（判断的立场）

**意味：**

- **「からいって」：** 立場・視点（立场与视点）
- **「からいうと」：** 観点（角度）
- **「からいえば」：** 観点（角度）

**くわしい意味記述：**

- **からいって：** 話し手の主張を補強するために，ある見方を例に挙げて述べるときに使う。（为加强说话人的主张，在举出某种看法进行陈述时使用。）
- **からいうと：** 経験をもとに考えを言うときに使う。アドバイスを求められ，それに答えるときによく使う。「私」「彼」といった人を表す名詞に直接付くことはできない。（用于以经验为依据表达想法。常用于别人征求建议而自己作答时。不能直接接在「私」「彼」等表示人的名词之后。）
- **からいえば：** 話し手や話し手に近い立場の意見を述べるときに使う。「私」「彼」といった人を表す名詞に直接付くことはできない。（用于陈述说话人或与说话人立场相近一方的意见。不能直接接在「私」「彼」等表示人的名词之后。）

**派生語：** 「からいって」：未列出；「からいうと」：未列出；「からいえば」：未列出

### 例句

1. 法律の改正は現状からいって、無理だ。

   （从现状来看，修改法律行不通。）

2. 学生の立場から言うと、優しすぎる先生はやる気がなくなる。

   （从学生的立场来说，老师过于宽松反而会让人失去干劲。）

3. この考え方は、私の経験からいうと、よくイギリス人などにもあらわれている。

   （根据我的经验，这种想法也常见于英国人等群体。）

4. 社会の常識から言えば、お世話になったかたにお礼をするのは当然だ。

   （从社会常识来说，向关照过自己的人道谢是理所当然的。）
