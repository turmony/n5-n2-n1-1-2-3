# 核心与接续

## **A【动词辞书形】だけで B。**

总接续严格按原视频板书：A为一个简易、较小的动作，B为由此出现的较大结果或状态。这里的「だけで」不是“仅限于A”的数量限定，而是“只做A／仅凭A就产生B”的因果或触发关系。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 动词 | 动词辞书形＋だけで | 聞くだけで日本語が上手になる；見るだけでお腹がいっぱいになる |

「で」是助词，整体「だけで」连接后项结果。视频主讲辞书形；外部资料还记录动词た形＋だけで，如「見ただけでつばが出る」，表示“仅仅做过／一做就……”，该形式作为补充，不改写视频总接续。

### 场景：只需一个简单动作就引发明显结果

**场景演示（自拟场景）：**
朋友介绍一款学习材料，说明每天只需做很小的动作就可能带来学习或身体状态的变化；另一人用“仅仅看到食物就……”表达即时反应。

甲：このCDは、寝ながら聞くだけで日本語が上手になるそうだよ。<br>
（听说这张CD只要躺着听，就能让日语变好。）

乙：本当かな。でも、毎日少しずつ続けるのはよさそうだね。<br>
（真的吗？不过每天一点点坚持似乎不错。）

甲：こんなたくさんの料理、見ているだけでお腹がいっぱいになりそう。<br>
（这么多菜，光是看着就好像饱了。）

乙：食べる前から満足しないで、少しは食べてね。<br>
（别还没吃就满足了，至少吃一点吧。）

# 语义边界、适用条件及后项限制

1. 核心是“仅凭A就出现B”，A通常是较简单的动作，B是状态、感受、能力变化等结果；不保证该结果在现实中必然发生。视频第一条例句本身带有广告式夸张，不能当作事实保证。
2. 常见于知觉或思考动词：見る、聞く、考える、想像する、思い出す等；「見ただけで／聞いただけで」可强调一次体验或刚做过某事就触发后项。
3. 与限定「二人だけで話す」不同：该句的「だけ」表示只有两个人，后面的「で」表示方式或范围；本课的「AだけでB」表示A足以触发B。
4. 「だけでも」表示“即使只做A也……”或最低限度，「だけでは」表示“仅凭A还不够／若只有A”；助词变化会改变判断方向。
5. 后项多为自然发生的感受、状态或评价，不宜把本课当作一般条件句「如果A就B」的无条件替换；根据语境可与「～と」等表达比较，但本课突出“只凭A就足以产生B”。
6. 视频提到名词、い形容词等「だけで」的其他接续和限定用法，例如「二人だけで話がしたい」「可愛いだけで歌唱力は素人レベルだ」；这些不是本课主讲的“动词辞书形＋だけで”总接续，列作范围外补充。

# 易混项及 JLPT 考点

| 表达 | 区别与考点 |
|---|---|
| AだけでB（本课） | 仅凭A就产生B；如見るだけでお腹がいっぱいになる |
| Nだけで | 只有N；如二人だけで話す，表示限定人数 |
| AだけでもB | 即使只做A也B／最低限度也B，带让步或最低要求 |
| AだけではB | 仅凭A不足以B，常接否定或不足判断 |
| Aたら／AとB | 一般条件或恒常结果；「だけで」突出“只凭A就足够” |

JLPT常考：动词接「だけで」用辞书形（聞くだけで、温めるだけで）；阅读中根据B判断是“限定”还是“仅凭A触发结果”；注意「見ただけで」的た形补充及「だけでも／だけでは」的助词差异。
