# 学习者原始输出

N3第11个语法：【普通形（な・の）】+ かわりに+B。有三种用法。1，表示代替。2，表示反面。3，表示代偿行为。【普通形（な・の）】な形容词和名词的现在肯定形要去だ加な/の。至于图中的である，可能也可以用である，我不确定，请你检索相关信息

## 学习者修订要求

不做 A，改做 B 改为A不做，B做是不是更符合

# 核心

根据前后项的关系，主要分为三种：

| 用法 | 意思 |
|---|---|
| 代理、代替 | 代替 A 做 B；A 不做，B 做 |
| 相反的两面 | 有 A 这一面，同时也有 B 这一相反面 |
| 回报、补偿、交换条件 | 作为 A 的回报或交换，做 B |

“A 不做，B 做”对应 A、B 都是动作的情况。不同教材可能把“代理”和“代用”分开列，用法数量不同，不影响按这三类理解。

# 接续

| 类型 | 接续规则 |
|---|---|
| 动词 | 普通形＋かわりに；表示“A 不做，B 做”时，通常用辞书形 |
| い形容词 | 普通形＋かわりに |
| な形容词 | 普通形（现在肯定形用「な／である」）＋かわりに |
| 名词 | 代理、代用：名词＋の＋かわりに；将身份或性质作为前项：名词＋である＋かわりに |

# 理解校对与である接续

- 三种用法理解基本正确。「代偿行为」记为“回报、补偿或交换条件”，范围更清楚。
- 「である」确实可以用，但不能把「名词＋の」与「名词＋である」不分意思地互换。
- **便利なかわりに／便利であるかわりに**：都把“便利”作为前项性质；「である」较书面。
- **先生のかわりに**：代替老师。
- **先生であるかわりに**：前项是“是老师”这件事，需要后文构成相应的对照或交换关系，不能理解成“代替老师”。
- “现在肯定形去掉「だ」，加「な／の」”可以作为基本记法；名词部分还要结合具体用法判断。

日本語NET 明确列出「ナAな／である」「Nである」；たのすけ也将它们与代理、代用中的「Nの」分开说明。来源见页尾。

# 图片例句

## 代理、代替

> 今日は田中先生のかわりに私が授業します。
>
> 今天由我代替田中老师上课。

A 是被代替的人，B 是由别人承担的动作。

## 相反的两面

> ここは家賃が安いかわりに、交通が不便だ。
>
> 这里房租便宜，但交通不便。

“房租便宜”是优点，“交通不便”是缺点。此处不是“用交通不便代替房租便宜”。

## 回报、交换

> 引っ越しを手伝ってもらったかわりに、食事をごちそうした。
>
> 作为对方帮我搬家的回报，我请对方吃了饭。

「手伝ってもらった」表示我得到了帮助，后项是我作出的回报。

# 语义边界与易混项

- **～けれども**：可以泛指转折；「かわりに」强调两面之间有得有失、相互抵偿，不适用于所有转折。
- **～にかわって（に代わって）**：表示代替某人承担行动时，常与「～のかわりに」接近；不能直接套用于优缺点对照或回报用法。
- 交换不一定已经完成，也可以提出条件，例如“我帮你做 A，你帮我做 B”。

# JLPT 考点

- 先判断是“替代”“优缺点对照”还是“交换回报”，再判断接续。
- 注意「な形容词＋な」，以及名词后的「の／である」所表达的不同关系。
- 遇到「～てもらったかわりに」，先分清谁获得帮助、谁作出回报。

# 补充自然例句

> 外食するかわりに、家で料理します。
>
> 不出去吃，在家做饭。

A「外食する」不做，B「家で料理する」做。

> この部屋は静かなかわりに、駅から遠い。
>
> 这个房间很安静，但离车站远。

> 日本語を教えるかわりに、中国語を教えてください。
>
> 我教你日语，作为交换，请你教我中文。
