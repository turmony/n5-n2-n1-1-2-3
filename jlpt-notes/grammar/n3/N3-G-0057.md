# 核心与接续

## **【普通形（だ不要・だ不要）】＋にちがいない（に違いない）**

**一定……；肯定……；准是……；确实是……。** 表示说话人强烈相信某个判断成立。典型场景是根据线索、经验或情况作出确信程度很高的推断；也可用于郑重确认。

括号依次对应**な形容词、名词的现在肯定形**：不加だ，不改成な或の；这两类也可使用较正式的「である＋にちがいない」。动词和い形容词按普通形接续。

| 类型 | 接续规则 | 示例 |
|---|---|---|
| 动词 | 普通形＋にちがいない | 来る／来ない／来た／来なかった＋にちがいない |
| い形容词 | 普通形＋にちがいない | おいしい／おいしくない／おいしかった／おいしくなかった＋にちがいない |
| な形容词 | 现在肯定：词干＋にちがいない，或词干＋である＋にちがいない；其他形式按普通形 | 大変にちがいない／大変であるにちがいない／大変だったにちがいない／大変ではなかったにちがいない |
| 名词 | 现在肯定：名词＋にちがいない，或名词＋である＋にちがいない；其他形式按普通形 | 学生にちがいない／学生であるにちがいない／学生だったにちがいない／学生ではないにちがいない |

「だ不要」只针对现在肯定形，不删除过去形「だった」。例如「学生ではなかったにちがいない」仍可表示“当时肯定不是学生”，需要合适上下文支持判断。表格展示词形，不意味着无须语境就能自然断言。

- **礼貌形式：にちがいありません（に違いありません）**；也可说「にちがいないです」。原课钱包例句采用前者。前项仍按表格接续，不说「来ますに違いありません」。
- **否定放在前项**：「来ないにちがいない」是“肯定不会来”；「知らなかったにちがいない」是“当时肯定不知道”。末尾的ない属于整个确信句型，不会使整句变成否定推断。
- **違いない不是違う的ない形**。五段动词「ちがう（違う）」的ない形是「ちがわない（違わない）」；本句型中的「ちがい（違い）」按名词理解，与ない组合。不能把「来るに違いない」改成「来るに違わない」。

# 语义边界与语气

1. **强烈确信不等于已经客观证实**。看到餐馆排队，推断很好吃，这仍是推断；后来发现并不好吃，不代表前句语法错误。
2. **依据可以明确说出，也可由语境补足**。常见「～から」「～を見ると」「きっと」「やっぱり」，但这些词不是必需。不要把“有依据”写成“必须提供科学证明”。
3. **可判断现在、过去或将来**：「疲れているに違いない」「忘れたに違いない」「喜ぶに違いない」由前项和上下文确定时间。
4. **可用于郑重确认**。原课中本人认出失而复得的钱包，说「私が落とした財布に違いありません」，强调确实无误。这种已能确认的场景，与尚未核实的强烈推断要分开理解；不能把所有に違いない都规定为“100%事实”。
5. **不是命令、义务或自己的意向形式**。「彼は来るに違いない」表示判断他肯定会来，不是要求他必须来。表达“我打算去”通常用「行くつもりです」等，不用本课句型替代计划表达。
6. **与にきまっている的差别是依据和语气的倾向**。に違いない常呈现由情况得出结论的语感；に決まっている常带“当然如此、这还用说”的强主张。两者都可有依据，不能简单分成“一个客观、一个完全无依据”。
7. **不把推测表达换算成固定概率**。原视频为了展示强弱而排列「だろう／はずだ／と思う／ようだ／らしい／かもしれない」；本卡保留这些对照，但不把排列或讲解中的百分比当成统一规则。「ようだ／らしい」还涉及信息来源与判断方式，不能只按确信程度排序。

# 原课板书例句与讲解

以下依原视频板书与日语字幕核对，中文为整理译文。

1. 彼は来るに違いない。
   - 他一定会来。
2. 彼は来るに決まっている。
   - 他当然会来。
   - 原课用于对照：に決まっている更突出说话人认为“不必考虑也很明显”的态度，不作为本课的新接续。
3. 確かにこれは私が落とした財布に違いありません。
   - 确实，这就是我丢失的钱包。
   - 本人确认失物的例子，既展示礼貌形式，也展示“确实无误”的断定。

原课另列「彼は来るだろう／来るはずだ／来ると思う／来るようだ／来るらしい／来るかもしれない」作为相关表达。这里仅记录课程对照，不为它们各自指定概率。

# 课程例句

以下四句按06:30例句页核对，中文为整理译文。

1. 吉村氏なら、国民の要望に応えてくれるに違いない。
   - 如果是吉村先生，一定会回应国民的诉求。
   - 展示说话人的信任与预期，不等于已经发生的事实。
2. 開店前から人が並んでいる。このラーメン屋はおいしいに違いない。
   - 还没开门就有人排队，这家拉面店一定很好吃。
   - “有人排队”是线索；「このラーメン屋はおいしい」自然理解为店里的拉面好吃。
3. やっぱり犯人はあの男に違いない。
   - 果然，犯人一定是那个男人。
   - 这是课程场景中说话人的判断，不因使用に違いない就成为事实认定。
4. 確かにこれは私が落とした財布に違いありません。
   - 确实，这就是我丢失的钱包。

# 自然例句（自拟）

1. 昨夜はほとんど寝ていないそうだから、彼は疲れているにちがいない。
   - 听说他昨晚几乎没睡，他肯定很累。
2. あの時あんなに驚いていたのだから、彼女は何も知らなかったにちがいない。
   - 她当时那么吃惊，肯定什么都不知道。
3. この量の仕事を一人で終えたのだから、大変だったにちがいない。
   - 一个人完成这么多工作，一定很辛苦。
4. 制服を着て学校へ向かっているので、あの人は学生にちがいない。
   - 那个人穿着校服朝学校走去，肯定是学生。

# 易混项与 JLPT 考点

| 表达 | 重点 | 对照 |
|---|---|---|
| にちがいない | 强烈确信的推断，也可郑重确认 | こんなに遅いのだから、何かあったに違いない |
| にきまっている | 强烈主张，常带“当然、这还用说” | そんな話は嘘に決まっている |
| はずだ | 根据已知情况、安排等判断“按理应该” | 予定どおりなら、もう着いているはずだ |
| かもしれない | 提出可能性，不断言一定成立 | 電車が遅れているかもしれない |
| にそういない（に相違ない） | 较正式、书面的“确实／无疑” | 与に違いない相关，常见于郑重确认或书面陈述 |
| ちがわない（違わない） | 动词違う的否定，表示没有不同或没有错 | 本课固定形式是違いない，不能替换为違わない |

- **接续题**：○ 学生に違いない／学生であるに違いない；× 学生だに違いない／学生なのに違いない（若要表达“肯定是学生”）。
- **な形容词题**：○ 大変に違いない／大変だったに違いない；× 大変なに違いない。不要误加な，也不要删掉过去形。
- **否定题**：「行かなかったに違いない」＝肯定没去；末尾ない不等于“并非肯定”。
- **形式题**：「違いない→違いありません」；不是「違わない→違いありません」这一组动词变形。
- **阅读题**：区分线索与结论，并区分说话人的确信、推断和已核实事实；「きっと／やっぱり」帮助理解语气，但不是客观证明。
- **级别说明**：本库按出口日語N3第57课编号保存；部分教学网站列为N2，属于教学分级差异，不改变接续。
